# そらまめマーケット 地域別売上アプリ

そらまめマーケット（架空の会社）の店舗の日次売上から、地域を選ぶとその地域の月別売上の図と、店舗別の2025年の売上の表を出す Shiny アプリです。R データ分析108ステップの第102〜105ステップで作りました。

## 動かし方

1. `data` フォルダに `sora_stores.csv` と `store_sales_daily.csv` を置きます。
2. RStudio で `app.R` を開き、「Run App」を押します。

## データについて

店舗の売上は社外秘のため、このリポジトリには含めていません（`.gitignore` で `data/` を除外しています）。データは社内の共有フォルダから入手してください。
