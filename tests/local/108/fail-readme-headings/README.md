# 広告経由の顧客は、買う額が少ないのか

R データ分析108ステップの修了課題です。そらまめマーケット（架空の会社）のネット通販のデータで、流入経路と購入額の関係を調べました。

広告経由で入った顧客は、ほかの経路の顧客より1年間に買う額が少ないか。年齢の違いを考えても差は残るか。

## データ

注文明細（ec_orders.csv）と顧客マスタ（ec_customers.csv）を使いました。社外秘のデータなので、このリポジトリには含めていません。アプリからダウンロードして data フォルダに置いてください。

年齢をそろえても、広告経由の顧客の2025年の購入額は、検索経由より1人あたり約3,900円少ないことが分かりました。

## 作り方

RStudio で final.qmd を開き、Render を押すと final.html ができます。
