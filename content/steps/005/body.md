## 問い

そらまめマーケット（架空の会社です）の経営企画部で、上司から「客単価と売場効率が最も高い店舗はどこか、調べてほしい」と頼まれました。stores には売上と客数と売場面積はありますが、客単価や売場効率の列はありません。そこで、既存の列から新しい列を作ります。

## 列を作る：mutate()

客単価とは、客1人が1回の買い物で使った金額の平均です。売上を客数で割れば求められます。新しい列を作るには dplyr の `mutate()` を使います。mutate は「変化させる」という意味の英語です。`mutate(データ, 新しい列名 = 計算式)` の形で書きます。

```r
stores_spend <- mutate(stores, spend = sales * 10000 / customers)
glimpse(stores_spend)
```

売上 sales の単位は万円なので、10000 を掛けて円に直してから客数で割っています。単位をそろえる確認は、仕事でも計算ミスを防ぐ大切な習慣です。

計算式の中では、列名をそのまま変数のように書けます。`sales * 10000 / customers` は「各行の売上をその行の客数で割る」という意味で、50店舗それぞれについて一度に計算されます。このように、1行ずつ繰り返しを書かなくても列全体をまとめて計算できることを、ベクトル演算といいます。

`mutate()` は元の列をすべて残し、新しい列を右端に加えます。カンマで区切れば、複数の列を一度に作れます。ここで売場効率も作りましょう。売場効率とは、売場1 m² あたりの売上（万円）で、限られた売場をどれだけ上手に使えているかを表します。

```r
mutate(stores,
       spend = sales * 10000 / customers,
       sales_per_m2 = sales / floor_m2)
```

なお、すでにある列名を指定すると、新しい列は加わらず、その列が上書きされます。

## 列を選ぶ：select()

列が増えると、表が横に長くなって見にくくなります。上司に見せる表は、必要な列だけに絞るのが基本です。必要な列だけを残すには `select()` を使います。

```r
stores_small <- select(stores_spend, store_name, region, location, spend)
stores_small
```

`select(データ, 列名1, 列名2, ...)` の形で、残したい列を並べます。列名には引用符を付けません。書いた順に列が並ぶので、見たい順に並べ替える目的にも使えます。逆に、特定の列だけを外したいときは、列名の前に `-` を付けます。

```r
select(stores_spend, -store_id)
```

行を選ぶのが `filter()`、列を選ぶのが `select()` です。名前が似ているので、「行は filter、列は select」と組で覚えましょう。

## 条件で値を分ける：if_else()

上司は「前年より売上が伸びた店舗か」も一目でわかるようにしてほしいそうです。今年の売上が前年以上なら「増収」、前年を下回れば「減収」と区分します。

条件によって値を変えるには `if_else()` を使います。

```r
stores_trend <- mutate(stores_spend,
                       trend = if_else(sales >= sales_last, "増収", "減収"))
select(stores_trend, store_name, sales, sales_last, trend)
```

`if_else(条件, TRUE のときの値, FALSE のときの値)` の形です。条件が各行で判定され、TRUE の行には "増収"、FALSE の行には "減収" が入ります。`mutate()` の中で使うと、区分を表す列を作れます。このような区分の列は、次の第6ステップでグループごとに集計するときに役立ちます。

最後に、第4ステップの `arrange()` と `desc()` を使って客単価や売場効率の高い順に並べれば、冒頭の問いに答えられます。客単価の1位と売場効率の1位が同じ店舗とは限りません。どんな立地の店舗が上位に来るかにも注目しながら、小課題で実際に実行して確かめてみましょう。

## 卒論・実務での使いどころ

「1人あたり」「1 m² あたり」「前年比」などの指標を既存の列から計算し、必要な列だけを残す作業は、卒論の実証分析でも会社の売上報告でも最初に必ず行う下ごしらえです。
