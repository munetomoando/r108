## 問い

計量経済学の教科書に載っている推定結果は、同じデータと同じ式を使えば、自分の手で再現できるはずです。第5部の総合演習として、Wooldridge の教科書の賃金関数を R で再現し、二次項と交差項を加え、回帰表にまとめます。最後に、同じ式を日本の架空データで推定して比べます。

## 使うデータ

`wage1` は、J. M. Wooldridge の教科書 *Introductory Econometrics: A Modern Approach*（第7版、Cengage、2020年）で使われている賃金データです。1976年の米国の人口動態調査（Current Population Survey）から取った526人の労働者で、wooldridge パッケージに入っています。時給 `wage`（ドル）、教育年数 `educ`、経験年数 `exper`、勤続年数 `tenure`、女性ダミー `female` などの列があります。

比べる相手は、第21ステップから使ってきた `wage`（3,000人）です。教材用に乱数で作った**架空のデータ**で、実在の調査の値ではありません。

## 教科書の例を再現する

```r
m_ex2 <- lm(log(wage) ~ educ, data = wage1)
m_ex3 <- lm(log(wage) ~ educ + exper + tenure, data = wage1)
```

例2.10の単回帰では、切片が約0.584、教育年数の係数が約0.083、決定係数が約0.186です。教育年数が1年長いと時給はおよそ8.3%高い、と読みます（正確には $(e^{0.083}-1)\times 100 \approx 8.6\%$）。例3.2の重回帰では、教育年数が約0.092、経験年数が約0.0041、勤続年数が約0.022、決定係数が約0.316です。どれも教科書の値と小数第3位まで一致します。

再現は、先行研究を自分の分析の出発点にする第一歩です。値が合わなければ、データの版、標本の絞り込み、変数の作り方のどこかが違っています。

## 二次項と交差項を加える

教科書の第7章では、経験年数と勤続年数の二次項、女性ダミーと教育年数の交差項を加えた式(7.18)を推定しています（版によって式番号が違うことがあります）。

```r
m_ex7 <- lm(log(wage) ~ female * educ + exper + I(exper^2) + tenure + I(tenure^2),
            data = wage1)
```

交差項 `female:educ` は約 −0.0056 で、標準誤差は約0.0131です。教育の効果が男女で違うという証拠はほとんどありません。`female` の係数約 −0.227 は「教育年数0年の女性」と男性の差なので、これだけを男女差として読んではいけません（第41ステップ）。経験年数のピークは $-0.0293/(2\times(-0.00058)) \approx 25$ 年です。

## 回帰表にまとめ、日本の架空データと比べる

```r
modelsummary(list("例2.10" = m_ex2, "例3.2" = m_ex3, "式7.18" = m_ex7),
  output = "markdown", fmt = 4, gof_map = c("nobs", "r.squared"))
```

教科書と同じく、ここでは括弧内を通常の標準誤差にしています。`vcov = "HC1"` を付けて頑健な標準誤差にすると、例3.2の勤続年数の標準誤差は約0.0031から約0.0038に大きくなります。

日本の架空データで同じ式を推定し、`coef_rename` で係数名をそろえて並べると、次のことが分かります。

- 男性の教育年数の係数は、米国1976年が約0.082、日本（架空）が約0.065
- 経験年数のピークは、米国が約25年、日本（架空）が約29年
- 勤続年数の係数は、米国が約0.032、日本（架空）が約0.0074。日本（架空）の2乗の項はほぼ0
- 決定係数は、米国が約0.441、日本（架空）が約0.339

日本の架空データは、作るときに教育年数の係数を0.07、勤続年数を0.01（2乗の項なし）と決めてあります。推定値はそれに近い値ですが、ぴったり同じではありません。

比べるときは、データの性質の違いに注意します。一方は半世紀前の米国の実際の調査、もう一方は教材用の架空のデータです。また、どちらの係数も「他の条件を一定とした差」です。能力や家庭環境のように観察できない違いを含みうるので、教育の因果効果そのものとは限りません。因果効果の推定は第7部で学びます。

## 卒論・実務での使いどころ

卒論ではまず先行研究の表を再現してから、自分のデータで同じ式を推定し、1つの回帰表に並べて違いを論じます。社内の賃金分析でも、他社や公表された研究の推定と同じ式で比べると、自社の時給体系の特徴を説明しやすくなります。
