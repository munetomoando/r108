## 問い

サイコロを振ると、1〜6の目が同じ確率で出ます。では1万回振って出た目の平均をとると、いくつになるでしょうか。R で乱数を使ってサイコロを振り、回数を増やすと平均がどう落ち着くか（大数の法則）を目で確かめます。第31ステップ以降の標本調査や検定の話は、すべてこの「乱数で何度も試す」方法の上に立っています。

## サイコロを振る：sample()

`sample()` は、与えた値の中から無作為に（ランダムに）取り出す関数です。

```r
set.seed(108)
sample(1:6, 10, replace = TRUE)
```

`1:6` は1から6までの整数で、サイコロの目です。2つ目の引数 `10` は取り出す回数です。`replace = TRUE` は「取り出した目を戻してから次を取り出す」（復元抽出）という意味で、同じ目が何度でも出てよいことを表します。書かないと「戻さない」（非復元抽出）になり、6つより多くは取り出せません。

上のコードを実行すると、2, 5, 3, 6, 5, 5, 5, 3, 2, 6 の10個が出ます。平均は4.2で、10回程度では理論上の平均（下で説明する3.5）からかなり離れることもあります。

## シードで「同じ乱数」を再現する

コンピュータの乱数は、実際には決まった計算で作られる数の列で、出発点を決めると同じ列が出てきます。この出発点の番号を**シード**（種）といい、`set.seed()` で決めます。`set.seed(108)` の直後に `sample()` を実行すると、誰のパソコンでも、何度実行しても同じ目が出ます。分析を他の人が再現できるよう、乱数を使うコードは先頭に必ず `set.seed()` を書きましょう。このアプリでも、乱数を使う小課題は指定のシードを書かないと正解と照合できません。

## 1万回振る：大数の法則

サイコロの目の理論上の平均（**期待値**）は、各目に確率 $1/6$ を掛けて足したものです。

$$\frac{1+2+3+4+5+6}{6} = 3.5$$

振る回数を増やすと、出た目の平均はこの3.5に近づいていきます。これを**大数の法則**といいます。

```r
set.seed(108)
rolls <- sample(1:6, 10000, replace = TRUE)
mean(rolls)
```

1万回の平均は3.5052で、3.5との差は0.01もありません。

## 回数ごとの平均を折れ線にする

「k 回目までの平均」は「k 回目までの合計 ÷ k」です。`cumsum()` は先頭からの合計を順に並べた**累積和**を返すので、`cumsum(rolls) / 1:10000` で1万個の平均を一度に計算できます。`tibble(列名 = 値, …)` は、列名と値を並べて書くと、その場で表（tibble。データフレームの一種）を作る関数です。これで表にして折れ線を描きます。

```r
running <- tibble(n_roll = 1:10000,
                  running_mean = cumsum(rolls) / n_roll)
ggplot(running, aes(x = n_roll, y = running_mean)) +
  geom_line()
```

10回目までの平均は4.2、100回目までは3.54、1,000回目までは約3.42、1万回目までは3.5052です。図の左端では線が大きく上下しますが、右に進むほど3.5のまわりに落ち着きます。`+ scale_x_log10()`（第19ステップ）を足すと、横軸が対数目盛りになり、最初の数十回の揺れが見やすくなります。

## 予告：同じ実験を何度も繰り返す

次の第31ステップで詳しく学ぶ `replicate(回数, 式)` は、同じ式を指定した回数だけ実行し、結果を並べて返します。「10回振って平均をとる」実験を5回繰り返すと、次のようになります。

```r
set.seed(108)
replicate(5, mean(sample(1:6, 10, replace = TRUE)))
```

結果は 4.2, 4.2, 4.0, 3.4, 3.4 です。10回振った平均は、実験のたびにこれだけ揺れます。この実験を1,000回繰り返すと、平均は小さいときで1.9、大きいときで5.0になりました。この揺れ方（標本平均の分布）を調べるのが第31ステップです。

## 正規分布の乱数：rnorm()

サイコロのような「1〜6のどれか」ではなく、連続した値の乱数も作れます。`rnorm(k)` は、平均0・標準偏差1の**正規分布**（左右対称の釣鐘型の分布）から k 個の乱数を作ります。`rnorm(k, mean = 10, sd = 2)` のように平均と標準偏差も指定できます。

```r
set.seed(108)
rnorm(5)
```

## 卒論・実務での使いどころ

卒論のシミュレーションでも、販促の効果を試算する社内資料でも、乱数を使うコードには必ず `set.seed()` を書き、誰が実行しても同じ結果になるようにしておきましょう。
