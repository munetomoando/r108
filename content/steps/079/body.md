## 問い

第76〜78ステップのモデルは、予測したい系列の過去の値だけを使いました。このステップでは、回帰（第37ステップの `lm()`）に**説明変数**を入れて予測します。物価には「毎年この月は高い」という月の効果と、「前年の水準が高ければ今年も高い」という関係がありそうです。この2つで、消費者物価指数の1年先までを予測できるでしょうか。

## データ

`cpi` は、総務省統計局「消費者物価指数」（2025年基準、2026年10月23日に取得）の全国・月次で、2000年1月から2026年9月までの321か月です。総合 `cpi_all` の**原数値**（季節調整をしていない値）を予測します。2025年の平均を100とする指数です。第78ステップと同じく、データの終わりの12か月（2025年10月〜2026年9月）をテスト期間、それより前を訓練期間とします。

## 月ダミー

月を `month(date)` の数のまま回帰に入れると、「1月から12月へ月が進むほど一定の幅で上がる」という直線を当てはめてしまいます。`factor()` で因子にすると、第40ステップで見たように、基準の1月以外の11か月それぞれに0か1のダミー変数が入ります。これを**月ダミー**といいます。

```r
cpi_m <- cpi |>
  mutate(mon = factor(month(date)),
         cpi_lag12 = lag(cpi_all, 12))
train <- filter(cpi_m, date < ymd("2025-10-01"))
m_mon <- lm(cpi_all ~ mon, data = train)
```

`mon9` の係数は「9月は1月より平均でいくら高いか」です。係数は −0.13〜+0.58 の範囲に収まり、物価の季節の動きは小さいことが分かります。一方、切片は約87.5で、訓練期間の1月の平均にすぎません。この25年で物価の水準は大きく変わったので、月ダミーだけのモデルは水準をとらえられません。

## 前年の値を説明変数に加える

12か月前の値 `cpi_lag12` のように、過去の値を説明変数にしたものを**ラグ説明変数**といいます。

```r
m_lag <- lm(cpi_all ~ mon + cpi_lag12, data = train)
```

2000年の12か月は前年の値がなく `NA` なので、`lm()` が自動で除きます。前年の値を使うと、予測できるのは**12か月先まで**です。2026年9月の予測には2025年9月の実績を使い、これは訓練期間に入っています。13か月先を予測するには、前年の値そのものをまず予測しなければなりません。

## テスト期間で比べる

c で RMSE を比べると、月ダミーだけは約13.5、月ダミー＋前年の値は約1.72、ナイーブ予測（2025年9月の100.1を12か月並べる）は約1.29でした。説明変数を加えると大きく改善しますが、それでも**素朴な予測に負けました**。

原因は `cpi_lag12` の係数（約1.24）にあります。1より大きいので、モデルは前年の値に対して3.1〜3.6%ほど高い値を予測しました。訓練期間では、物価の水準が最も高い2022年以降が、ちょうど前年比2.5〜3.3%の物価上昇の時期と重なっていたからです。実際のテスト期間の前年同月比は、2025年10月の2.9%から2026年2月には1.3%まで下がりました。過去の関係がそのまま続くとは限りません。

もう1つの素朴な予測として、前年同月の値をそのまま使う**季節ナイーブ予測**（`test$cpi_lag12`）もあります。これは物価が上がらないと仮定するのと同じで、RMSE は約1.90でした。

なお、`cpi_lag12` の係数は予測のための関係で、「前年の物価が今年の物価を押し上げる」という因果効果ではありません。

## 卒論・実務での使いどころ

売上の予測に月ダミーや前年同月の値を入れるときも、テスト期間で素朴な予測と比べ、予測できるのはラグの長さ（ここでは12か月）までであることを書き添えます。
