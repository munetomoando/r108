## 問い

そらまめマーケットでは、店舗のパート・アルバイトがなかなか集まらないという声が増えています。経営企画部のあなたは、上司から「働く人の割合がこの20年でどう変わったか、県ごとに調べてほしい」と頼まれました。2000〜2020年に就業率が最も上がった県はどこでしょうか。このステップでは、表の形を「横長」と「縦長」の間で変える方法を学びます。

## データを眺める：数字の列名とバッククォート

使うのは、総務省統計局「国勢調査」の時系列データから作った都道府県別の就業率（%）です。就業率は、15歳以上の人のうち働いている人（就業者）の割合です。

```r
labor_wide
names(labor_wide)
```

1行が1つの県で、2000年から2020年まで5年おきの就業率が、`2000`、`2005` … という5つの列に横に並んでいます。Excel や役所の統計表でよく見る形で、これを**横長**（ワイド）の表と呼びます。

列名が数字なので注意が必要です。R では、名前が数字で始まる列は、そのままでは書けません。`` ` ``（バッククォート。キーボードの Shift + @ の位置にあることが多い記号）で囲みます。

```r
labor_wide |>
  select(pref, `2000`, `2020`)
```

`"2000"` と引用符で囲むと「2000という文字」、囲まないと「数の2000」と読まれます。

## 縦長にする：pivot_longer()

横長の表は人が眺めるには便利ですが、「年ごとに集計する」「年を横軸にしてグラフを描く」といった作業には向きません。年が列名の中に隠れていて、値として使えないからです。そこで、1行が「1つの県の1つの年」になるように積み直します。これを**縦長**（ロング）の表と呼びます。tidyr パッケージの `pivot_longer()` を使います。

```r
labor_wide |>
  pivot_longer(cols = -pref, names_to = "year", values_to = "emp_rate")
```

- `cols` … 縦に積む列。`-pref` は「pref 以外のすべての列」という意味です
- `names_to` … 元の列名（2000 など）を入れる新しい列の名前
- `values_to` … 元の値（就業率）を入れる新しい列の名前

結果を見ると、year の列は `<chr>`（文字列）になっています。元が列名だったので、文字として取り出されるのです。年を数として扱えるように、`names_transform` で整数に直しておきましょう。`as.integer()` は値を整数に変える関数です。

```r
labor_long <- labor_wide |>
  pivot_longer(cols = -pref, names_to = "year", values_to = "emp_rate",
               names_transform = list(year = as.integer))
labor_long
```

縦長になると、第6ステップの `group_by()` と `summarise()` がそのまま使えます。例えば、年ごとに47都道府県の就業率の平均を求められます（人口の重みを付けない単純な平均です）。

```r
labor_long |>
  group_by(year) |>
  summarise(mean_rate = mean(emp_rate))
```

## 変化幅を求める：横長のほうが楽なこともある

一方、「2020年の値 − 2000年の値」のように、同じ県の2つの年を引き算するなら、横長のほうが簡単です。列どうしの引き算になるからです。

```r
labor_wide |>
  mutate(change = `2020` - `2000`) |>
  arrange(desc(change))
```

どの県がいちばん上に来るか、実行して確かめてください。

## 横長に戻す：pivot_wider()

縦長の表を横長に戻すのが `pivot_wider()` です。`names_from` に「列名にしたい列」、`values_from` に「中身にしたい列」を指定します。

```r
labor_long |>
  pivot_wider(names_from = year, values_from = emp_rate)
```

元の `labor_wide` と同じ形に戻ったことを確かめてください。`filter()` で年を絞ってから戻せば、報告に使う小さな表も作れます。作業に合わせて縦長と横長を行き来しましょう。目安は「集計やグラフは縦長、人が読む表や列どうしの計算は横長」です。

## 定義を確かめる

この就業率は、就業者 ÷（15歳以上人口 − 労働力状態「不詳」）× 100 で計算しています。「不詳」は、国勢調査で働いているかどうかの回答がなかった人です。2020年は不詳が多く（全国で約11%、東京都では約23%）、分母から除くことは「不詳の人も、回答した人と同じ割合で働いている」と仮定することになります。不詳を分母に含める定義で計算し直すと、1位の県が入れ替わります。公的統計を使うときは、数字の大きさだけでなく、どう定義された数字かを必ず確かめましょう。

## 卒論・実務での使いどころ

役所の統計表や社内の Excel は横長で届くことが多いので、まず `pivot_longer()` で縦長にしてから集計し、報告用の表は `pivot_wider()` で横長に戻すと、作業が速く正確になります。
