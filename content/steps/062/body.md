## 問い

これまでの合成データでは、真の効果（+30万円）が分かっていたので、推定が当たったかどうかを確かめられました。実際のデータでは真の値は分かりません。ただし、同じ訓練について「実験の答え」と「観察データ」の両方がそろった有名な例があります。観察データの手法は、実験の答えを再現できるでしょうか。

## NSW と LaLonde の比較

NSW（National Supported Work Demonstration）は、1970年代半ばの米国で行われた職業訓練の社会実験です。就労経験の乏しい人に仕事と訓練の機会を提供し、参加希望者を無作為に参加者と対照群に分けました。

LaLonde（1986）は、この実験の対照群を使わず、代わりに一般の人の調査（CPS など）から比較群を作り、回帰などの当時の手法で推定しました。その結果、観察データの推定値は実験の値から大きく外れ、手法やモデルによっても大きく変わりました。その後 Dehejia と Wahba（1999、2002）は、同じ問題に傾向スコアを使いました。

このステップでは、causaldata パッケージの2つのデータを使います。

- `nsw`：Dehejia と Wahba が使った NSW の標本。参加者185人と対照群260人
- `cps`：CPS から作った比較群の候補15,992人（全員 `treat = 0`）

年収 `re74`・`re75`・`re78` は、1974・1975・1978年の実質年収（ドル）です。`re78` は訓練が終わった後の年収で、これを結果とします。`re74` と `re75` は、おもに訓練前の年収です（`re75` は一部の人で訓練の期間と重なります）。

## 実験の答え

```r
lm(re78 ~ treat, data = nsw)
```

無作為に割り当てたので、平均の差がそのまま効果の推定値です（第56ステップ）。参加者の1978年の年収は対照群より約1,794ドル高くなりました。これを「答え」として、観察データの推定と比べます。

## 実験の対照群がなかったら

実験の対照群を捨て、NSW の参加者だけを CPS の人々と並べます。2つの表は列名が同じなので、`bind_rows()` で縦につなげます。

```r
nsw_cps <- bind_rows(filter(nsw, treat == 1), cps)
nsw_cps |>
  group_by(treat) |>
  summarise(人数 = n(), 年齢 = mean(age), 年収75 = mean(re75), 年収78 = mean(re78))
```

CPS の人々は平均約33.2歳、1975年の年収は約13,651ドルです。参加者は約25.8歳で、約1,532ドルしか稼いでいません。比べる相手がまったく違うので、単純比較 `lm(re78 ~ treat, data = nsw_cps)` の係数は約−8,498ドルになります。訓練が年収を下げたのではなく、もともと稼ぐ力の違う人どうしを比べた選択バイアスです。

## 傾向スコアで調整する

第61ステップと同じく、年齢・教育年数・人種・婚姻・学位の有無・1974と1975年の年収から傾向スコアを推定し、比較群に $p/(1-p)$ の重みをつけます。

```r
ps_nsw <- glm(treat ~ age + I(age^2) + educ + black + hisp + marr + nodegree + re74 + re75,
              data = nsw_cps, family = binomial)
```

CPS の15,992人のうち14,815人は傾向スコアが0.01未満で、重みはほぼ0になります。参加者に似た一部の人だけが比較に使われ、重みつきの1975年の年収は約1,546ドルと、参加者にそろいます。推定値は約1,315ドルで、単純比較よりずっと実験に近づきます。

ただし、ぴったり一致はしません。同じ変数を回帰に入れて調整すると約794ドル、傾向スコアのモデルに「1974・1975年の年収が0か」のダミーを加えると約1,503ドルです。どの変数をどんな形で入れるかで、推定値は数百ドル動きます。

## 教訓

観察データの調整がうまくいくのは、参加が観察できる変数だけで説明でき（条件付き独立）、参加者に似た比較相手が十分にいる（共通サポート）ときです。NSW では実験の答えがあるので「近づいた」と判断できますが、ふつうの研究ではそれができません。推定値を1つだけ示すのではなく、モデルを変えても結論が変わらないかを示すことが大切です。

## 卒論・実務での使いどころ

卒論で観察データから制度の効果を推定するときは、単純比較・回帰・傾向スコアの結果を並べ、比較群が処置群とどれだけ違うか（バランス表）も示します。
