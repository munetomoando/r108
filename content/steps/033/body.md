## 問い

ある調査で、男性の平均時給が女性より200円ほど高かったとします。この差は、男女の賃金に本当に違いがあることを示しているのでしょうか。それとも、たまたまその人たちを選んだから生じた偶然の差なのでしょうか。**仮説検定**と**p値**で、この問いに答える方法を学びます。

## 使うデータ

`wage` は教材用に乱数で作った**架空の**賃金調査（3,000人）です。このステップでは主に、そのうち卸売業・小売業の300〜999人規模の企業で働く77人（`retail`。男性36人・女性41人）を使います。そらまめマーケットのような小売企業で、少人数の社内調査をした場面だと考えてください。

```r
retail |>
  group_by(female) |>
  summarise(m = mean(hourly_wage), n = n())
```

男性の平均は約2,080円、女性は約1,867円で、差は約214円です。

## 「差がない」と仮定して考える

仮説検定では、まず「母集団では男女の平均時給は等しい」という仮説を立てます。これを**帰無仮説**といいます。そのうえで「もし帰無仮説が正しいなら、今回のような差はどれくらい出やすいか」を調べます。偶然では滅多に出ない差なら、帰無仮説を疑います。

`t.test()` に `時給 ~ 男女` の形の式を渡すと、2つのグループの平均の差を検定します。

```r
tt <- t.test(hourly_wage ~ female, data = retail)
tt$p.value
```

p値は約0.19です。**p値**とは、帰無仮説が正しいと仮定したとき、実際と同じかそれ以上に大きな差が偶然に出る確率です。

## 置換検定：偶然の差を自分で作る

t検定の計算は式の中に隠れています。同じ考え方を、シミュレーションで目に見える形にしたのが**置換検定**です。男女で時給の分布に違いがないなら、`female` の印を無作為に付け替えても、平均の差は同じような大きさになるはずです。

```r
set.seed(108)
perm_diff <- replicate(1000, {
  f <- sample(retail$female)
  mean(retail$hourly_wage[f == 0]) - mean(retail$hourly_wage[f == 1])
})
```

`sample()` にベクトルを1つだけ渡すと、中身を並べ替えます。男性36人・女性41人という人数はそのままで、誰が男性かだけが無作為に変わります。1000個の差は −522円から +578円まで散らばり、0を中心とした山になりました。

実際の差を、この分布と比べます。`pull()` は表から1つの列をベクトルとして取り出す関数、`abs()` は絶対値です。

```r
means <- retail |> group_by(female) |> summarise(m = mean(hourly_wage)) |> pull(m)
obs_diff <- means[1] - means[2]
mean(abs(perm_diff) >= abs(obs_diff))
```

偶然の差のうち、実際の差（約214円）以上に大きかったものは1000回中197回、割合で約0.20でした。t検定のp値とほぼ同じです。214円の差は、偶然でも5回に1回ほどは出る大きさなのです。

## p値の正しい読み方

p値は「帰無仮説が正しい確率」でも「差が偶然である確率」でもありません。帰無仮説を正しいと**仮定したうえで**計算した、データの出やすさです。また、p値が大きくても「差がない」ことの証明にはなりません。実はこのデータは、作るときに女性の時給を低めに設定してあります（他の条件が同じなら約11%低い）。77人では人数が少なく、その差を偶然と見分けられなかったのです。

3,000人全体で同じことをすると、差は約342円で、`t.test()` のp値は `< 2.2e-16`（0.0000…と0が15個以上続く値）と表示されます。置換検定では、1000回の並べ替えで生じた差は最大でも約110円で、実際の差以上になったことは1回もありませんでした。このとき計算上のp値は0ですが、「p値が0、つまり偶然の可能性はまったくない」と読んではいけません。言えるのは「1000回の並べ替えでは1回も起きなかった」ことだけなので、「p < 0.001」と書きます。並べ替えの回数を増やせば、もっと小さな値まで調べられます。

## 卒論・実務での使いどころ

社内アンケートで部署間の差が見えたときも、卒論で男女差を論じるときも、差の大きさとp値を並べて示し、p値が大きい場合は「差がない」ではなく「この人数では差があるとは言えない」と書きましょう。
