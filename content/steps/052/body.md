## 問い

論文では、先行研究を「(Card と Krueger 1994)」のように引用し、末尾に参考文献の一覧を付けます。本文で図や表に触れるときは「図 1 のように」と番号で指します。これを手で書くと、図を1つ足しただけで番号がずれ、文献リストとの食い違いも起きます。このステップでは、Quarto に引用と番号を自動で付けさせます。

## 文献ファイルを用意する

文献の情報は、BibTeX（ビブテック）形式のファイル `references.bib` にまとめます。1件はたとえば次のように書きます。

```bibtex
@article{card1994,
  author  = {Card, David and Krueger, Alan B.},
  title   = {Minimum Wages and Employment: A Case Study of the Fast-Food
             Industry in New Jersey and Pennsylvania},
  journal = {American Economic Review},
  year    = {1994},
  volume  = {84},
  number  = {4},
  pages   = {772--793}
}
```

先頭の `@article` は文献の種類（本なら `@book`）、すぐ後の `card1994` が**キー**です。キーは本文から文献を呼び出すための名前で、「著者名＋年」にすると覚えやすくなります。著者が複数いるときは `and` でつなぎ、日本語の著者は `{川口, 大司 and 森, 悠子}` のように「姓, 名」で書きます。

1. 見本 [references.bib](local/references.bib) をダウンロードし、`paper.qmd` と同じフォルダに移します。最低賃金に関する4件の文献が入っています。
2. `paper.qmd` の YAML ヘッダに次の1行を加えます。

```yaml
bibliography: references.bib
```

見本の書誌情報は、卒論で使う前に必ず原典（論文の1ページ目や出版社のページ）で確かめます。Google Scholar などの「引用」から BibTeX をコピーできますが、誤りが混じることがあるので、そのまま信じないようにします。

## 本文で引用する

本文では、キーの前に `@` を付けて引用します。

```markdown
最低賃金の引き上げが雇用に与える影響は、長く議論されてきました [@card1994; @neumark2008]。
@cengiz2019 は、最低賃金のすぐ下にいた仕事がどれだけ減ったかを数えました。
```

角かっこで囲むと「(Card と Krueger 1994; Neumark と Wascher 2008)」のような括弧付きの引用、囲まないと「Cengiz ほか (2019)」のように文の主語になる形で出力されます。複数の文献は `;` で区切ります。引用した文献だけが、文書の末尾に一覧として自動で並びます。一覧の位置を決めたいときは、最後に次のように書きます。

```markdown
## 参考文献 {.unnumbered}

::: {#refs}
:::
```

## 図表を番号で参照する

ステップ51で付けたラベルの前に `@` を付けると、図表の番号に置き換わります。

```markdown
@fig-scatter は2024年の最低賃金と平均時給の散布図です。
年ごとの平均を @tbl-year に示します。
```

Render すると、`@fig-scatter` は「図 1」、`@tbl-year` は「表 1」になります。図を前に1つ足しても、番号は自動で付け直されます。

## うまくいかないとき

Word を開いて、次の2つが残っていないか確かめます。

- 「?@fig-scatter」：相互参照が解決していません。ラベルの綴りと、`fig-` や `tbl-` で始まっているかを確かめます。図のチャンクで図を表示していない（`p <- ggplot(...)` と代入しただけ）ときにも起きます。
- 「(cengiz2018?)」のような太字の「キー?」：そのキーが `references.bib` にありません。綴りを比べます。

確認スクリプトは、文献が3件以上引用されているか、`@fig-` と `@tbl-` の参照があるかを `paper.qmd` で調べ、さらに Word に出力した中身を読んで、「?@」や「キー?」が残っていないこと、文献の一覧が3件以上あることを確かめます。

## 卒論・実務での使いどころ

卒論では、読んだ文献をその日のうちに `references.bib` に加え、本文では必ず `@キー` と `@fig-`・`@tbl-` で書いておくと、提出直前に章を入れ替えても引用と番号が崩れません。
