## 問い

第8部の総合演習です。あなたは県の政策評価の担当者として、2019年に始まった最低賃金の特別引上げ（架空の政策）が若年の就業率をどれだけ下げたかを報告します。第64〜67ステップのパネルデータ `mw` を使い、差の差分析・イベントスタディ・プラセボ・頑健性の確認をひとそろい行い、結論を3文にまとめます。

## データと「答え」

`mw` は47県×2012〜2024年（611行）の架空のパネルです。12県（`treated = 1`）で2019年から特別引上げが行われ、`post` は2019年以降で1になります。教材用の合成データなので、若年就業率への真の効果は決めてあります（引上げの年に −0.5、翌年に −0.8、2年目以降は −1.0 ポイント）。成人就業率には効果がありません。また、2020年には全県で一律に就業率が2ポイント下がるように作ってあります。

実際の研究では真の値は分かりません。この演習では、推定がどれだけ真の値に近いかも確かめられます。

## 報告の4点セット

政策の効果を差の差分析で報告するときは、次の4つをそろえます。

| 小課題 | 何をするか | 何を示すか |
| --- | --- | --- |
| a | 二元固定効果の差の差 | 効果の大きさ（1つの数）と信頼区間 |
| b | イベントスタディの図 | 効果の時間の変化と、処置前に差が動いていないか |
| c | プラセボ | 効果が出ないはずの結果では効果が出ないか |
| d | 頑健性 | 分析の選び方を変えても結論が変わらないか |

a は第66ステップ、b は第67ステップと同じ式です。どちらも県と年の固定効果を入れ、同じ県の誤差は年をまたいで相関しやすいので、県でクラスタした標準誤差を使います（第65ステップ）。

```r
m_did <- feols(youth_emp_rate ~ treated:post | pref_code + year,
             data = mw, cluster = ~pref_code)
```

イベントスタディの係数は、どれも基準年（2018年、`rel_year = -1`）と比べた処置県と対照県の差の変化です。処置前の係数が0の近くに並んでいれば、引上げの前は2つのグループが同じように動いていたことになります。

## プラセボと頑健性

c のプラセボでは、成人（25〜64歳）の就業率に同じ回帰を当てはめます。最低賃金に近い賃金で働く人は若年に多いので、成人には大きな影響がないはずです。もし成人でも同じくらいの「効果」が出たら、引上げではなく、対象県だけに起きた別の出来事（景気の悪化など）を拾っている疑いがあります。

d の頑健性では、推定に使う期間を変えます。RDD では帯域幅を変えましたが、差の差分析では次のような選び方が結論を左右しうるので、ここを変えて確かめます。

- **特別な年を除く**：2020年は全国で就業率が大きく下がりました。年の固定効果は全県に共通の変化を取り除きますが、その年のショックが処置県と対照県に違う大きさで及んでいれば偏ります。2020年を除いても結論が変わらないかを見ます
- **期間を短くする**：処置の前後3年ずつ（2016〜2022年）に絞ると、遠い年の動きに左右されにくくなります

```r
filter(mw, between(year, 2016, 2022))
```

ただし、期間を短くすると「処置後の何年分を平均した効果か」も変わります。効果が年とともに大きくなる場合、処置後の年が少ないほど平均した効果は小さく出ます。推定値が少し動いたときは、b の図と合わせて理由を考えましょう。

## 結論の書き方

結論は、効果の大きさを数字と信頼区間で示し、プラセボと頑健性の結果を添え、最後に仮定を書きます。差の差分析の仮定は、引上げがなかったら処置県と対照県の若年就業率が同じように推移したという平行トレンドです。処置前の係数が0に近いことやプラセボで効果が出ないことは、この仮定を支える材料にはなりますが、仮定が正しいことの証明にはなりません。「引き下げた」と断定せず、「平行トレンドの仮定のもとで〜と推定される」と書きます。

## 卒論・実務での使いどころ

卒論で制度の効果を差の差分析で示すときは、本文の表に主な推定値を、図にイベントスタディを置き、プラセボと期間を変えた結果を付録の表にまとめます。
