## 問い

政府から現金の給付を受けた世帯は、その政府をより支持するようになるでしょうか。ウルグアイの貧困対策の所得移転（PANES）では、所得の指標が基準より低い世帯が対象になりました。第70ステップの回帰不連続デザインを実データに使い、基準の前後で政府への支持が変わるかを調べます。

## データ

causaldata パッケージの `gov_transfers` は、Manacorda、Miguel、Vigorito（2011）の研究のデータで、`?gov_transfers` の説明によれば、もともと基準の近くの世帯だけに絞ってあります。1,948世帯について、次の列を使います。

- `Income_Centered`：所得の指標から基準の値を引いたもの。負なら対象（−0.02〜0.02）
- `Participation`：給付を受けたか（1＝受給）
- `Support`：政府への支持の指標（0、0.5、1 の3つの値）

このデータでは、`Income_Centered` が負の1,127世帯は全員が受給し、正の821世帯は誰も受給していません。受給が基準だけで決まるので、第70ステップの奨学金と同じ形で分析できます。第70ステップと違い、処置を受けるのは閾値の左側です。

論文の要旨では、受給世帯は非受給世帯より、現政権を支持する確率が11〜13ポイント高く、その効果は給付の終了後も続いたと報告されています。ここでの `Support` は3段階の指標で、推定の方法も論文と同じではないので、値を直接は比べません。

## 図と局所線形回帰

```r
bins_gt <- transfers |>
  mutate(bin = floor(Income_Centered * 500) / 500 + 0.001) |>
  group_by(bin) |>
  summarise(support = mean(Support), 世帯数 = n())
```

基準の左側（受給世帯）では支持の平均がおおむね0.8〜0.9、右側ではおおむね0.65〜0.8 に並びます。ただし点のばらつきは大きく、第70ステップの合成データほどはっきりした段差ではありません。実データの図はこのように読みにくいのがふつうです。

段差は第70ステップと同じ形の回帰で測ります。`Income_Centered` はすでに基準からの距離なので、そのまま使えます。

```r
m_gt <- lm(Support ~ Participation * Income_Centered, data = transfers)
confint(m_gt)
```

`Participation` の係数が、基準ちょうどでの支持の段差です。`confint()` で信頼区間も確かめましょう。

## 帯域幅の感度

このデータはもともと基準の前後0.02以内なので、帯域幅は0.02より狭くすることしかできません。0.005 まで狭めると、使う世帯は462になり、推定値の標準誤差は全世帯のときの約2倍になります。狭い帯域幅で推定値が変わったとき、それが「基準に近い世帯では効果が小さい」ことによるのか、単に人数が減ってぶれただけなのかは、信頼区間と合わせて読む必要があります。

## 仮定の確認

効果と読むための仮定は第70ステップと同じです。仮定そのものは検定で証明できませんが、支える材料は集められます。1つは、受給で変わるはずのない世帯の特徴が、基準で段差を持たないかを見ることです。

```r
lm(Age ~ Participation * Income_Centered, data = transfers) |> confint()
```

全世帯で推定すると、世帯の平均年齢の段差は約−1.3歳（95%信頼区間 約−3.9〜1.4）、平均教育年数の段差は約0.11年（約−0.18〜0.40）で、どちらもはっきりした段差はありません。もう1つは世帯数の分布です。0.002刻みのビンの世帯数は、基準の左側でおおむね100〜145、右側でおおむね70〜90 と、左側の方が全体に多くなっています。基準のすぐ左にだけ集まっているわけではありませんが、このデータだけでは操作がなかったとは言い切れません。

## 卒論・実務での使いどころ

実データで RDD を使うときは、ビン平均の図、局所線形回帰、帯域幅を変えた表に加えて、処置で変わらないはずの変数の段差と、閾値の前後の人数も示します。
