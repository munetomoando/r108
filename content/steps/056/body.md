## 問い

第55ステップでは、自分で訓練に参加するかどうかを選ぶと、観察できる差に**選択バイアス**が混ざり、効果の符号まで逆に見えることを確かめました。では、参加者を**抽選で**決めたら、何が変わるのでしょうか。

## ランダム化比較試験（RCT）

参加を希望した人を、くじ引きで「訓練を受ける群（**処置群**）」と「受けない群（**対照群**）」に分けて比べる方法を、**ランダム化比較試験**（RCT, randomized controlled trial）といいます。

使うのは架空のデータ `rct`（1,000人、単位は万円）です。参加希望者を抽選で500人ずつに分けたという設定です。列は `treat`（処置群なら1）、訓練の前に決まっている `age`・`female`・`educ_years`・`prior_earn`（前年収入）、訓練後の年収 `earn_post` です。教材用に乱数で作ったデータで、作るときに訓練の真の効果を **+30万円** と決めてあります。

抽選で決めると、どちらの群に入るかは本人の前年収入や意欲と関係がありません。そのため、もし誰も訓練を受けなかった場合の年収 $Y(0)$ の平均は、2つの群で（平均的には）等しくなります。

$$E[Y(0)\mid D=1] = E[Y(0)\mid D=0]$$

第55ステップの式で、選択バイアスの項が0になるということです。こうして、観察できる差がそのまま平均処置効果の推定値になります。

## 平均の差と回帰

```r
mean(rct$earn_post[rct$treat == 1]) - mean(rct$earn_post[rct$treat == 0])
```

処置群の平均は約457.9万円、対照群は約423.1万円で、差は約34.8万円です。

同じ差は回帰でも求められます。

```r
m_rct <- lm(earn_post ~ treat, data = rct)
coef(m_rct)
confint(m_rct)
```

説明変数が0か1のダミー変数だけの回帰では、切片が対照群の平均（約423.1）、`treat` の係数が「処置群の平均 − 対照群の平均」（約34.8）になります。回帰を使う利点は、標準誤差（約8.0）や信頼区間（約19.0〜50.5万円）も同時に出ることです。

推定値34.8万円は、真の効果30万円とは一致しません。1,000人を1回抽選しただけなので、たまたま処置群に年収の高くなりやすい人が少し多く入った、といった偶然の誤差が残るためです。それでも、95%信頼区間は30万円を含んでいます。抽選をくり返せば、推定値は平均すると30万円になります。

## バランスチェック

抽選がきちんと行われたかは、訓練の前から決まっている特徴（**共変量**）の平均を群ごとに比べて確かめます。これを**バランスチェック**といいます。

```r
rct |>
  group_by(treat) |>
  summarise(人数 = n(), 年齢 = mean(age), 女性比率 = mean(female),
            教育年数 = mean(educ_years), 前年収入 = mean(prior_earn))
```

前年収入の平均は処置群で約272万円、対照群で約270万円、女性比率は約0.45と約0.45で、ほぼ同じです。年齢は約39.3歳と約38.2歳で、約1歳違います。`t.test(age ~ treat, data = rct)` で確かめると p 値は約0.14で、抽選の偶然として珍しくない差です。

共変量がまったく同じになることは期待しません。大事なのは、偏りが偶然の範囲に収まっていることです。もし前年収入の平均が大きく違っていたら、抽選の手続きに問題があった（たとえば担当者が「見込みのある人」を処置群に回した）ことを疑います。

バランスチェックで比べるのは、**処置の前**に決まっている変数だけです。訓練後の年収のように、処置によって変わりうる変数を比べても、抽選がうまくいったかどうかは分かりません。

## RCTの限界

RCT は選択バイアスを取り除く最も確実な方法ですが、使える場面は限られます。費用がかかる、希望者の一部に訓練を受けさせないことが倫理的に許されない場合がある、割り当てられても参加しない人がいる、などの問題があります。また、推定できるのは「参加を希望した人」についての効果です。そこで第59ステップ以降では、観察データで効果を推定する方法を学びます。

## 卒論・実務での使いどころ

ネット通販のクーポンや広告の A/B テスト（第86〜88ステップ）も RCT です。結果を報告するときは、平均の差と信頼区間に加えて、必ずバランスチェックの表を添えましょう。
