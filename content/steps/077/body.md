## 問い

第76ステップでは、1か月前の値だけを使う AR(1) で鉱工業生産を予測しました。2か月前、3か月前の値も使えば、もっと良いモデルになるでしょうか。このステップでは、次数の違うモデルを **AIC** で比べて1つを選び、12か月先までの予測を**予測区間**つきで図にします。第81ステップの総合演習で使う形を、ここでひととおり身につけます。

## 使うデータ

`iip` は、経済産業省「鉱工業生産・出荷・在庫指数」（2020年基準）の鉱工業総合の月次の値で、2026年10月24日に取得した時点の2018年1月〜2026年8月の104か月です。setup で、季節調整済指数 `iip_sa` を時系列にした `y`（`ts(iip$iip_sa, start = c(2018, 1), frequency = 12)`）を作ってあります。季節調整済指数は年間補正でさかのぼって改定されるので、結果は取得時点のデータによるものです。

## ARIMA の次数

`arima()` の `order = c(p, d, q)` の3つの数を**次数**といいます。

- `p` … AR の次数。何か月前までの自分の値を使うか。AR(2) は1か月前と2か月前の値を使います
- `d` … 階差をとる回数。`d = 1` なら前月差にしてから当てはめます
- `q` … MA の次数。MA（moving average、移動平均）は、過去の月の「予測が外れた分（偶然の動き）」を今月の説明に使う部分です。ARMA(1,1) は `c(1, 0, 1)` です

次数を増やすほど、モデルはデータに細かく合わせられます。しかし、たまたまの動きにまで合わせると、将来の予測はかえって悪くなります（過学習）。

## AIC で比べる

**AIC**（赤池情報量規準）は、当てはまりの良さと、推定する係数の数を両方考える指標です。

$$\text{AIC} = -2 \times \text{対数尤度} + 2 \times \text{推定する値の数}$$

対数尤度は当てはまりの良さで、大きいほど良いモデルです。係数を1つ増やすと2の罰が加わるので、当てはまりがそれ以上良くならない限り AIC は増えます。**AIC が小さいモデルほど良い**と判断します。`AIC()` にモデルを渡すと計算できます。

```r
m1 <- arima(y, order = c(1, 0, 0))
m2 <- arima(y, order = c(2, 0, 0))
c(AIC(m1), AIC(m2))
```

a の4つのモデルでは、AR(1) が約492.2で最も小さく、AR(2) と ARMA(1,1) が約494.0、AR(3) が約495.7でした。2か月前以前の値や MA の部分を足しても、当てはまりはほとんど良くなりません。そこで b・c では AR(1) を使います。

階差をとる ARIMA(1,1,0)（`order = c(1, 1, 0)`）の AIC は約489.5です。第81ステップでは、AR(1) と ARIMA(1,1,0) の AIC を並べて比べます。ただし、階差をとるモデルは前月差の系列で当てはまりを測るので、`d` の違うモデルどうしの AIC の差は目安にとどめます。AIC は手元のデータへの当てはまりを測るもので、将来の予測の当たり具合は、第78ステップのようにテスト期間で確かめます。

## 予測区間

`predict(m1, n.ahead = 12)` は、12か月先までの予測値 `$pred` と標準誤差 `$se` を返します。**95%予測区間**は、予測値 ∓ 1.96 × 標準誤差です。モデルが正しければ、実際の値が約95%の確率でこの範囲に入ります。

```r
fc_raw <- predict(m1, n.ahead = 12)
fc <- tibble(date = seq(ymd("2026-09-01"), by = "month", length.out = 12),
             pred = as.numeric(fc_raw$pred),
             se = as.numeric(fc_raw$se),
             lower = pred - 1.96 * se,
             upper = pred + 1.96 * se)
```

2026年9月の予測値は約102.3で区間は約97.4〜107.1、2027年8月は約104.5で区間は約94.0〜115.0です。先の月ほど偶然の動きが積み重なるので、区間は広がります。予測値が少しずつ上がるのは、AR(1) の予測が平均（約105.4）に近づくからです。

図では、実績を線、予測区間を `geom_ribbon()` の帯、予測値を破線で重ねます。`geom_ribbon()` は、`ymin` から `ymax` までを塗りつぶす層です。データの違う層を重ねるので、`ggplot()` を空にして層ごとに `data =` を指定します。

```r
recent <- filter(iip, date >= ymd("2022-01-01"))
ggplot() +
  geom_line(data = recent, aes(x = date, y = iip_sa)) +
  geom_ribbon(data = fc, aes(x = date, ymin = lower, ymax = upper), alpha = 0.3) +
  geom_line(data = fc, aes(x = date, y = pred), linetype = "dashed")
```

予測区間は「モデルが正しく、過去と同じような偶然の動きが続けば」という前提での幅です。2020年のような急なショックまでは表していません。また、よく当たる予測であっても、何が生産を動かしたかという因果関係は分かりません。

## 卒論・実務での使いどころ

予測を報告するときは、1つの数字だけでなく予測区間を帯で示すと、どれくらい外れうるかが読み手に伝わり、在庫や生産の計画で上下の幅を見込めます。
