## 問い

分析が終わっても、R の出力をそのまま貼り付けた表や、画面の大きさのまま保存した図は、論文には載せられません。変数名が英語のまま、桁がばらばら、図の文字がつぶれている、といった問題が起きるからです。論文にそのまま載せられる表と図にするには、何を整えればよいでしょうか。

## 記述統計表：datasummary_skim

論文の最初の表は、ふつう記述統計表です。modelsummary パッケージの `datasummary_skim()` にデータフレームを渡すと、列ごとの要約統計量を1行ずつ並べた表ができます。

```r
mroz |> select(inlf, hours, wage) |> datasummary_skim(output = "markdown")
```

そのままだと、見出しが英語（Unique、Missing Pct.、Mean など）で、Histogram（小さなヒストグラムの画像）の列も付きます。この列は HTML などに書き出すと小さな図になりますが、このアプリの画面では画像の場所を示す文字が出るだけです。論文に載せる列だけを、日本語の見出しで選びましょう。

```r
mroz |>
  select(労働参加 = inlf, 時給 = wage, 教育年数 = educ) |>
  datasummary_skim(output = "markdown", fmt = 2,
                   fun_numeric = list(観測数 = N, 平均 = Mean, 標準偏差 = SD,
                                      最小 = Min, 最大 = Max))
```

ポイントは3つです。

- `select(新しい名前 = 元の名前)` で、表に載せる変数を選びながら日本語の名前に変える
- `fun_numeric` に「見出し = 関数」のリストを渡して、列の統計量を選ぶ。`N`・`Mean`・`SD` などは modelsummary の関数で、欠損値（NA）を除いて計算する
- `fmt = 2` で桁をそろえる

観測数の列を入れておくと、欠損値に気づけます。753人のうち時給の観測数は428で、働いている女性にしか時給がないこと（第47ステップ）が表から読み取れます。

## 回帰表：星印と注記

回帰表は第44ステップの `modelsummary()` で作ります。論文では、係数が統計的に有意かどうかを星印（*）で示すことが多く、`stars = TRUE` で付けられます。

```r
modelsummary(list("線形確率モデル" = lpm, "ロジット" = logit),
  output = "markdown", vcov = "HC1", fmt = 4, stars = TRUE,
  gof_map = c("nobs", "r.squared"),
  notes = "括弧内は不均一分散に頑健な標準誤差（HC1）。データは Mroz (1987)。")
```

表の下に「+ p < 0.1, * p < 0.05, ** p < 0.01, *** p < 0.001」という星印の説明が自動で付きます。6歳未満の子どもの数の係数は、線形確率モデルで約 −0.2618、ロジットで約 −1.4434 で、どちらも *** です。線形確率モデルは誤差の分散が説明変数によって変わる形になっているので、頑健な標準誤差（`vcov = "HC1"`）で報告するのが一般的です。

星印は便利ですが、第35ステップで学んだとおり「有意」は「重要」と同じではありません。本文では、係数の大きさ（子ども1人で確率が約26%ポイント下がる）を言葉で説明しましょう。ロジットの列には決定係数が出ません。ロジットは最小二乗法ではないので、ふつうの決定係数がないからです。

## 図を論文のサイズで保存する

`ggsave()` の幅と高さは、何も指定しないとインチ単位です。論文では cm で考えたほうが分かりやすいので、`units = "cm"` を付けます。

```r
ggsave(out_png, plot = p, width = 16, height = 10, units = "cm", dpi = 300)
```

A4 の用紙の左右に2.5cmずつ余白をとると、本文の幅は約16cmです。この幅で保存すると、Word に貼ったときに縮小されず、文字の大きさが保存したときのまま保たれます。`dpi`（1インチあたりの点の数）は解像度で、印刷用には300が目安です。16cm×10cm を300 dpi で保存すると、画像は1,889×1,181ピクセルになります。

図を大きく保存して Word で縮めると、軸の文字が小さくなりすぎます。逆に、画面用に小さく作って引き伸ばすと、ぼやけます。最初から載せるサイズで保存するのが確実です。

## 卒論・実務での使いどころ

卒論では、表1に記述統計、表2に回帰の結果、図は本文の幅で保存したもの、という形が基本です。社内の報告資料でも、見出しを日本語にし、注記で出所と標準誤差の種類を示した表は、そのまま会議資料に使えます。
