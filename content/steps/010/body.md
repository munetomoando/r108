## 問い

経営企画部に、ネット通販の担当者から商品マスタが届きました。商品マスタとは、商品ごとのIDや分類、価格をまとめた台帳のことです。同じ中身が CSV と Excel の2つの形式で届いています。上司の最初の質問は「通販の商品は何カテゴリあるの？」です。このステップでは、2つの形式のファイルを正しく読み込む方法を学びます。

## CSV を型を指定して読む：col_types

CSV は、値をカンマで区切って並べただけの文字のファイルです。第3ステップで使った `read_csv()` は、各列の中身を見て「これは数値」「これは文字」と型を推測します。

```r
products <- read_csv("data/ec_products.csv", show_col_types = FALSE)
glimpse(products)
```

`product_id` は "00002" のように先頭に0の付いた5桁の文字列です。今の readr は、0で始まる値を文字列のまま読むので、0は消えません。ただし推測に任せきりにすると、データの形が少し変わっただけで型が変わることがあります。そこで、仕事では型を自分で指定して読むのが安全です。そのための引数が `col_types` です。

```r
products <- read_csv("data/ec_products.csv", col_types = "ccdd")
```

`"ccdd"` は、1列目から順に1文字ずつ型を表します。`c` は文字列（character）、`d` は数値（double、小数も扱える数）です。もし `product_id` を数値（`d`）として読むと、"00002" は 2 になり、商品IDとして使えなくなります。商品IDや郵便番号のように「数字が並んでいるが計算はしない値」は、文字列として読むのが原則です。

## Excel を読む：read_excel() とシートの指定

Excel のファイル（.xlsx）は readxl パッケージの `read_excel()` で読みます。Excel のファイルには複数のシートが入っていることがあるので、まず `excel_sheets()` でシートの名前を確かめましょう。

```r
excel_sheets("data/ec_products.xlsx")
read_excel("data/ec_products.xlsx")
```

`read_excel()` は、シートを指定しないと1枚目を読みます。このファイルの1枚目は「説明」のシートで、データの説明が書いてあるだけです。商品の表を読むには、引数 `sheet` でシートの名前を指定します。

```r
products_x <- read_excel("data/ec_products.xlsx", sheet = "商品一覧")
products_x
```

表示された `product_id` の列を見てください。CSV と違い、`<dbl>`（数値）になっていて、先頭の0が消えています。

## 消えた0を戻す：str_pad()

これは、誰かが Excel でファイルを開き、商品IDを数値として保存し直したためです。0はファイルの中ですでに消えています。`read_excel()` でも `col_types` で型を指定できますが、文字列として読んでも "2" になるだけで、0は戻りません。

```r
read_excel("data/ec_products.xlsx", sheet = "商品一覧",
           col_types = c("text", "text", "numeric", "numeric"))
```

`read_excel()` の `col_types` は、`"text"`（文字列）や `"numeric"`（数値）を `c()` で並べて指定します。`read_csv()` の書き方とは違うので注意しましょう。

消えた0は、stringr パッケージの `str_pad()` で戻します。`str_pad(x, width = 5, pad = "0")` は、文字列が5文字になるまで左側に "0" を足します。

```r
str_pad(c("2", "10", "12345"), width = 5, pad = "0")
```

ID の桁数が決まっているときだけ使える方法です。元の桁数が分からないときは、ファイルを作った人に確かめる必要があります。

## カテゴリの数を数える

正しく読めたら、上司の質問に答えましょう。第7ステップの `count()` を使うと、カテゴリごとの商品数が分かります。

```r
count(products, category)
```

結果の表の行数が、カテゴリの数です。何行になるか、実行する前に予想してから確かめてみてください。

## 卒論・実務での使いどころ

ID や郵便番号、市区町村コードのような「数字の並んだ文字列」は、読み込みで先頭の0が消えやすいので、読んだ直後に `glimpse()` で型を確かめる習慣をつけましょう。
