## 問い

販促の予算を決める会議で、上司が言いました。「売上の8割は上位2割の顧客が生む、とよく聞く。うちの通販ではどうなのか。大事な顧客は誰なのか」。顧客5,000人を購買の記録で分け（**RFM 分析**）、上位2割の顧客が売上の何割を占めるかを求めます。

## R・F・M を計算する

RFM 分析は、顧客を次の3つの指標で見る方法です。

- **R**（Recency、最新性）… 最後に買ってから何日たったか。小さいほど良い
- **F**（Frequency、頻度）… 何回注文したか。多いほど良い
- **M**（Monetary、金額）… いくら使ったか。多いほど良い

注文明細を顧客ごとに集計して、1人1行の表にします。基準日は2025年12月31日です。

```r
rfm <- od |>
  group_by(customer_id) |>
  summarise(recency = as.integer(ymd("2025-12-31") - max(order_date)),
            frequency = n_distinct(order_id),
            monetary = sum(sales)) |>
  inner_join(select(customers, customer_id, channel, rank), by = "customer_id")
```

日付どうしの引き算は日数になり、`as.integer()` で整数にします。顧客マスタにない顧客（退会済み）は分析の対象外なので、`inner_join()` で5,000人に絞ります。中央値は、R が34日、F が10回、M が約2.6万円でした。

## 5段階の点数を付ける：ntile

`ntile(x, 5)` は、x の小さい順に人数がほぼ等しい5つの組に分け、1〜5の番号を付けます。5,000人なら1組1,000人です。

```r
rfm_s <- rfm |>
  mutate(r_score = ntile(desc(recency), 5),
         f_score = ntile(frequency, 5),
         m_score = ntile(monetary, 5))
```

点数は「5が良い顧客」にそろえます。R は日数が少ないほど良いので、`desc()` で向きを逆にします。m_score ごとに平均をとると、m_score = 5 の組は平均で約21回注文し、最後の注文から平均約33日です。m_score = 1 の組は約4回、約184日で、しばらく買っていない人が多くなります。3つの点数を組み合わせると、「R は高いが F は低い＝最近来た新しい顧客」「F は高いが R が低い＝離れかけた常連」のように、顧客の状態に合わせた手を考えられます。

## 上位2割のシェア：累積比率

売上の多い順に並べ、上から何人目までで売上の何割になるかを計算します。`row_number()` は、並べた後の行に1, 2, 3, … と番号を返します。

```r
pareto <- rfm |>
  arrange(desc(monetary)) |>
  mutate(cum_cust = row_number() / n(),
         cum_share = cumsum(monetary) / sum(monetary))
ggplot(pareto, aes(x = cum_cust, y = cum_share)) +
  geom_line()
```

図は左上にふくらんだ曲線になり、ふくらみが大きいほど売上が一部の顧客に偏っています。上位20%（1,000人）の売上シェアは約43%、上位50%で約77%、上位80%で約96%でした。「上位2割が8割」というほど極端ではなく、残りの8割の顧客も売上の半分以上を生んでいます。80:20 はあくまで目安で、業種やデータで違うので、自社の数字で確かめることが大切です。

## 読むときの注意

- **期間の長さ**：2024年の途中や2025年に登録した顧客は、買える期間が短いので M が小さくなりがちです。登録時期をそろえて比べたいときは、第85ステップのコホート分析を使います
- **会員ランクとの違い**：m_score = 5 の1,000人のうち、会員ランクがゴールドの人は321人でした。ランクの基準と実際の購買は一致していません
- **因果は分からない**：紹介経由の顧客は37%が m_score = 5 に入りますが、紹介で来たから多く買うのか、多く買う人が紹介で来やすいのかは区別できません。上位顧客への販促の効果も、無作為に分けて確かめます（第86〜88ステップ）

## 卒論・実務での使いどころ

累積比率の曲線は、所得分布のローレンツ曲線と同じ考え方で、顧客の偏りにも所得格差にも使えます。
