## 問い

第75ステップで、鉱工業生産指数の水準は1か月前との相関が約0.89と、とても強いことを見ました。それなら、先月の生産から今月の生産を予測できそうです。このステップでは、過去の自分の値で今月を説明する**自己回帰モデル**を、`lm()` と `arima()` の2通りで推定し、2026年9月の値を予測します。

## 使うデータ

`iip` は、経済産業省「鉱工業生産・出荷・在庫指数」（2020年基準）の鉱工業総合の月次の値で、2026年10月24日に取得した時点の2018年1月〜2026年8月の104か月です。予測には季節調整済指数 `iip_sa` を使います。季節の上下が取り除かれているので、モデルに季節を入れずに済みます。季節調整済指数は年間補正でさかのぼって改定されるので、結果は取得時点のデータによるものです。

## ラグを説明変数にした回帰

今月の値を1か月前の値で説明するモデルを **AR(1)**（1次の自己回帰モデル、AR は autoregressive の略）といいます。

$$y_t = c + \phi\, y_{t-1} + \varepsilon_t$$

$\phi$（ファイ）が「先月の値をどれだけ引き継ぐか」を表します。第73ステップの `lag()` で先月の値の列を作れば、これまでの `lm()` で推定できます。

```r
iip_l <- iip |>
  mutate(prev = lag(iip_sa))
m_lm <- lm(iip_sa ~ prev, data = iip_l)
coef(m_lm)
```

最初の月は `prev` が `NA` なので、103か月で推定されます。傾きは約0.89、決定係数は約0.80です。

## arima で推定する

R の `arima()` は、時系列モデルをまとめて扱う関数です。`order = c(p, d, q)` の3つの数でモデルを指定します。

- `p` … 何か月前までの自分の値を使うか（AR の次数）
- `d` … 何回階差をとってから当てはめるか（第75ステップの `diff()`）
- `q` … 過去の偶然の動きをいくつ使うか（第77ステップ）

AR(1) は `order = c(1, 0, 0)` です。`arima()` には `ts()` で作った時系列を渡します。

```r
y <- ts(iip$iip_sa, start = c(2018, 1), frequency = 12)
m_ar <- arima(y, order = c(1, 0, 0))
m_ar
```

`ar1` が $\phi$ で約0.895、`lm()` の傾きとほぼ同じです。注意したいのは `intercept` です。`arima()` の intercept は**系列の平均**（約105.4）で、`lm()` の切片（約11.5）とは意味が違います。AR(1) は「平均からのずれの約9割を翌月に引き継ぐ」モデルと読めます。

## 1か月先を予測する

`predict()` に `n.ahead = 1` を指定すると、データの最後の月の次（2026年9月）を予測します。結果の `$pred` が予測値、`$se` が予測の標準誤差です。

```r
fc1 <- predict(m_ar, n.ahead = 1)
pred_lm <- coef(m_lm)[["(Intercept)"]] + coef(m_lm)[["prev"]] * tail(iip$iip_sa, 1)
```

`tail(x, 1)` は x の最後の1個を取り出します。2026年8月の値は101.9で、`arima()` の予測は約102.3、`lm()` の予測は約102.2です。どちらも2026年8月より少し高いのは、平均の約105.4に向かって戻ると予測するからです。予測の標準誤差は約2.5ポイントで、前月差の散らばり（第75ステップの約2.6）と同じくらいの不確かさがあります。

## 推定する期間で結果は変わる

全期間の平均約105.4には、生産水準の高かった2018〜2019年（年平均は約114.6と約111.9）が含まれます。2021年1月以降だけで推定し直すと、`ar1` は約0.61、平均は約103.3に変わります。全期間の $\phi$ が1に近いのは、2018年から2020年にかけて水準が大きく下がったことも映しています。どの期間で推定するかは、予測したい将来に近い時期はどこかを考えて選びます（第80ステップ）。

また、先月の生産で今月をよく予測できても、それは過去の動きのくり返しを使っているだけです。先月の生産が今月の生産を生むという**因果関係**を示すものではありません。

## 卒論・実務での使いどころ

売上や受注のように月ごとの値が続く系列では、まず AR(1) を当てはめて「先月の値をどれだけ引き継ぐか」を見ると、その系列の動きの癖と予測の出発点がつかめます。
