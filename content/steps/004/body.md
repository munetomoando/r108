## 問い

経営企画部の上司から、次の依頼が来ました。「今年、前年より売上が落ちた店はどこ？ 一覧にしてほしい」。売上が前年を下回ることを**前年割れ**といいます。50行の店舗データ `stores`（架空の企業「そらまめマーケット」のデータ）の中から、条件に合う行だけを取り出し、売上の高い順に並べる方法を学びます。

## 行を選ぶ：filter()

第3ステップでは、表全体を `head()` や `summary()` で眺めました。実務では「条件に合う行だけを見たい」場面がよくあります。そのときに使うのが dplyr パッケージの `filter()` です。dplyr は、表を加工するための関数を集めたパッケージで、tidyverse（データ分析のためのパッケージ群）の中心の一つです。

`filter()` は `filter(データ, 条件)` の形で書きます。条件が TRUE（真）になった行だけが残ります。

```r
big <- filter(stores, sales > 100000)
big
nrow(big)
```

これは今年の売上が10億円（100000万円）を超える店舗です。`>` は「より大きい」を表す比較の演算子です。演算子とは、`+` や `*` のように値どうしを計算したり比べたりする記号のことです。比較の演算子には次のものがあります。

| 書き方 | 意味 |
| --- | --- |
| `>` / `<` | より大きい / より小さい |
| `>=` / `<=` | 以上 / 以下 |
| `==` | 等しい |
| `!=` | 等しくない |

条件では、数値と列だけでなく、列どうしを比べることもできます。たとえば `staff > 30` は「従業員が30人より多い」、`sales > sales_last` は「今年の売上が前年より多い（前年超え）」という意味です。比較は行ごとに行われます。

文字の列を条件にするときは、比べる値を引用符で囲みます。

```r
filter(stores, region == "近畿")
```

ここで大事なのは、「等しい」は `=` ではなく `==`（イコール2つ）だという点です。`=` は引数（関数に渡す値）の名前を指定するための記号です。`filter(stores, region = "近畿")` と書くと、R は「region という名前の引数に "近畿" を渡した」と解釈し、エラーになります。初心者が最もよくつまずく箇所の一つなので、エラーが出たらまず疑いましょう。

## 条件を組み合わせる：& と |

条件が2つ以上あるときは、論理演算子でつなぎます。

- `&`（かつ）… 両方の条件を満たす行だけを残す
- `|`（または）… どちらか一方でも満たせば残す

```r
# 九州・沖縄の店舗で、かつ商業施設の中にある店
filter(stores, region == "九州・沖縄" & location == "商業施設")

# 中部、または近畿の店舗
filter(stores, region == "中部" | region == "近畿")
```

`&` は条件を足すほど行が減り、`|` は条件を足すほど行が増えます。結果の行数を `nrow()` で確かめると、意図どおりに絞れたかを確認できます。

## 行を並べる：arrange() と desc()

一覧を上司に見せるなら、順位がわかるように並べたくなります。行を並べ替えるには `arrange()` を使います。

```r
arrange(stores, floor_m2)
```

`arrange()` は、指定した列の値が小さい順（昇順）に並べます。大きい順（降順）にしたいときは、列名を `desc()` で包みます。desc は descending（降順）の略です。

```r
by_staff <- arrange(stores, desc(staff))
head(by_staff)
```

`filter()` も `arrange()` も、元の `stores` を書き換えません。結果を残したいときは `<-` で新しい名前に代入します。元のデータを残しておくと、やり直しが簡単になります。

前年割れの店舗を取り出したら、`region` の列を眺めてみてください。特定の地域に偏っていないでしょうか。地域ごとの数を数える方法は第6ステップで学びます。また、「filter した結果を変数に入れ、それを arrange に渡す」という2段階の処理を短くつなぐ書き方（パイプ `|>`）は第7ステップで学びます。

## 卒論・実務での使いどころ

「前年割れの店舗」「特定の地域の郊外店」のように対象を絞り込み、大きい順に並べて上位を確かめる作業は、実務の報告でも卒論の分析でも最初に行う基本の操作です。
