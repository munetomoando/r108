## 問い

職業訓練は年収を上げたのでしょうか。第7部の総合演習として、第59〜61ステップの職業訓練の観察データ `obs`（4,000人）に、単純比較・回帰・マッチング・傾向スコアの重みの4つの方法を使い、推定値を1つの表に並べて結論を書きます。

## データと「答え」

`obs` は教材用の合成データで、訓練の真の効果は全員+30万円/年と決めてあります。ただし、前年収入の低い人や若い人ほど訓練に参加しやすいように作ってあります。第59ステップで見たとおり、参加者の前年収入の平均は約191万円、不参加者は約308万円です。

実際の研究では真の値は分かりません。この演習では答えが分かっているので、それぞれの方法がどれだけ近づくかを確かめられます。

## 4つの方法

| 方法 | 何をそろえるか | 推定の対象 |
| --- | --- | --- |
| 単純比較 | 何もそろえない | — |
| 回帰 | 共変量を式に入れて「他の条件を一定」にする | 効果が全員同じなら ATE＝ATT |
| マッチング | 参加者1人に似た不参加者1人を選ぶ | ATT |
| 傾向スコアの重み | 不参加者に $p/(1-p)$ の重みをつける | ATT |

```r
est_naive <- coef(lm(earn_post ~ treat, data = obs))[["treat"]]
est_reg <- coef(lm(earn_post ~ treat + prior_earn + age + I(age^2) + educ_years + female,
                   data = obs))[["treat"]]
```

`coef(モデル)[["treat"]]` は、係数のうち treat の値だけを1つの数として取り出します。後で表にまとめるときに便利です。

マッチングは第60ステップと同じく、最近傍の1対1、ATT、共変量は前年収入・年齢・教育年数・性別です。`MatchIt` は読み込みに少し時間がかかります。傾向スコアの重みは第61ステップと同じ作り方です。

```r
results <- tibble(方法 = c("単純比較", "回帰", "マッチング", "傾向スコアの重み"),
                  推定値 = c(est_naive, est_reg, est_match, est_ipw))
```

## 結果の読み方

小課題 d で作った表 `results` の4つの値を、真の値（30万円）と並べて見てください。

単純比較だけが大きく外れ、符号まで逆になるはずです。訓練が年収を下げたのではなく、もともと年収の低い人が参加したという選択バイアスです（第55ステップ）。調整した3つの方法は、どれもプラスで30万円に近い値です。

3つの値が少しずつ違うのは、そろえ方が違うからです。マッチングでは、選ばれた不参加者の前年収入の平均が約199万円で、参加者の約191万円より少し高く残ります。この差の分だけ、推定値が下に偏りやすくなります。どの方法も完全ではないので、1つの値だけでなく、複数の推定を並べて示すことに意味があります。

## 結論を書くときの注意

この演習で調整がうまくいったのは、参加が観察できる変数（前年収入と年齢）だけで決まるようにデータを作ったからです。やる気のような観察できない理由で参加が決まっていれば、どの方法でも偏りが残ります。また、第61ステップで見たように、前年収入が500万円を超える人には参加者がいません。推定できるのは、参加者に似た人がいる範囲の効果です。

結論は「調整すると約〇万円のプラス」と数字で示し、「参加が観察できる変数で説明でき、似た比較相手がいるという条件のもとで」と条件を添えて書きます。第62ステップの NSW のように、実際のデータでは方法やモデルで値が動くことも忘れないようにしましょう。

## 卒論・実務での使いどころ

卒論で観察データから効果を推定するときは、単純比較と3つの調整方法の推定値を1つの表にまとめ、値の違いの理由と、結論が成り立つ条件を本文に書きます。
