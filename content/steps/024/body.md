## 問い

パートの時給と人件費を考えるとき、まず目に入るのは最低賃金です。では、最低賃金の高い県ほど、そこで働く人の平均的な賃金も高いのでしょうか。2025年の47都道府県を散布図にして確かめ、その関係をどこまで読んでよいかを考えます。

## 使うデータ

`panel` は第18ステップで作った都道府県パネル（`pref_panel.csv`）です。平均時給 `avg_wage` は、厚生労働省「賃金構造基本統計調査」（2019〜2025年）の一般労働者（短時間労働者を除く）の所定内給与額を所定内実労働時間数で割った値で、各年6月分の円/時です。最低賃金 `min_wage` は厚生労働省「地域別最低賃金改定状況」の時間額で、**その年の6月に効いていた額**、つまり前年度の最低賃金です（最低賃金は毎年10月ごろに改定されるため）。たとえば2025年の行の `min_wage` は2024年度の額です。

```r
p2025 <- filter(panel, year == 2025)
ggplot(p2025, aes(x = min_wage, y = avg_wage)) +
  geom_point()
```

## 相関係数で関係の強さを測る

散布図が右上がりなら、2つの変数には正の関係があります。その強さを1つの数で表すのが**相関係数**です。−1から1の値をとり、1に近いほど点が右上がりの直線に沿って並び、0に近いほど直線的な関係がないことを表します。R では `cor()` に2つの列を渡します。

```r
cor(p2025$min_wage, p2025$avg_wage)
```

2025年では約0.908です。最低賃金が最も高い東京都（1,163円）は平均時給も最も高く（約2,631円）、最低賃金が最も低い秋田県（951円）や、平均時給が最も低い青森県（約1,619円）は左下に位置します。年を変えて計算しても、2019〜2025年の相関係数はどの年も0.91〜0.94の範囲にあります。

## 回帰直線を引く

点の並びに最もよく当てはまる直線を**回帰直線**といいます。`geom_smooth(method = "lm")` を足すと、図に回帰直線が引かれます。`lm` は「線形モデル」（linear model）の略です。`method` を書かないと、点の並びに沿って曲がる線が引かれます。

```r
ggplot(p2025, aes(x = min_wage, y = avg_wage)) +
  geom_point() +
  geom_smooth(method = "lm")
```

直線の周りの灰色の帯は、直線の位置がどのくらい不確かかを表す範囲です。帯の意味と直線の求め方は、第5部（回帰分析）で詳しく学びます。

## 点に県名を書く

`geom_text()` は点の位置に文字を書く層で、どの列を書くかを `aes(label = 列名)` で指定します。47県の名前をそのまま書くと、点や文字どうしが重なります。ggplot2 の範囲では、次のような工夫ができます。

- `size = 3` で文字を小さくする
- `vjust = -0.6` で文字を点の少し上にずらす（負の値で上、正の値で下）
- `check_overlap = TRUE` で、先に書いた文字と重なる文字を省く（ただし一部の県名は表示されなくなります）

```r
ggplot(p2025, aes(x = min_wage, y = avg_wage)) +
  geom_point() +
  geom_text(aes(label = pref), size = 3, vjust = -0.6)
```

図を見ると、左下に固まった県では名前が重なりますが、右上の東京都・神奈川県・大阪府ははっきり読めます。全部を読ませるより、伝えたい県が読めればよいと割り切るのも1つの方法です。

## 相関は因果ではない

右上がりの図を見ると「最低賃金を上げれば平均賃金も上がる」と言いたくなります。しかし、この図だけではそう言えません。最低賃金は、各地の賃金水準なども考えて審議会で決められるので、「賃金が高い県だから最低賃金も高い」という逆向きの関係がありえます。また、企業の生産性や物価の高い地域では、両方がともに高くなります。こうした第3の要因があっても、同じ右上がりの図になります。

## 卒論・実務での使いどころ

散布図に回帰直線と相関係数を添えると関係の強さを一目で示せますが、店舗の時給を決める資料でも卒論でも、それが因果を示すものではないことを一言添えておきましょう。
