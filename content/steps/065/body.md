## 問い

最低賃金の高い県・年ほど、若年就業率は高いのでしょうか、低いのでしょうか。第64ステップで見たように、県には水準の違いがあり、全県に共通する年ごとの動きもあります。この2つを取り除くと、答えはどう変わるでしょうか。

## プールした OLS：まとめて回帰すると

使うのは第64ステップと同じ `mw`（47県×13年の架空のパネル）です。ここでは説明変数に最低賃金 `min_wage`（円/時）を使います。「最低賃金が高いと若年の就業が減るか」は、最低賃金の議論でいちばん問われる点だからです。

まず、611行をすべてまとめて、ふつうの回帰をします。県や年の区別をせずにデータを「プール」するので、**プールした OLS** と呼びます。

```r
m_pool <- feols(youth_emp_rate ~ min_wage, data = mw)
coef(m_pool)
```

min_wage の係数は約 +0.0072 です。最低賃金が100円高いと、若年就業率が約0.72ポイント高いという関係です。最低賃金を上げると就業が増えるように見えます。

しかしこのデータでは、最低賃金は全県で毎年20円ほど上がり、若年就業率も全国で緩やかに上がっています。両方が時間とともに上がるだけで、正の関係が出てしまいます。

## 二元固定効果：県の違いと年の動きを取り除く

**固定効果**とは、県ごと（または年ごと）に別々の切片を置くことです。県の固定効果は「その県にずっと共通する水準」を、年の固定効果は「その年に全県に共通する動き」（2020年の落ち込みなど）を吸収します。両方を入れたモデルを**二元固定効果**（two-way fixed effects）モデルといいます。

$$y_{it} = \alpha_i + \lambda_t + \beta x_{it} + \varepsilon_{it}$$

$i$ は県、$t$ は年、$\alpha_i$ が県の固定効果、$\lambda_t$ が年の固定効果です。fixest では、式の `|` の右に固定効果の変数を書きます。

```r
m_fe <- feols(youth_emp_rate ~ min_wage | pref_code + year, data = mw)
coef(m_fe)
```

係数は約 −0.0147 で、符号が逆になりました。県の固定効果だけでは約 +0.0076、年の固定効果だけでは約 −0.0002 です。両方を入れて初めて負の関係が現れます。

県の固定効果は、第64ステップの within 変換と同じことをしています。若年就業率と最低賃金の両方から県内平均を引いて `lm()` で回帰すると、係数は `feols(youth_emp_rate ~ min_wage | pref_code, data = mw)` と一致します（小課題 e で確かめます）。

## 係数をどう読むか

二元固定効果の係数 −0.0147 は、「同じ県の中で、その年の全国の動き以上に最低賃金が1円上がると、若年就業率が約0.0147ポイント低い」という関係です。100円なら約1.47ポイントです。

県と年の効果を取り除いた後に残る最低賃金の動きは、主に特別引上げで対象12県の最低賃金が他県より余分に上がった部分です（2019年に40円、その後は毎年10円ずつ上乗せ）。つまりこの係数は、ほぼ「特別引上げの前後で、対象県の就業率が他県と比べてどう変わったか」から決まっています。

これを因果効果と読むには、仮定が必要です。固定効果が取り除くのは「県ごとに一定の違い」と「全国共通の年の動き」だけです。対象県だけで同じ時期に別の出来事（工場の閉鎖など）があれば、それも係数に混ざります。この仮定はデータで証明することはできません。第66ステップで、この考え方を差の差分析として整理します。

## 県でクラスタした標準誤差

同じ県の誤差は、年をまたいで似ていることがよくあります。ある県で若年の就業が平年より多い年が続く、といった具合です。すると「611個の独立な観測」とみなす通常の標準誤差は小さすぎることがあります。そこで、県の中では誤差が相関してもよいとする**クラスタ標準誤差**を使います。

```r
m_iid <- feols(youth_emp_rate ~ min_wage | pref_code + year, data = mw, vcov = "iid")
m_cl  <- feols(youth_emp_rate ~ min_wage | pref_code + year, data = mw, cluster = ~pref_code)
se(m_iid)
se(m_cl)
```

標準誤差は、iid で約0.00156、県でクラスタすると約0.00171（約1.10倍）です。このデータは誤差を県や年と無関係に作ったので、差は小さくなりました。実際の県のデータでは、クラスタ標準誤差が何倍にもなることがあります。県単位の政策を分析するときは、県でクラスタするのが標準です。クラスタの数（ここでは47県）が少なすぎると、この方法も不正確になる点に注意します。

## 卒論・実務での使いどころ

卒論で都道府県のパネルを分析するときは、プールした OLS と二元固定効果の結果を並べ、県でクラスタした標準誤差を使ったことを表の注記に書きます。
