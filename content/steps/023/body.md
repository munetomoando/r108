## 問い

そらまめマーケットは、来年の値付けの方針を決める会議に向けて資料を作っています。経営企画部のあなたは「過去の消費税率引上げのとき、店頭の価格全体はどう動いたか」を1枚の図で示すよう頼まれました。消費者物価指数の折れ線に、見出し・注記・縦線を加えて、会議でそのまま見せられる図に仕上げます。

## 使うデータ

`cpi` は総務省統計局「消費者物価指数」（2025年基準）の全国・月次の値で、2000年1月から2026年9月まであります。消費者物価指数は、家計が買う商品とサービスの値段を、決まった買い物かごの金額として指数にしたものです。値段は消費税込みの店頭価格で測ります。

- `date` … 年月（その月の1日の日付）
- `cpi_all` … 総合
- `cpi_core` … 生鮮食品を除く総合（天候で大きく動く野菜・魚などを除いたもの）

**2025年基準**とは、2025年の平均を100とすることです。2019年10月の総合が89.7なら、「2025年平均より約10%安かった」と読みます。100より小さい値でも、物価が下がっていたという意味ではありません。

setup では、2回の引上げを含む2012〜2021年の10年分を `cpi_1221` に取り出してあります。

```r
cpi_1221 <- filter(cpi, year(date) >= 2012, year(date) <= 2021)
```

## labs で見出しと軸の名前を付ける

これまでの図では、軸の名前が `date` や `cpi_all` のような列名のままでした。分析する本人には分かっても、会議の出席者には伝わりません。`labs()` を `+` で足すと、見出しや軸の名前を自由に書けます。

```r
p <- ggplot(cpi_1221, aes(x = date, y = cpi_all)) +
  geom_line() +
  labs(title = "消費者物価指数（総合）の推移",
       x = "年月", y = "指数（2025年＝100）",
       caption = "出所：総務省統計局「消費者物価指数」2025年基準")
p
```

`title` は見出し、`x` と `y` は軸の名前、`caption` は図の右下に小さく出る注記です。社内資料でも、公的統計を使った図には caption に出所を書く習慣を付けましょう。補足の一文を見出しの下に出したいときは `subtitle` を使います。

図を `p` に代入しておくと、`p + …` のようにあとから部品を足していけます。

## テーマで見た目を整える

ggplot2 の既定の図は、灰色の背景に白い格子です。**テーマ**（theme）は、背景・格子・文字の大きさなど、データと関係のない見た目をまとめて決める部品です。`theme_minimal()` を足すと、背景が白くなり、格子も薄くなります。

```r
p2 <- p + theme_minimal()
p2
```

ほかに `theme_bw()`（枠つき）、`theme_classic()`（格子なし）などがあります。資料の中ではテーマをそろえると、図が並んだときに読みやすくなります。

## 縦線と注記で出来事を示す

図のどこを見てほしいかは、図の中に書き込みます。`geom_vline()` は、横軸の指定した位置に縦線を引く層です。横軸が日付なので、位置も `ymd()` で日付にして渡します。`annotate()` は、データの表とは別に、文字などを1つずつ置く関数です。

```r
p3 <- p2 +
  geom_vline(xintercept = ymd(c("2014-04-01", "2019-10-01")), linetype = "dashed") +
  annotate("text", x = ymd(c("2014-04-01", "2019-10-01")), y = 90.5,
           label = c("消費税 5%→8%", "消費税 8%→10%"))
p3
```

`annotate()` の1つ目の引数 `"text"` は文字を置くという意味で、`x` と `y` は置く場所（軸の値）です。文字が線や折れ線と重なったら、`y` の値を変えて調整しましょう。

## 段差の大きさを確かめる

図を見ると、2014年4月の縦線のところで、折れ線が階段のように一段上がっています。数字でも確かめましょう。

```r
filter(cpi_1221, month(date) %in% c(3, 4, 9, 10), year(date) %in% c(2014, 2019))
```

総合指数は2014年3月の85.5から4月の87.3へ、1.8ポイント上がりました。これは2000年以降で最も大きい前月からの上昇です。一方、2019年は9月の89.4から10月の89.7へ0.3ポイントで、ほかの月の動きと見分けがつかないほどです。前年同月比の公表値も、2014年4月は3.4%、2019年10月は0.2%でした（この表の指数から計算すると、生鮮食品を除く総合などで公表値と0.1ポイント違うことがあります）。

2019年の段差が小さかった理由は d で考えます。同じ「増税」でも、店頭の価格への表れ方は制度の細部で変わります。図に縦線を引いただけで「影響があった・なかった」と決めず、数字と制度の両方を確かめることが大切です。

## 卒論・実務での使いどころ

制度が変わった時点に縦線と注記を入れた時系列の図は、卒論で政策の前後を比べるときにも、社内で「値上げや増税の前後に売上がどう動いたか」を説明するときにも、最初に見せる1枚になります。
