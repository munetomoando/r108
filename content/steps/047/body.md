## 問い

卒論の分析は、先行研究の再現から始めると確実です。同じデータで同じ集計をして、論文と同じ数字が出れば、自分の作業手順が正しいと確かめられます。労働経済学の古典 Mroz（1987）のデータで、記述統計表を再現してみましょう。

## 使うデータ

`mroz` は、T. A. Mroz が1987年に *Econometrica*（55巻4号、765–799頁）に発表した、既婚女性の労働時間についての論文のデータです。Wooldridge の教科書 *Introductory Econometrics: A Modern Approach* でも繰り返し使われていて、wooldridge パッケージに入っています。

```r
data("mroz", package = "wooldridge")
nrow(mroz)
```

1行が既婚女性1人で、753人います。主な列は次のとおりです（どれも1975年の値）。

| 列 | 意味 |
| --- | --- |
| `inlf` | 労働参加ダミー（働いていれば1） |
| `hours` | 年間の労働時間 |
| `wage` | 時給（ドル） |
| `educ` | 教育年数 |
| `exper` | 就業経験年数 |
| `age` | 年齢 |
| `kidslt6` / `kidsge6` | 6歳未満 / 6〜18歳の子どもの数 |
| `nwifeinc` | 妻以外の世帯所得（千ドル） |

## 賃金は働いている人にしか観察されない

`mean(mroz$wage)` を実行すると、`NA` になります。働いていない女性には時給がないので、`wage` が欠損値（NA）だからです。そのため、労働経済学の論文では、賃金にかかわる記述統計を**働いている人だけ**で示すことがよくあります。

```r
workers <- mroz |> filter(inlf == 1)
```

`inlf == 1` の女性は428人です。残りの325人は `wage` がすべて NA で、`hours` は0です。どの行を分析に使ったかは、論文では必ず書かれています。再現するときは、まずこの「標本の絞り込み」を論文に合わせます。

## 平均と標準偏差の表を作る

論文の記述統計表は、ふつう1行に1つの変数、列に平均と標準偏差を並べます。第13ステップの `pivot_longer()` で縦長にすると、`group_by()` と `summarise()` の1回で全部の変数を集計できます。

```r
workers |>
  pivot_longer(c(hours, wage, educ, exper, age, kidslt6, kidsge6),
               names_to = "変数", values_to = "値") |>
  group_by(変数) |>
  summarise(平均 = mean(値), 標準偏差 = sd(値))
```

働いている428人では、労働時間の平均が約1,303時間（標準偏差 約776）、時給が約4.18ドル（約3.31）、教育年数が約12.66年（約2.29）、就業経験が約13.04年（約8.06）です。6歳未満の子どもの数の平均は約0.14人で、753人全体の約0.24人より少なくなっています。小さな子どもがいる女性ほど働いていない、という関係がすでに表に現れています（第48ステップで回帰で確かめます）。

## 論文の値と照合する

再現の最後に、自分の数字と論文の数字を並べた表を作り、差を確かめます。差が0でなければ、データの版、標本の絞り込み、変数の定義（たとえば時給を何で割って出したか）のどこかが違っています。

Mroz（1987）の標本は753人、そのうち1975年に働いていたのは428人です。手元のデータの人数と比べると、どちらも差は0になります。

照合の相手には、論文や教科書に**はっきり書かれている値**だけを使います。記憶やうろ覚えの値と比べて「だいたい合っている」と書くのは再現ではありません。論文の表を手元に置き、どの表のどの行と比べたのかを、卒論の本文か注に書きましょう。

## 卒論・実務での使いどころ

卒論では、先行研究の表を1つ再現して「データと手順が正しいこと」を示してから、自分の分析に進みます。実務でも、前任者の集計表を同じデータで作り直して一致を確かめてから、新しい分析を加えると、数字の食い違いで手戻りせずにすみます。
