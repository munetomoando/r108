## 問い

教育年数の長い人ほど時給は高いのでしょうか。高いとしたら、その関係はどれくらい強いのでしょうか。架空の賃金調査 `wage`（3,000人、乱数で作った教材用のデータ）で相関係数を求め、対数をとる効果と外れ値の影響、そして相関から言えないことを確かめます。

## 相関係数をもう一度

第24ステップで学んだ**相関係数**は、2つの変数の直線的な関係の強さを −1 から 1 の数で表します。正なら「一方が大きいと他方も大きい」、負なら逆、0 に近いほど直線的な関係がありません。式で書くと、2つの変数の偏差の積の平均を、それぞれの標準偏差（第28ステップ）で割ったものです。

$$r = \frac{\frac{1}{n-1}\sum_{i}(x_i - \bar{x})(y_i - \bar{y})}{s_x \, s_y}$$

標準偏差で割っているので、単位（年、円）によらない数になります。

```r
cor(wage$educ_years, wage$hourly_wage)
```

結果は約0.26です。正の相関ですが、点が直線にぴったり並ぶほど強くはありません。同じ教育年数の人の間でも、時給には大きな個人差があるからです。

## 相関行列で一度に見る

`cor()` に数値の列だけからなる表を渡すと、すべての組み合わせの相関係数を並べた**相関行列**が返ります。

```r
wage |>
  select(educ_years, exper, tenure, hourly_wage) |>
  cor() |>
  round(2)
```

対角線は自分自身との相関なので1です。時給との相関は、経験年数 `exper` が約0.31、勤続年数 `tenure` が約0.32で、教育年数より少し高くなっています。また、教育年数と経験年数の相関は約 −0.18 と負です。年齢が同じなら、学校に長くいた人ほど働いた年数が短くなるからです。

## 対数をとる

賃金の分析では、時給そのものではなく、その**自然対数**（`log()`）を使うことがよくあります。対数をとると、2,000円→2,200円と20,000円→22,000円のように、「同じ割合（10%）の違い」が同じ幅になります。右に長い裾が縮まり、分布が左右対称に近づきます。

```r
wage <- mutate(wage, lw = log(hourly_wage))
cor(wage$educ_years, wage$lw)
```

教育年数と対数時給の相関は約0.24で、時給そのものとの相関（約0.26）とあまり変わりません。相関係数の大きさだけで「どちらが正しい」とは決まりません。対数の利点は次の外れ値の例ではっきりします。

## 外れ値1つで相関は変わる

`bind_rows()` は、列名のそろった2つの表を上下につなげる関数です。これを使って、「高卒（12年）で時給10万円」という極端な1人を加えてみます。

```r
extreme <- head(wage, 1) |>
  mutate(educ_years = 12, hourly_wage = 100000, lw = log(100000))
wage_out <- bind_rows(wage, extreme)
cor(wage_out$educ_years, wage_out$hourly_wage)
```

3,001人のうちたった1人なのに、時給との相関係数は約0.26から約0.09へ大きく下がります。相関係数は平均や標準偏差と同じく、極端な値に引っ張られやすいのです。一方、対数時給との相関は約0.24から約0.23へと、ほとんど変わりません。10万円の対数は約11.5で、ほかの人（対数で6〜9ほど）から極端には離れないからです。

外れ値を見つけたら、まず入力の誤り（桁の打ち間違いなど）でないかを確かめます。本当の値なら、勝手に消さず、対数をとる、外れ値を除いた結果も並べて示す、といった扱いを明記します。散布図を描いて点の並びを目で確かめることも大切です。

## 相関は因果ではない

教育年数と時給に正の相関があっても、「教育を1年延ばせば時給が上がる」とは言えません。もともとの能力や家庭環境が、教育年数と時給の両方を高めているかもしれないからです。相関は関係の強さを測る道具で、効果の大きさを測るには回帰分析（第5部）や因果推論（第7・8部）の考え方が必要です。

## 卒論・実務での使いどころ

卒論でも社内アンケートの分析でも、相関係数は散布図と一緒に示し、外れ値の扱いと「相関であって因果ではない」ことを一言添えましょう。
