## 問い

第37ステップでは `lm()` が傾き約0.0489を出しました。この数字はどこから来たのでしょうか。中身を知れば、傾きは平均・分散・共分散だけで手計算できます。今回は**最小二乗法**の仕組みを、Rで1つずつ確かめます。

データは第37ステップと同じ、賃金調査風の**架空のデータ** `wage`（3,000人）です。setup で、第37ステップの単回帰 `m <- lm(log_wage ~ educ_years, data = wage)` を作ってあります。

## 最小二乗法とは

データの点に直線を引くとき、どの直線が「いちばん当てはまる」のでしょうか。最小二乗法は、各点と直線との縦のずれ（**残差**）を二乗して合計し、それが最も小さくなる直線を選びます。二乗するのは、上にずれた点と下にずれた点が打ち消し合わないようにするためです。

この条件を解くと、傾きと切片は次の式になります。

$$\hat\beta_1 = \frac{\mathrm{Cov}(x, y)}{\mathrm{Var}(x)}, \qquad \hat\beta_0 = \bar y - \hat\beta_1 \bar x$$

傾きは「x と y が一緒に動く度合い（共分散）」を「x の散らばり（分散）」で割ったものです。切片の式は、直線が平均の点 $(\bar x, \bar y)$ を必ず通ることを表しています。

```r
slope <- cov(wage$educ_years, wage$log_wage) / var(wage$educ_years)
intercept <- mean(wage$log_wage) - slope * mean(wage$educ_years)
c(intercept, slope)
coef(m)
```

`cov()` は共分散、`var()` は分散を求める関数です。結果は切片約6.858、傾き約0.0489で、`coef(m)` と一致します。`lm()` は特別なことをしているわけではなく、この計算をしているのです。

## 当てはめ値と残差

直線の上の値を**当てはめ値**（$\hat y$）、実際の値との差 $y - \hat y$ を**残差**といいます。

```r
fit <- fitted(m)
res <- residuals(m)
sum(res)
mean(fit)
mean(wage$log_wage)
```

`fitted()` と `residuals()` は、1人1つずつ、3,000個の値を返します。残差の合計は `-7.2e-14` のような値になります（細かい数字は環境によって変わります）。これは $-7.2 \times 10^{-14}$ で、計算の丸めによる誤差を除けば0です。切片を入れた最小二乗法では、残差の合計は必ず0になります。そのため当てはめ値の平均も、実際の対数時給の平均（約7.561）と一致します。

## 決定係数 R²

**決定係数** $R^2$ は、y の散らばりのうち、直線で説明できた割合です。

$$R^2 = 1 - \frac{\text{残差の二乗和}}{\text{y と平均の差の二乗和}}$$

```r
r2 <- 1 - sum(res^2) / sum((wage$log_wage - mean(wage$log_wage))^2)
c(r2, summary(m)$r.squared)
```

このデータでは、対数時給の平均からのずれの二乗和は約459.4、残差の二乗和は約433.1です。直線で説明できたのは全体の約5.7%（$R^2 \approx 0.057$）にとどまります。単回帰の $R^2$ は、相関係数の二乗 `cor(wage$educ_years, wage$log_wage)^2` とも一致します。

$R^2$ が小さくても、係数に意味がないわけではありません。時給は学歴以外の多くの要因で決まるので、1つの変数で説明できる割合が小さいのは自然なことです。$R^2$ は「当てはまりのよさ」を表し、「係数の正しさ」を表すものではありません。

## 外れ値に弱い

最小二乗法は残差を**二乗**するので、遠く離れた点ほど大きく効きます。小課題 d で、極端な値の1人を加えると傾きがどう動くか予想してみましょう。対数をとらない時給で回帰すると、変化はさらに大きくなります。

## 卒論・実務での使いどころ

回帰の結果を報告する前に、残差の合計や $R^2$ を自分で計算し直せると、ソフトの出力を正しく読めているかを確かめられます。社内の賃金分析でも、極端な値の1人が傾きを動かしていないかを残差で点検しましょう。
