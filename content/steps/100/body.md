## 問い

第12部では、そらまめマーケット（架空の会社）の分析担当として、分析の結果を上司や経営会議に「伝える」形に仕上げます。毎月初めに、上司から「先月の通販の数字をまとめて」と頼まれるとします。忙しい上司が読むのは最初の数行だけです。結論を先頭に置き、コードは見せず、来月は対象の月を変えるだけで作り直せる報告書を Quarto で作ります。

## 業務レポートと論文の違い

第51〜54ステップでは、Quarto で Word の論文を書きました。業務レポートは、次の3点が違います。

- **結論が先**：論文は「問い→データ→方法→結果→結論」の順でしたが、業務レポートは冒頭に **要約**（数値入りの結論を2〜3行）を置き、根拠の図表をその後に並べます
- **コードを見せない**：読み手が知りたいのは結果です。YAML ヘッダに `execute:` の `echo: false` を書くと、すべてのチャンクでコードが消え、結果（表と図）だけが残ります
- **HTML で配る**：`format: html` にすると、ブラウザで読める1つのファイルになります。雛形の `embed-resources: true` は図もファイルの中に入れる設定で、メールに添付するだけで相手が開けます

## 雛形を HTML に出力する

1. ステップ50で作ったプロジェクト `r108` を開きます。
2. このアプリから [ec_orders.csv](data/ec_orders.csv) と [ec_products.csv](data/ec_products.csv) をダウンロードし、`data` フォルダに移します。
3. 雛形 [report.qmd](local/report.qmd) をダウンロードし、プロジェクトのフォルダに移して開きます。
4. RStudio は「Render」、Positron は「Preview」を押します。同じフォルダに `report.html` ができます。
   - Windows：エクスプローラーで `report.html` をダブルクリックすると、既定のブラウザ（Edge など）で開きます。
   - macOS：Finder で `report.html` をダブルクリックすると、Safari などで開きます。

開くと、表と図の上にコードが出ているはずです。setup のチャンクでは、第82・83ステップと同じ定義で、月ごとの売上・客数・客単価と前年同月比を `kpi` に計算しています。`lag(sales, 12)` は12か月前の値です。

## コードを隠し、要約を冒頭に置く

YAML ヘッダの `format:` の前に、次の2行を加えます。著者名も自分の名前にします。

```yaml
execute:
  echo: false
```

次に、setup のチャンクのすぐ下（雛形の `<!-- -->` のメモの位置）に要約を書きます。数値は手で打たずに **インラインコード** で埋め込みます。文の中に `` `r 式` `` と書くと、レンダリングのときに式が計算され、結果の数値に置き換わります。

```markdown
## 要約

- `r year(m)`年`r month(m)`月の売上は `r round(now$sales / 10000)` 万円で、前年同月比 `r round(now$sales_yoy, 1)`% でした。
- 客数は `r now$buyers` 人（前年同月比 `r round(now$buyers_yoy, 1)`%）、客単価は `r round(now$spend)` 円（同 `r round(now$spend_yoy, 1)`%）です。
- 売上の伸びは客数の増加によるもので、1人当たりの購入額は伸びていません。
```

Render すると、冒頭に「2025年12月の売上は 991 万円で、前年同月比 14% でした」と出ます。客数は2,374人（17.6%増）、客単価は4,174円（3.1%減）です。インラインコードもチャンクと同じく上から順に実行されるので、要約を setup のチャンクより上に置くと、`m` や `now` がまだ無いというエラーになります。

## 対象の月をパラメータにする

来月に12月を1月へ書き換えるとき、コードの中を探すのは手間で、直し忘れも起きます。そこで、対象の月を YAML ヘッダの **params**（パラメータ）にします。

```yaml
params:
  month: "2025-12-01"
```

setup のチャンクの `m <- ymd("2025-12-01")` を `m <- ymd(params$month)` に書き換えます。チャンクの中では、YAML の値を `params$month` で読めます。これで、YAML の `month` を `"2025-06-01"` に変えて Render し直すだけで、2025年6月のレポートになります（売上894万円、前年同月比94.3%）。ターミナルで `quarto render report.qmd -P month:2025-06-01` と打っても同じです（RStudio の Terminal タブ。`quarto` が見つからないと出たら YAML を書き換える方法を使います）。

ただし6月は客単価も8.7%伸びているので、要約の3行目の「1人当たりの購入額は伸びていません」は誤りになります。数値はインラインコードで自動的に更新されますが、**判断を書いた文は毎回読み直す** 必要があります。作り直したら、月を12月に戻して Render し、確認スクリプトを実行します。

## 卒論・実務での使いどころ

毎月・毎週作る報告は、最初に1度パラメータ付きの Quarto で作っておくと、次からは params を変えて Render するだけになり、転記の誤りもなくなります。
