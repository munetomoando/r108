## 問い

第66ステップの差の差分析では、特別引上げの効果を「処置後の平均」として1つの数（約 −0.98 ポイント）にまとめました。しかし効果は、引上げの直後から同じ大きさとは限りません。年を追って効果がどう変わるか、そして引上げの前に処置県と対照県の差が動いていなかったかを、1枚の図で確かめます。

## 相対年を作る

**イベントスタディ**（event study）は、処置が始まった時点から数えた年（**相対年**）ごとに効果を推定する方法です。`minwage_panel` では12県がそろって2019年から引上げを始めたので、相対年は `year - 2019` で作れます。

```r
mw_es <- mw |>
  mutate(rel_year = year - 2019)
count(mw_es, rel_year)
```

2012年は −7、2018年は −1、2019年は 0、2024年は 5 です。

対照群（引上げのない35県）には、そもそも「引上げから何年目」がありません。それでもここでは、対照群にも同じ式で `rel_year` を付けます。次の推定では相対年を `treated`（対照群は0）と掛け合わせるので、対照群の行のダミーはすべて0になり、対照群は年の固定効果（各年の全国共通の動き）を推定するための比較相手として使われます。もし対照群の `rel_year` を `NA` にすると、`feols()` はその行を推定から落としてしまい、比べる相手がいなくなります。

## 相対年ごとの効果を推定する

fixest の `i()` は、相対年ごとに「その年の処置県なら1」というダミーをまとめて作る関数です。`ref = -1` は、引上げの前年（2018年）を基準にして、そのダミーを作らないという指定です。

```r
es <- feols(youth_emp_rate ~ i(rel_year, treated, ref = -1) | pref_code + year,
            data = mw_es, cluster = ~pref_code)
coef(es)
```

係数は相対年 −7〜5 のうち −1 を除いた12個です。それぞれ「その年の処置県と対照県の差が、2018年の差と比べてどれだけ違うか」を表します。基準年を決めないと、県の固定効果と区別できず推定できません。

結果を見ると、処置後は 0年目が約 −0.44、1年目が約 −1.11、2年目以降は約 −0.89〜−1.13 です。データを作るときの真の効果（−0.5、−0.8、2年目以降 −1.0）と同じく、効果が少しずつ大きくなり、その後は横ばいになる形をおおむね再現しています。

## 係数と信頼区間を図にする

イベントスタディの結果は、表より図で示すのが普通です。`confint()` で95%信頼区間を取り出し、係数の名前（`"rel_year::-7:treated"` など）から `parse_number()` で相対年の数字を取り出して表にします。

```r
ci <- confint(es)
es_tab <- tibble(rel_year = parse_number(names(coef(es))),
                 estimate = coef(es), lower = ci[[1]], upper = ci[[2]])
ggplot(es_tab, aes(x = rel_year, y = estimate)) +
  geom_pointrange(aes(ymin = lower, ymax = upper)) +
  geom_hline(yintercept = 0)
```

`geom_pointrange()` は点（係数）と縦線（信頼区間）を一度に描き、`geom_hline()` は水平線を引きます。基準年 −1 の係数は定義により0なので、図には点がありません。

## 処置前の係数を読む

処置前（−7〜−2）の6つの係数は −0.31〜+0.26 で、どの信頼区間も0をまたいでいます。引上げの前は、処置県と対照県の差がほぼ一定だったということです。これは**事前トレンドの確認**と呼ばれ、平行トレンドの仮定と矛盾しない証拠になります。

ただし、2つの点に注意します。第1に、平行トレンドの仮定は「引上げがなかったら、処置後も平行に動いたはず」という観察できない状況についての主張です。処置前の係数が0に近くても、仮定が正しいことの証明にはなりません。第2に、検定は偶然に外れることがあります。このデータは処置前に平行トレンドが成り立つように作ってありますが、処置前の6つの係数がすべて0かをまとめて検定すると、p値は約0.046になります。1つの検定結果ではなく、係数の並び方と大きさを図全体で判断します。

## 卒論・実務での使いどころ

卒論で制度の導入前後を比べるときは、差の差の推定値1つだけでなく、処置前の係数を含むイベントスタディの図を必ず載せ、事前トレンドがないことと効果の時間的な変化を示します。
