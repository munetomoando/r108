## 問い

教育を1年長く受けると、賃金は何%上がるでしょうか。教育年数で賃金を回帰するだけでは、もともとの能力や家庭環境が教育年数と賃金の両方に影響する（交絡）ため、因果効果とは言えません。そこで、教育年数だけを動かす「外からのきっかけ」を使う**操作変数法**を学びます。

## データと統制変数

`close_college` は、Card（1995）が使った米国の若年男性3,010人のデータです。`lwage` は対数賃金、`educ` は教育年数、`nearc4` は育った郡に4年制大学があったか（1＝あり）を表します。

近くに大学があった2,053人の教育年数の平均は約13.5年、なかった957人は約12.7年です。大学が近いと通いやすく、進学する人が増えると考えられます。

統制変数は、経験年数 `exper`、黒人 `black`、南部 `south`、都市部 `smsa` の4つにします。大学のある郡は都市部に多く、南部に少ないので、地域の違いを統制しないと「大学が近い」ことが地域の賃金水準の違いを拾ってしまうからです。`married` は入れません。この列は0/1ではなく1〜6の婚姻状態のコードで、7人が欠損しています。また結婚は教育の結果として変わりうるので、第57・58ステップで学んだ「統制してはいけない変数」にあたるおそれがあります。

## OLS と第1段階

```r
ols <- feols(lwage ~ educ + exper + black + south + smsa, data = cc, vcov = "hetero")
fs  <- feols(educ ~ nearc4 + exper + black + south + smsa, data = cc, vcov = "hetero")
```

OLS の `educ` の係数は約0.074です。対数賃金なので、教育1年で賃金が約7.4%高いという関係です。

`fs` は**第1段階**で、操作変数 `nearc4` が教育年数を動かすかを確かめます。係数は約0.337で、ほかの条件が同じなら、大学が近い人は教育年数が約0.34年長いことになります。操作変数が教育年数と関係していることを**関連性**の条件といいます。強さの目安が第1段階の**F値**で、操作変数が1つなら `nearc4` の t値の2乗に等しく、ここでは約17.5です。F値が10を下回るような弱い操作変数では、2SLS の推定値が大きく偏るおそれがあります。

## 二段階最小二乗法（2SLS）

fixest では「結果 ~ 統制変数 | 内生変数 ~ 操作変数」と書くと、**二段階最小二乗法**（2SLS）になります。内生変数とは、交絡のために OLS では効果を正しく測れない説明変数（ここでは `educ`）のことです。

```r
iv <- feols(lwage ~ exper + black + south + smsa | educ ~ nearc4,
            data = cc, vcov = "hetero")
fitstat(iv, "ivwald")
```

`fitstat()` はモデルの統計量を取り出す関数で、`"ivwald"` は頑健な標準誤差で計算した第1段階の F値です（約17.5で、手で計算した値と同じです）。

教育の係数 `fit_educ` は約0.132で、教育1年で賃金が約13%上がるという推定です。考え方は単純で、「大学が近いと賃金がどれだけ高いか」（`lwage` を `nearc4` と統制変数で回帰した係数、約0.0445）を「大学が近いと教育年数がどれだけ長いか」（約0.337）で割った値（0.0445 ÷ 0.337 ≈ 0.132）になっています。

ただし標準誤差は約0.049と、OLS の約0.004よりずっと大きく、95%信頼区間は約0.036〜0.228と広くなります。また統制変数を入れないと、2SLS は約0.188、OLS は約0.052に変わります。統制変数の選び方で結果は動きます。

## 除外制約

2SLS が因果効果を表すには、関連性に加えて**除外制約**が必要です。「`nearc4` は教育年数を通してしか賃金に影響しない」という仮定です。大学のある地域は仕事の質や親の所得が違うかもしれず、そうした経路が残っていれば除外制約は崩れます。関連性は第1段階で確かめられますが、除外制約はデータで検定できません。経済学の知識で、教育以外の経路がないと言えるかを議論する必要があります。

## 卒論・実務での使いどころ

卒論で操作変数法を使うときは、OLS と 2SLS を並べ、第1段階の係数と F値を報告し、除外制約が成り立つと考える理由を文章で説明します。
