## 問い

第37ステップの単回帰では、教育年数1年あたり対数時給が約0.049高いという結果でした。では、経験年数や勤続年数が同じ人どうしで比べると、学歴による差は変わるのでしょうか。説明変数を複数入れる**重回帰**で確かめます。

データは引き続き、賃金調査風の**架空のデータ** `wage`（3,000人）です。

## 重回帰：説明変数を + で並べる

```r
m_multi <- lm(log_wage ~ educ_years + exper + tenure, data = wage)
m_multi
```

`~` の右に、説明変数を `+` でつないで並べます。式で書くと次のとおりです。

$$\log(\text{時給}) = \beta_0 + \beta_1\,\text{教育年数} + \beta_2\,\text{経験年数} + \beta_3\,\text{勤続年数} + u$$

推定すると、教育年数の係数は約0.0634、経験年数は約0.0082、勤続年数は約0.0084です。

重回帰の係数 $\beta_1$ は、**他の説明変数（経験年数と勤続年数）を一定としたときの**、教育年数1年あたりの差です。「経験年数も勤続年数も同じ人どうしで比べると、教育年数が1年長い人は対数時給が約0.063高い（約6.5%高い）」と読みます。

## 単回帰との比較と信頼区間：confint()

```r
m_simple <- lm(log_wage ~ educ_years, data = wage)
c(coef(m_simple)[["educ_years"]], coef(m_multi)[["educ_years"]])
confint(m_multi)
```

`confint()` は、各係数の95%信頼区間を返します。教育年数の係数は、単回帰で約0.0489（95%信頼区間 約0.042〜0.056）、重回帰で約0.0634（約0.057〜0.070）です。2つの区間は重なりません。係数がはっきり大きくなりました。

なぜ大きくなったのでしょうか。このデータでは、教育年数の長い人ほど経験年数が短くなっています。経験年数の平均は、教育12年の人で約25.5年、18年の人で約18.6年です（相関係数は約−0.18）。学校に長くいた分、働き始めるのが遅いためと考えられます。経験年数も時給を高めるので、単回帰では「学歴が高い人は経験が短い分だけ時給が低い」という効果が混ざり、学歴の差が小さく見えていたのです。経験年数をそろえると、その混ざりが取り除かれます。

なお、このデータは作るときに「教育1年で対数時給が0.07高い」と決めてあり、経験年数の効果は二次関数（第42ステップ）で入れています。重回帰の0.063も、その値とは一致していません。

## 欠落変数バイアス

モデルに入れるべき変数を入れ忘れたために係数がずれることを、**欠落変数バイアス**といいます。ずれが起きるのは、入れ忘れた変数が (1) 被説明変数に影響し、かつ (2) 説明変数と相関しているときです。経験年数はどちらも満たしていました。

小課題 c では、真の効果を自分で決めたデータでこれを再現します。

```r
set.seed(39)
sim <- tibble(ability = rnorm(1000),
              educ = 14 + ability + rnorm(1000, sd = 1.5),
              lw = 7 + 0.05 * educ + 0.1 * ability + rnorm(1000, sd = 0.2))
```

能力 `ability` の高い人ほど教育年数が長く、能力そのものも時給を高めます。教育の真の効果は0.05です。能力を入れない回帰では教育の係数が約0.085と大きく出て、能力を入れると約0.056と、0.05に近づきます。今度は入れ忘れた変数が教育と**正の**相関をもつので、係数は上にずれます。経験年数の例とは逆向きです。

## 「他の条件を一定」の限界

重回帰で一定にできるのは、モデルに入れて**観測できる**変数だけです。実際のデータでは能力は観測できません。そのため、重回帰の係数も能力などによるバイアスを含んでいる可能性があります。係数は「他の条件を一定とした差」であって、因果効果とは限りません。この問題に正面から取り組むのが、第7・8部の因果推論です。

## 卒論・実務での使いどころ

卒論では、単回帰と重回帰の係数を並べ、「何をそろえると係数がどう変わったか」を説明すると説得力が増します。そらまめマーケットの人事部が学歴手当を考えるときも、経験年数の違いをそろえた差を見ないと、学歴の差を小さく見誤るおそれがあります。
