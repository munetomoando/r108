## 問い

第9部では、月ごと・四半期ごとに並んだ**時系列データ**を扱い、最後に来年の失業率を予測します。最初の問いは「失業率は前年同月より上がったか」です。景気の新聞記事は「前月より0.1ポイント上昇」「前年同月比0.2%増」のように、過去の値と比べて書かれます。この比べ方を R で作れるようにします。景気指標を自分で読めると、企業の需要予測や採用計画を立てるときにも役に立ちます。

## 使うデータ

`lfs` は、総務省統計局「労働力調査」の長期時系列（表1-a-1、2026年8月分公表時点で取得）から作った、2000年1月から2026年8月までの320か月の表です。第20ステップで使ったものと同じです。

- `unemp_rate_sa` … 完全失業率（％）の季節調整値。季節による上下を取り除いた値です
- `unemp_rate_nsa` … 完全失業率（％）の原数値。調べたままの値です
- `employed_10k` … 就業者数（万人、原数値）

季節調整値は毎年1月分の公表時に過去にさかのぼって改定されます。そのため、当時の報道の値と0.1ポイントほど違う月があります。

## 1か月前の値を横に並べる：lag

時系列の表では、1行が1か月で、上から古い順に並んでいます。`lag()`（dplyr）は列の値を1行ずつ下にずらします。並びが古い順なので、ずらした値は「1か月前の値」になります。

```r
lfs_m <- lfs |>
  mutate(prev_sa = lag(unemp_rate_sa),
         diff_sa = unemp_rate_sa - prev_sa)
```

最初の月（2000年1月）には前の月がないので、`prev_sa` は `NA` になります。`lag()` を使う前には、次の2点を確かめます。

- 表が日付の古い順に並んでいるか（並んでいなければ `arrange(date)` で並べる）
- 途中の月が抜けていないか（抜けていると、1行前が1か月前ではなくなる）

`lfs` は320行で、2000年1月から2026年8月までちょうど320か月なので、抜けはありません。

## 前年同月と比べる

前の月と比べるときは**季節調整値**を使います。原数値のまま比べると、例えば3月から4月に上がった分が、景気によるのか、毎年の季節の動きなのかを区別できないからです。

一方、**前年の同じ月**と比べれば、季節の影響はほぼ同じなので、原数値のまま比べられます。12か月前の値は `lag(列, 12)` で取り出せます。

```r
lfs_yoy <- lfs |>
  mutate(yoy_diff = unemp_rate_nsa - lag(unemp_rate_nsa, 12),
         emp_yoy = (employed_10k / lag(employed_10k, 12) - 1) * 100)
```

ここで、比べ方を2通りに分けています。

- **前年同月差**（ポイント）… 失業率のように、もともと％で表す値は差をとります。2.4%から2.6%なら「0.2ポイント上昇」です。「0.2%上昇」とは書きません
- **前年同月比**（％）… 就業者数のように、人数や金額で表す値は比をとります。6,835万人から6,849万人なら約0.2%増です

b を実行すると、2026年1〜3月は前年同月より0.2〜0.3ポイント高く、4月以降は前年と同じ水準だったことが分かります。2026年8月は原数値で2.6%、前年同月も2.6%でした。就業者数の前年同月比は、2026年1月にわずかなマイナス（約−0.04%）になったほかは、0〜1%ほどの増加でした。

## 図で見る

前年同月差は、0 の水平線を引いた折れ線にすると、上がった時期と下がった時期が一目で分かります。

```r
lfs_recent <- filter(lfs_yoy, date >= ymd("2019-01-01"))
ggplot(lfs_recent, aes(x = date, y = yoy_diff)) +
  geom_line() +
  geom_hline(yintercept = 0)
```

2020年5月から2021年2月までは前年同月より0.5〜0.7ポイント高い月が続き、コロナ禍の影響が表れています。ただし、全期間で最も大きく上がったのはリーマン・ショック後の2009年7月で、前年同月より1.6ポイント高くなりました。

## 月次から年へ集計する

年ごとの平均は、第15ステップの `year()` と `group_by()`・`summarise()` で作れます。月数も数えておきます。

```r
lfs |>
  group_by(year = year(date)) |>
  summarise(unemp_mean = mean(unemp_rate_nsa), months = n())
```

2026年は8か月分しかありません。原数値は春に高く年末に低いので、1〜8月だけの平均は、12か月の平均より高めに出やすくなります。途中までの年を他の年と比べるときは、季節調整値の平均を使うか、前年の同じ期間（1〜8月）どうしで比べます。

## 卒論・実務での使いどころ

前月差は季節調整値で、前年同月差・比は原数値で計算するという使い分けは、卒論で景気指標を引用するときにも、自社の売上を「前年同月比」で報告するときにもそのまま使えます。
