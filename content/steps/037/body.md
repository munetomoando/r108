## 問い

教育年数が1年長い人は、時給が何%高いのでしょうか。第29ステップでは相関係数で「一緒に動く度合い」を測りました。今回は**回帰分析**で、「1年あたりどれだけ違うか」という大きさを1つの数字で表します。

## 使うデータ

第21ステップから使っている賃金調査風の**架空のデータ** `wage`（3,000人）を使います。教材用に乱数で作ったもので、実在の人や調査の値ではありません。教育年数 `educ_years` は12・14・16・18年の4種類です。まず教育年数ごとに時給を集計してみましょう（小課題 e）。平均時給は12年で約1,784円、16年で約2,278円と、教育年数が長いほど高くなっています。

## 直線を当てはめる：lm()

**単回帰**は、説明したい変数 $y$（被説明変数）を、1つの変数 $x$（説明変数）の直線で表す方法です。

$$y = \beta_0 + \beta_1 x + u$$

$\beta_0$ は切片、$\beta_1$ は傾き、$u$ は直線では説明できない残り（誤差）です。R では `lm()`（linear model の略）で推定します。

```r
m <- lm(log_wage ~ educ_years, data = wage)
m
coef(m)
```

`~` の左に被説明変数、右に説明変数を書きます。`coef()` は推定した係数を取り出す関数です。このデータでは切片が約6.858、傾きが約0.0489になります。「教育年数が1年長いと、対数時給が平均で約0.049高い」という意味です。

被説明変数を時給そのもの（`hourly_wage`）でなく、対数時給 `log_wage` にしたのには理由があります。賃金は「何円高いか」より「何%高いか」で考えるほうが自然です。時給1,000円の人の100円と、時給5,000円の人の100円では重みが違うからです。

## 係数を%で読む：exp()

対数の差は、比率のおおよその目安になります。係数0.049なら「約4.9%高い」と読めます。ただしこれは係数が小さいときの近似です。正確な%は次の式で求めます。

$$(e^{\beta_1} - 1) \times 100$$

```r
b_educ <- coef(m)[["educ_years"]]
(exp(b_educ) - 1) * 100
```

`exp()` は $e$（約2.718）の何乗かを計算する関数で、`log()` の逆の働きをします。結果は約5.01%です。係数が0.3を超えるような大きな値だと、近似と正確な値の差が大きくなるので注意しましょう。

このデータは、作るときに「他の条件が同じなら教育1年で対数時給が0.07高い」と決めてあります。単回帰の0.049はそれより小さくなっています。なぜずれるのかは第39ステップで考えます。

## 予測値：predict()

推定した直線を使うと、教育年数16年の人の対数時給を予測できます。

```r
pred16 <- predict(m, newdata = tibble(educ_years = 16))
exp(pred16)
```

`newdata` には、予測したい人の説明変数を、モデルと同じ列名の表で渡します。予測値は対数時給で約7.640、`exp()` で円に戻すと約2,081円です。16年の人の実際の平均時給（約2,278円）より低く、中央値（2,097円）に近い値です。回帰の予測値は「対数時給の平均」の予測で、対数の平均を `exp()` で戻した値はもとの平均より小さくなるからです。右に裾の長い時給の分布では、その値は中央値に近くなります。

## 係数は「因果効果」とは限らない

傾き0.049は、教育年数の違う人どうしを比べたときの差です。教育年数の長い人は、経験年数や能力など他の点でも違っているかもしれません。その違いも含んだ差なので、「教育を1年延ばせば時給が5%上がる」とは言えません。また、決定係数（$R^2$、第38ステップ）は約0.057で、時給の個人差の大部分は教育年数だけでは説明できません。

## 卒論・実務での使いどころ

卒論で「Xが1単位違うとYは何%違うか」を示すときの出発点が単回帰です。そらまめマーケットの人事部が時給テーブルを見直すときも、まず学歴や勤続年数ごとの差を回帰で1つの数字にまとめると、議論の土台になります。
