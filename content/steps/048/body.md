## 問い

第47ステップでは、6歳未満の子どもがいる女性ほど働いていないらしいことが、記述統計表から見えてきました。では、教育年数・年齢・夫などの所得といった条件をそろえると、小さな子どもが1人増えるごとに、労働参加の確率はどれだけ下がるのでしょうか。Wooldridge の教科書の第7章にある線形確率モデルの推定（第7版の式(7.29)。版によって式番号が違うことがあります）を再現しながら考えます。

## 線形確率モデル

被説明変数が「働いている（1）か、いない（0）か」のようなダミー変数でも、`lm()` でそのまま回帰できます。これを**線形確率モデル**（linear probability model）といいます。0と1の平均は1の割合なので、当てはめ値は「働いている確率」と読めます。

```r
lpm <- lm(inlf ~ nwifeinc + educ + exper + I(exper^2) + age + kidslt6 + kidsge6,
          data = mroz)
coef(lpm)
```

第47ステップと違い、ここでは働いていない女性も含めた753人全員を使います。働くかどうかを説明するには、働いていない人が欠かせないからです。

`kidslt6`（6歳未満の子どもの数）の係数は約 −0.262 です。ほかの条件が同じなら、小さな子どもが1人増えると、労働参加の確率は約0.262（26.2%ポイント）下がると読みます。教育年数は約0.038、6〜18歳の子ども `kidsge6` は約0.013 で、決定係数は約0.264 です。どれも教科書の値と一致します。

線形確率モデルは係数をそのまま確率の変化として読めるのが長所です。一方で、直線なので、条件によっては確率がマイナスや1を超える値になります。`fitted(lpm)` を見ると、753人のうち16人が0未満、17人が1を超えています。

## ロジットモデル

確率を必ず0と1の間に収めるには、S 字の曲線を当てはめる**ロジットモデル**を使います。R では `glm()`（一般化線形モデル）に `family = binomial` を付けます。

```r
logit <- glm(inlf ~ nwifeinc + educ + exper + I(exper^2) + age + kidslt6 + kidsge6,
             data = mroz, family = binomial)
coef(logit)
```

`kidslt6` の係数は約 −1.443 です。この値は確率の変化ではなく、**対数オッズ**（働く確率 ÷ 働かない確率 の対数）の変化です。符号（マイナス）と有意かどうかは読めますが、大きさを線形確率モデルの −0.262 と直接比べてはいけません。大きさを伝えるには、次の予測確率を使います。

## 予測確率で比べる

ほかの条件を「夫などの所得20千ドル、教育12年、経験10年、40歳、6〜18歳の子ども1人」にそろえ、6歳未満の子どもの数だけを0・1・2と変えた女性を考えます。

```r
new <- tibble(nwifeinc = 20, educ = 12, exper = 10, age = 40, kidsge6 = 1,
              kidslt6 = c(0, 1, 2))
predict(lpm, new)
predict(logit, new, type = "response")
```

`type = "response"` を付けると、ロジットの予測値が対数オッズではなく確率で出ます。結果は次のとおりです。

| 6歳未満の子ども | 線形確率モデル | ロジット |
| --- | --- | --- |
| 0人 | 約0.678 | 約0.718 |
| 1人 | 約0.416 | 約0.376 |
| 2人 | 約0.154 | 約0.124 |

0人と2人の差は、線形確率モデルで約0.52、ロジットで約0.59です。どちらのモデルでも、小さな子どもが2人いると、働く確率は7割前後から1〜2割まで下がります。線形確率モデルでは1人ごとの下がり幅がいつも同じ（約0.262）ですが、ロジットでは出発点の確率によって下がり幅が変わります。

ただし、これは「他の条件をそろえた差」です。子どもを持つかどうかは、働きたい気持ちや家族の事情とも関係していて、データにない違いが混ざっている可能性があります。「子どもが生まれると働かなくなる」という因果の主張には、第7部の手法が必要です。

## 卒論・実務での使いどころ

卒論で0か1の結果（就職したか、進学したか、購入したか）を分析するときは、線形確率モデルとロジットの両方を推定し、結論が変わらないことを示します。実務で「ある条件の顧客が購入する確率」を説明するときも、係数ではなく予測確率の表にすると伝わりやすくなります。
