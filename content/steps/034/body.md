## 問い

女性は男性より非正規雇用（パート・アルバイト・契約社員など）で働く割合が高いのでしょうか。性別と雇用形態という2つの「区分」の関係を、クロス表とカイ二乗検定で調べます。

## 使うデータ

このステップの `wage` は、第21ステップから使っている賃金調査風の**架空のデータ**（3,000人）です。教材用に乱数で作ったもので、実在の人や調査の値ではありません。setup で、0/1 の列を読みやすくした次の2列を足してあります。

- `sex` … `female` が1なら "女性"、0なら "男性"
- `emp` … `regular` が1なら "正規"、0なら "非正規"

これまで扱ってきた時給は「数の大きさ」に意味がある変数でした。性別や雇用形態は「どの区分に入るか」を表す変数で、**カテゴリ変数**（質的変数）と呼びます。カテゴリ変数どうしの関係は、平均や相関ではなく、組み合わせごとの人数で見ます。

## クロス表を作る（table）

`table()` に2つの列を渡すと、1つ目を行、2つ目を列にした**クロス表**（分割表）ができます。各マスは、その組み合わせに当てはまる人数です。

```r
tab <- table(wage$sex, wage$emp)
tab
```

実行すると、女性は正規843人・非正規658人、男性は正規1208人・非正規291人と分かります。`table()` の結果は data.frame ではなく、table という種類の表です。`tab["女性", "非正規"]` のように、行と列の名前で1つのマスを取り出せます。

## 行の割合にする（prop.table）

女性と男性では人数が少し違うので、人数のままでは比べにくくなります。そこで、行ごとに合計が1になるように割合へ直します。

```r
prop.table(tab, margin = 1)
round(prop.table(tab, margin = 1), 3)
```

`margin = 1` は行ごと、`margin = 2` は列ごと、指定しなければ全体（3,000人）に対する割合です。問いは「女性の中で非正規は何割か」なので行ごとです。非正規の割合は女性で約43.8%、男性で約19.4%で、女性のほうが2倍以上高くなっています。

同じ割合は、これまでに学んだ `count()` と `group_by()` でも出せます。結果が data.frame になるので、続けて図にしたり絞り込んだりするときに便利です。

```r
wage |>
  count(sex, emp) |>
  group_by(sex) |>
  mutate(share = n / sum(n))
```

`count()` で組み合わせごとの人数 `n` を数え、性別ごとに `n / sum(n)` を計算しています。`share` の列が `prop.table(tab, margin = 1)` と同じ値になることを確かめましょう。

## カイ二乗検定（chisq.test）

手元の3,000人で差があっても、それが標本の偶然でたまたま出ただけかもしれません。そこで検定を使います。帰無仮説は「性別と雇用形態は無関係（独立）」です。無関係なら、女性でも男性でも非正規の割合は同じはずで、そのときに各マスに期待される人数を計算できます。**カイ二乗検定**は、実際の人数と期待される人数のずれをまとめた値（カイ二乗値）を使います。

$$\chi^2 = \sum \frac{(\text{実際の人数} - \text{期待される人数})^2}{\text{期待される人数}}$$

ずれが大きいほどカイ二乗値は大きくなり、p値は小さくなります。

```r
res <- chisq.test(tab)
res
res$p.value
```

2行×2列の表では、R は既定で「イェーツの連続性補正」という小さな調整をします。結果は X-squared = 205.75、p値は `p-value < 2.2e-16` と表示されます。これは、R が既定で表示する下限（2.2×10⁻¹⁶）より小さいという意味で、`res$p.value` で取り出すと 1.16e-46 というきわめて小さな値です。性別と雇用形態が無関係なら、これほど大きな偏りが偶然に出ることはまず考えられません。ただし、p値は「帰無仮説が正しい確率」ではありません。

`chisq.test()` には、割合ではなく必ず**人数**の表を渡します。割合の表を渡すと、各行に1人ずつ、全部で2人しかいない表として計算され、まったく違う結果になります。

## 結果の書き方

報告では、①割合の差そのもの、②検定の結果、③言えないこと、の順に書きます。「非正規の割合は女性で約44%、男性で約19%だった（カイ二乗検定、p < 0.001）」がその基本形です。そのうえで、関連は因果ではないことを添えます。女性に非正規が多い背景には、年齢・学歴・産業・家庭での役割分担など、さまざまな要因がありうるからです。

## 卒論・実務での使いどころ

アンケートの「年代×満足度」や、そらまめマーケットの「店舗の立地×パート比率」のように、区分どうしの関係を示すときは、クロス表の行の割合を示し、カイ二乗検定のp値を添えるのが基本の形です。
