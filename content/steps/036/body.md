## 問い

女性の時給は男性よりどれくらい低いのでしょうか。その差は、標本の偶然では説明できないほど大きいのでしょうか。第4部の総合演習として、記述統計・信頼区間・検定・分布の図を組み合わせ、男女間の賃金格差を1つの結論にまとめます。

## 使うデータと手順

使うのは、第21ステップから使ってきた賃金調査風の**架空のデータ** `wage`（3,000人）です。教材用に乱数で作ったもので、実在の人や調査の値ではありません。setup で、`female`（1=女性、0=男性）を "女性"・"男性" のラベルにした列 `sex` を足してあります。

分析は次の4段で進めます。どれも第28〜35ステップで学んだ道具です。

1. 平均と中央値で差の大きさをつかむ（第28ステップ）
2. 差の95%信頼区間を求める（第32ステップ）
3. 検定で「偶然で説明できるか」を確かめる（第33ステップ）
4. 分布の図で、差がどこから来ているかを見る（第21ステップ）

## 差の大きさ：平均と中央値

```r
wage |>
  group_by(sex) |>
  summarise(mean_wage = mean(hourly_wage), median_wage = median(hourly_wage), n = n())
```

女性の平均時給は約1,906円、男性は約2,248円で、差は約342円です。女性の平均は男性の約84.8%になります。中央値は女性1,776円、男性2,075円で、差は299円（女性は男性の約85.6%）です。時給は右に裾が長い分布なので、平均は一部の高い時給に引っ張られます。平均と中央値の両方を示すと、差が一部の人だけの話ではないことが伝わります。

## 信頼区間と検定

```r
tt <- t.test(hourly_wage ~ female, data = wage)
tt$conf.int
tt$p.value
```

`female` は0が男性、1が女性なので、`t.test()` が示すのは「男性の平均 − 女性の平均」です。差の95%信頼区間は約281〜403円で、0を含みません。p値は1.5e-27ときわめて小さく、男女の平均に差がないとしたら、これほどの差が標本の偶然で出ることはまず考えられません。

信頼区間の読み方に注意しましょう。「母集団の差がこの区間に入る確率が95%」ではありません。同じやり方で標本をとって区間を作ることをくり返すと、そのうち約95%の区間が本当の差を含む、という意味です（第32ステップ）。

対数時給 `log_wage` でも検定すると、平均の差は約0.156です。対数の差は比率のおおよその目安になり、女性の時給はおよそ15%低いと読めます（正確には $e^{-0.156} \approx 0.856$ で、約14%低い）。第33ステップの置換検定でも同じ結論になるか、試してみるとよいでしょう。

## 分布の図

```r
ggplot(wage, aes(x = hourly_wage, fill = sex)) +
  geom_density(alpha = 0.4)
```

2つの山を重ねると、女性の分布が全体に左（低い側）へずれていること、それでも重なりが大きく、女性より時給の低い男性も多いことが分かります。平均の差は「グループ全体の傾向」であって、1人ひとりの比較ではありません。

## 「生の差」の読み方

ここで求めた約342円（約15%）は、男女の条件をそろえずに比べた**生の差**です。男女で学歴・経験年数・勤め先の企業規模・雇用形態などが違えば、その違いもこの差に含まれます。たとえば第34ステップで見たように、このデータでは非正規雇用の割合が女性約44%、男性約19%と大きく違い、非正規の時給は低めです。

```r
wage |>
  group_by(sex) |>
  summarise(educ = mean(educ_years), exper = mean(exper), regular = mean(regular))
```

教育年数と経験年数の平均は男女でほぼ同じですが、正規の割合は大きく違います。では、学歴・経験・雇用形態が同じ男女を比べると、差はどれくらい残るのでしょうか。それを調べるのが第5部の回帰分析です。

## 卒論・実務での使いどころ

格差を報告するときは、平均と中央値・信頼区間・検定・分布の図をそろえて示し、「生の差」と「条件をそろえた差」を区別して書きます。そらまめマーケットでパートの時給体系を見直すときも、同じ手順で男女や店舗の差を確かめられます。
