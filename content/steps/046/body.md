## 問い

卒論で最初につまずくのは、分析の手法よりも「問い」です。「最低賃金について調べたい」は題材であって、問いではありません。データで答えを出せる問いとは、どんな形をしているのでしょうか。

## 問いの3つの類型

実証分析の問いは、おおむね次の3つに分けられます。

| 類型 | 何を問うか | 例 |
| --- | --- | --- |
| 記述 | いま・過去に何が起きているか。その大きさや差、推移 | 男女間の賃金格差は、この20年でどれだけ縮まったか |
| 因果 | X を変えたら Y はどう変わるか（もし〜だったら） | 最低賃金を引き上げると、10代の就業率は下がるか |
| 予測 | まだ観察していない Y の値はいくらか | 来月の店舗別の売上はいくらになりそうか |

見分けるこつは、文末と「変える」という言葉です。「いくらか」「どれだけ」は記述、「〜すると…は変わるか」は因果、「〜になりそうか」は予測の問いです。

記述は易しい問いだと思われがちですが、そうではありません。正確な定義でデータを集計し、差や推移を示すだけで、世の中の思い込みを正せることがあります。第2〜4部で学んだ集計・図・信頼区間は、どれも記述の道具です。

因果と予測は似て見えますが、目的が違います。予測は当たればよく、X が Y の原因かどうかは問いません。傘の売上から雨の日の来店者数を予測できても、傘を売れば雨が降るわけではありません。因果の問いでは、X 以外の条件をそろえた比較が必要です。

## 同じデータでも、問いによって手法が変わる

第37〜44ステップの架空の賃金調査 `wage` で、3つの類型の問いを立ててみます。

```r
# 記述：男女で対数時給の平均はどれだけ違うか
wage |> group_by(female) |> summarise(平均 = mean(log_wage))

# 因果に近づける：学歴・経験・勤続が同じ人どうしで比べると、差はどうなるか
lm(log_wage ~ female + educ_years + exper + I(exper^2) + tenure, data = wage)

# 予測：教育16年・経験10年・勤続5年の女性の対数時給はいくらか
m <- lm(log_wage ~ female + educ_years + exper + I(exper^2) + tenure, data = wage)
predict(m, tibble(female = 1, educ_years = 16, exper = 10, tenure = 5))
```

2つ目の回帰は、条件をそろえて比べるので記述より一歩因果に近づきます。それでも、データにない違い（職種や能力など）は残ります。因果の問いに正面から答える手法（実験、差の差分析、操作変数など）は第7・8部で、予測の精度の確かめ方は第9部と第11部で学びます。

## 問い・データ・手法を対応させる

問いを立てたら、次の4つを書き出します。

- **問い**：疑問文で1文。答えが「はい・いいえ」か数値になる形
- **類型**：記述・因果・予測のどれか
- **データ**：何のデータで、1行が何を表すか（個人・企業・都道府県×年など）
- **手法**：集計・図・回帰・差の差分析など

特に大事なのが「1行が何か」です。都道府県ごとの平均しかないデータで「大学に進学した**人**は賃金が高いか」と問うことはできません。県単位の関係を個人の関係と読み違えることを、**生態学的誤謬**（せいたいがくてきごびゅう）といいます。問いの主語（人・企業・地域）と、データの1行の単位をそろえましょう。

また、因果の問いには、比べる相手が要ります。「奨学金を受けた人の所得」だけを集めても、受けなかったらどうだったかが分からなければ効果は測れません。

## 卒論・実務での使いどころ

卒論の指導で最初に見せる1枚は、この4行（問い・類型・データ・手法）です。社内の分析依頼でも、依頼が記述・因果・予測のどれかを最初に確かめておくと、必要なデータと手法を取り違えずにすみます。
