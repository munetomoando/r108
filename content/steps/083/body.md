## 問い

第82ステップの報告を聞いた上司から、次の質問が来ました。「12月が11月より多いのは毎年のことだろう。去年の12月と比べてどうなのか。伸びたのは客数なのか、単価なのか」。前年同月と比べ、売上の伸びを客数・客単価・カテゴリの**寄与度**に分けて答えます。

## 前年同月と比べる

第82ステップで見たとおり、12月は年末の需要で売上が膨らみます。季節の影響を除いて「去年より伸びたか」を知るには、前年の同じ月と比べます（第73ステップ）。`kpi` は2024年1月から古い順に1か月1行なので、12行前が前年同月です。

```r
kpi_yoy <- kpi |>
  mutate(spend = sales / buyers,
         sales_yoy = (sales / lag(sales, 12) - 1) * 100,
         buyers_yoy = (buyers / lag(buyers, 12) - 1) * 100,
         spend_yoy = (spend / lag(spend, 12) - 1) * 100)
```

2025年12月の売上は約991万円で、前年12月（約870万円）より約14.0%多くなりました。客数は2,019人から2,374人へ約17.6%増え、客単価は約4,307円から約4,174円へ約3.1%下がっています。

## 客数と客単価の寄与度

売上 = 客数 × 客単価 なので、伸び率を $g$ と書くと

$$1 + g_{\text{売上}} = (1 + g_{\text{客数}})(1 + g_{\text{客単価}})$$

です。右辺を展開すると、売上の伸びは「客数の伸び＋客単価の伸び＋両者の積（**交差項**）」に分かれます。

```r
contrib <- kpi_yoy |>
  filter(ym >= ymd("2025-01-01")) |>
  mutate(cross = buyers_yoy * spend_yoy / 100,
         total = buyers_yoy + spend_yoy + cross)
```

このように、全体の伸び率を要素ごとの「何ポイント分」に分けた値を**寄与度**と呼びます。2025年12月は、客数が +17.6 ポイント、客単価が −3.1 ポイント、交差項が −0.5 ポイントで、合計が +14.0% になります。伸びは客数によるもので、客単価はむしろ足を引っ張りました。交差項は伸び率が小さいときはほぼ0ですが、伸び率が大きいと無視できません。

月ごとに見ると、1月は売上が前年の2倍以上（約 +114%）でしたが、7月は約 +55%、12月は +14.0% と、伸びは年の後半ほど小さくなっています。どの月も伸びの大部分は客数です。2024年から2025年前半にかけて新しく登録した顧客が多く、顧客の数が増え続けたことが前年比を押し上げていました。顧客マスタの登録は2025年6月で止まっており、その後は前年比の伸びが急に縮みます。「売上は伸びた」だけでなく「伸びが鈍っている」ことも報告すべき点です。

## カテゴリ別の寄与度

同じ考え方で、全体の伸びをカテゴリに分けられます。分母を「そのカテゴリの前年の売上」ではなく「前年の全体の売上」にするのがこつで、こうすると8カテゴリの寄与度を足すと全体の伸び率（+14.0%）になります。

```r
ec |>
  filter(month(ym) == 12) |>
  group_by(category) |>
  summarise(s2024 = sum(sales[year(ym) == 2024]),
            s2025 = sum(sales[year(ym) == 2025])) |>
  mutate(contrib = (s2025 - s2024) / sum(s2024) * 100)
```

`sales[year(ym) == 2024]` は、sales のうち2024年の行だけを取り出す書き方です。結果は衣料品が +4.4、食品が +3.8、飲料が +3.6 ポイントで、家電（−1.8）とキッチン用品（−0.5）は減りました。家電は1点が高く、売れた数の少しの違いで売上が大きく動くので、1か月だけで判断しないよう注意します。

## 寄与度で言えること、言えないこと

寄与度分解は、伸びがどの要素の動きと一致しているかを足し算で示す会計上の分解です。「なぜ客単価が下がったのか」「広告で客数を増やせば売上が伸びるのか」といった原因は分かりません。原因を確かめるには、第86〜88ステップの A/B テストや、第90ステップの差の差分析を使います。

## 卒論・実務での使いどころ

前年同月比を「客数 +17.6、客単価 −3.1」のように寄与度で示すと、伸びの中身が一目で伝わり、GDP 成長率の需要項目別寄与度を読むときにも同じ考え方が使えます。
