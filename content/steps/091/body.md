## 問い

第11部では**機械学習**を学びます。機械学習は、データから「当たる予測」を作るための方法の集まりです。上司からは「売上をよく当てるモデルができたら、そのモデルでチラシの枚数も決められるだろう」と言われました。本当にそうでしょうか。最初に、予測と因果の違いを確かめます。

## 予測の問いと因果の問い

仕事で出てくる問いは、大きく2つに分かれます。

- **予測の問い** … 「明日の売上はいくらか」「来月に解約しそうな顧客は誰か」。何が起こりそうかを当てれば役に立ちます。原因が何かは問いません
- **因果の問い** … 「チラシを増やすと売上はいくら増えるか」「値引きで販売数はどれだけ増えるか」。こちらが条件を変えたら、結果がどれだけ変わるかを問います

第7・8部の因果推論と第10部の A/B テストは、因果の問いに答える方法でした。第11部の機械学習は、主に予測の問いに答える方法です。予測がよく当たるモデルでも、その係数が施策の効果を表すとは限りません。シミュレーションで確かめます。

## 予測は当たるが、効果を誤るモデル

ある店舗の1,000日分のデータを乱数で作ります（第30ステップ）。店長は、給料日や地域の行事で客が多いと見込んだ日ほど、チラシを多く配ります。この「見込み客数」`demand` は記録に残っていないとします。

```r
set.seed(108)
n <- 1000
demand <- rnorm(n)                          # 見込み客数（記録に残らない）
flyer <- 10 + 2 * demand + rnorm(n)         # チラシ（千枚）。客が多い日ほど多く配る
noise <- rnorm(n, 0, 5)
sales <- 100 + 1 * flyer + 10 * demand + noise   # 売上（万円）
sim <- tibble(demand, flyer, sales)
m_pred <- lm(sales ~ flyer, data = sim)
```

本当のチラシの効果は、1千枚で1万円です。ところが `coef(m_pred)` の flyer の係数は約4.87で、決定係数 R² は約0.73です。日々の売上はよく当たりますが、チラシの効果は約5倍に見えます。

## 施策を打つとどうなるか

全部の日でチラシを2千枚ずつ増やしてみます。見込み客数と偶然の揺れはそのままです。

```r
sales_up <- 100 + 1 * (flyer + 2) + 10 * demand + noise
c(coef(m_pred)[["flyer"]] * 2, mean(sales_up - sales))
```

モデルからは約9.7万円の増加を見込めますが、実際の増加は2万円です。チラシが多い日は、もともと客が多い日です。flyer の係数には、チラシの効果と、見込み客数の効果が混ざっています。これは第7部で学んだ**交絡**（欠落変数のバイアス）です。データを増やしても、この偏りは小さくなりません。

もし見込み客数を測れていれば、`lm(sales ~ flyer + demand, data = sim)` で flyer の係数は約0.93になり、本当の効果に近づきます（第92ステップの復習で確かめます）。しかし、交絡するものをすべて測れることはまれです。施策の効果を知りたいときは、チラシを配る日を無作為に決める実験や、差の差分析のような方法を使います。

## 第11部で学ぶこと

予測のモデルを作るときに大切なのは、**まだ見ていないデータでどれだけ当たるか**です。第92〜94ステップでは店舗の日次売上で、データを訓練用とテスト用に分ける考え方、tidymodels というパッケージでのモデルづくり、交差検証を学びます。第95〜99ステップでは、ネット通販の顧客のデータで、解約しそうな顧客を見つける分類のモデルを作ります。どのステップでも、予測に効く変数は「動かせば結果が変わる変数」とは限らない、ということを忘れないでください。

## 卒論・実務での使いどころ

分析を始める前に、問いが「当てたい」のか「施策の効果を知りたい」のかを決め、予測なら機械学習、効果なら実験や因果推論の方法を選びます。
