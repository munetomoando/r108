## 問い

そらまめマーケットの販促担当が、20種類のチラシを1つずつ試し、「有意な効果があったチラシ」を探しています。本当はどのチラシにも効果がないとき、何が起きるでしょうか。シミュレーションで確かめ、p値の誤用と、効果を見逃さないための標本サイズの考え方を学びます。

## 効果のないチラシを20種類試す

このステップの小課題 a〜d は、実際のデータではなく乱数で作った架空の購入額を使います。チラシを配った客100人と配らなかった客100人の購入額を、どちらも平均3,000円・標準偏差1,000円の正規分布から作ります。2群の平均は同じなので、どのチラシにも効果はありません。

```r
set.seed(108)
pvals <- replicate(20, {
  flyer <- rnorm(100, mean = 3000, sd = 1000)
  none <- rnorm(100, mean = 3000, sd = 1000)
  t.test(flyer, none)$p.value
})
sum(pvals < 0.05)
any(pvals < 0.05)
```

`replicate()`（第30ステップ）は `{ }` の中を20回くり返し、最後の行の値（p値）を集めます。`any()` は、論理値のベクトルの中に TRUE が1つでもあれば TRUE を返す関数で、「1つでも有意なチラシがあったか」を調べられます。

`set.seed(108)` のとき、20種類のうち12番目と19番目の2種類が5%水準で「有意」になります。効果がないと分かっているのに、です。

## 多重比較：検定をくり返すと「有意」は偶然に出る

有意水準5%の検定は、効果がないときにも5%の確率で「有意」と判定します。1回だけなら小さな確率ですが、20回くり返すと、少なくとも1回は「有意」が出る確率は次のようになります。

$$1 - 0.95^{20} \approx 0.64$$

つまり約64%です。たくさん試して「有意」なものだけを報告すると、効果のないものを効果ありと見誤ります。これを**多重比較**の問題といいます。上のシミュレーションを1,000回くり返して確かめることもできます（数秒かかります）。

```r
set.seed(108)
hit <- replicate(1000, {
  p <- replicate(20, t.test(rnorm(100, 3000, 1000), rnorm(100, 3000, 1000))$p.value)
  any(p < 0.05)
})
mean(hit)
```

結果は0.643で、計算どおり約64%になります。対策は、①試す前に何と何を比べるかを決めておく、②検定の回数に応じて基準を厳しくする（20回なら 0.05 ÷ 20 = 0.0025 を使うボンフェローニ補正）、③「有意」だったものを別の店舗や別の月でもう一度試す、の3つです。

## 検出力と必要な標本サイズ（power.t.test）

逆の失敗もあります。本当に効果があるのに「有意」にならず見逃すことです。本当に差があるときに「有意」と判定できる確率を**検出力**といいます。検出力は、差の大きさ、ばらつき（標準偏差）、人数で決まります。

チラシで購入額が平均200円上がるとき、1群100人で調べた場合の検出力は、`power.t.test()` で計算できます。

```r
power.t.test(n = 100, delta = 200, sd = 1000)$power
```

約0.29で、本当に効果があっても7割は見逃してしまいます。検出力を80%にするには何人必要かは、`n` を書かずに `power = 0.8` を渡すと計算できます（小課題 c）。結果は1群あたり約393.4人、つまり394人ずつです。見つけたい差を半分の100円にすると、必要な人数は約1,571人と4倍になります。人数は差の2乗に反比例するからです。試す前にこの計算をして、調べる人数を決めておくのが正しい手順です。

## 有意と重要は違う

「統計的に有意」は「差が0とは考えにくい」という意味で、「差が大きい」「役に立つ」という意味ではありません。p値は差の大きさだけでなく人数でも決まるため、10万人ずつ比べれば、平均10円の差でもp値は約0.025になります。判断には、差の大きさ（何円か）と信頼区間、そして施策の費用を必ず並べて示します。

## 卒論・実務での使いどころ

キャンペーンや政策の効果を検定で示すときは、比べる組み合わせと必要な人数を事前に決め、p値だけでなく効果の大きさと信頼区間を報告します。
