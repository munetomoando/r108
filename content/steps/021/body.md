## 問い

働く人の時給は、平均のあたりに左右対称に集まっているのでしょうか。それとも偏った形をしているのでしょうか。3,000人分の時給を図にして、分布（値がどのあたりにどれだけあるか）の形を確かめます。

## 使うデータ

`wage` は、賃金調査の個票（1人1行の回答）を模した**架空のデータ**です。教材用に乱数で作ったもので、実在の人や調査の値ではありません。このステップで使う列は次のとおりです。

- `hourly_wage` … 時給（円）
- `female` … 女性なら1、男性なら0
- `firm_size` … 勤め先の企業規模（〜29人・30〜299人・300〜999人・1000人以上）
- `age` … 年齢（歳）

## ヒストグラムと密度曲線

**ヒストグラム**は、横軸の値をいくつかの区間（ビン）に分け、区間に入る人数を棒の高さで表す図です。`aes()` には横軸だけを書きます。人数は `geom_histogram()` が自動で数えます。`binwidth` は1本の棒の幅で、100なら100円きざみです。

```r
ggplot(wage, aes(x = hourly_wage)) + geom_histogram(binwidth = 100)
```

`binwidth` を指定しないと、全体を30本に分けたうえで「よりよい値を選びましょう」という案内が出ます。幅を変えると見え方が変わるので、いくつか試すとよいでしょう。

`geom_density()` は、ヒストグラムの棒の頭をなめらかにつないだような**密度曲線**を描きます。縦軸は人数ではなく、曲線の下の面積が全体で1になるように調整した値です。

```r
ggplot(wage, aes(x = hourly_wage)) + geom_density()
```

図を見ると、山は左寄りにあり、右側に長い裾が伸びています。これを**右に裾が長い分布**と呼びます。`summary()` で確かめると、中央値（真ん中の人の値）は1,900円、平均は約2,077円で、平均のほうが高くなっています。最も高い人は8,594円です。少数の高い時給が、平均を右へ引っ張っているのです。

## 箱ひげ図でグループを比べる

**箱ひげ図**は、分布を5つほどの数で要約した図です。箱の真ん中の線が中央値、箱の下端と上端が下から25%と75%の位置（四分位）です。箱から伸びる線（ひげ）の先より外にある値は、点で1つずつ描かれます。

男女を比べるために、まず `female` を文字のラベルに直します。第5ステップの `if_else()` です。横軸に文字の列を当てると、その値ごとに箱が並びます。

```r
wage2 <- mutate(wage, sex = if_else(female == 1, "女性", "男性"))
ggplot(wage2, aes(x = sex, y = hourly_wage)) + geom_boxplot()
```

このデータでは、時給の中央値は男性が2,075円、女性が1,776円です。どちらの箱も、上側のひげと点が長く伸びています。男女どちらでも右に裾が長い形だと分かります。

## 図を分割する facet_wrap と水準の順

グループごとに同じ図を並べたいときは、`facet_wrap(~ 列名)` を足します。`~` は「この列で分ける」という印です。

ただし、`firm_size` は文字の列なので、そのまま分割すると文字の並べ替えの規則で「1000人以上」が先に来るなど、規模の順になりません。そこで `factor()` で**因子**（決まった水準と順序をもつ列）に直し、`levels` に並べたい順を渡します。

```r
size_levels <- c("〜29人", "30〜299人", "300〜999人", "1000人以上")
wage2 <- mutate(wage2, firm_size = factor(firm_size, levels = size_levels))
ggplot(wage2, aes(x = hourly_wage)) +
  geom_histogram(binwidth = 100) +
  facet_wrap(~ firm_size)
```

企業規模が大きいほど分布が少し右にずれ、中央値は「〜29人」の約1,790円に対し「1000人以上」では2,132円です。一方で、どの規模でも分布は大きく重なっています。平均の差だけでは見えない重なりが、分布の図なら一目で分かります。

## 卒論・実務での使いどころ

パートの時給を決めるときも、賃金の格差を卒論で論じるときも、平均だけでなく分布の形と重なりを図で確かめてから数字を選ぶと、典型的な人の姿を見誤らずにすみます。
