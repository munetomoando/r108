## 問い

2020年春、新型コロナウイルスの感染拡大で、日本の生産と雇用はどう動いたでしょうか。実質GDPと失業率を折れ線グラフに描いて確かめます。景気の動きは、店の売上や、人を採るときの環境に直接響きます。景気指標の折れ線を自分で描いて読めると、「いまは売上が落ちやすい時期か」「人が集まりやすい時期か」を判断する材料になります。

## 使うデータ

このステップでは、公的統計の2つの表を使います。

- `gdp` … 内閣府「四半期別GDP速報」（2026年4–6月期2次速報、2026年9月8日公表）の実質GDP。1994年1–3月期から2026年4–6月期までの130四半期です
  - `quarter` … 四半期の初日の日付（4–6月期なら4月1日）
  - `real_gdp` … 実質GDP（兆円、2020暦年連鎖価格）。実質GDPは、物価の変化を除いた国内の生産額です。値は**年率表示**で、その四半期のペースが1年続いたときの額を表します。そのため年間のGDPと同じ500〜600兆円の桁になります
  - `growth_qoq` … 前期比（％）
- `lfs` … 総務省統計局「労働力調査」の長期時系列（2026年8月分公表時点）。2000年1月から2026年8月までの月次の表です
  - `date` … その月の1日の日付
  - `unemp_rate_sa`、`unemp_rate_nsa` … 完全失業率（％）の季節調整値と原数値。完全失業率は、働く意思があり仕事を探している人（完全失業者）が、労働力人口に占める割合です
  - `employed_10k` … 就業者数（万人、原数値）

`read_csv()` は `2020-04-01` のような列を自動で日付型（Date）として読みます。`glimpse(gdp)` で `<date>` と表示されることを確かめましょう。

## 季節調整値と原数値

**原数値**は調べたままの値です。原数値には、毎年同じ時期に起きる上下があります。例えば年末は臨時の仕事が増えるので失業率が下がりやすく、2020年12月の失業率は原数値で2.8%、季節調整値で3.1%でした。

**季節調整値**は、こうした季節による上下を統計的に取り除いた値です。前の月や前の期と比べて景気がよくなったかを見るときは、季節調整値を使います。GDPの `real_gdp` も季節調整済みです。なお、季節調整値は新しいデータが加わるたびに過去にさかのぼって改定されます。そのため、このデータの値は当時の報道の値と少し違うことがあります。

## 折れ線グラフ：geom_line

時間とともに変わる量は、横軸に時間をとった**折れ線グラフ**で見せます。第19ステップの散布図の `geom_point()` を `geom_line()` に替えると、横軸の値の順に点が線で結ばれます。

```r
ggplot(gdp, aes(x = quarter, y = real_gdp)) + geom_line()
```

横軸が日付型の列なので、目盛りは自動で年になります。図を見ると、2008〜2009年のリーマン・ショックと、2020年のコロナ禍に深い谷があります。

## 期間を絞り、目盛りを整える：scale_x_date

30年分の図では、2020年前後の動きが細かくて読めません。日付の列は数と同じく `>=` や `<=` で比べられるので、第15ステップの `ymd()` で作った日付と比べて `filter()` で絞ります。

```r
gdp_covid <- filter(gdp, quarter >= ymd("2019-01-01"), quarter <= ymd("2022-12-31"))
```

期間を絞ると、目盛りの間隔も指定したくなります。日付の横軸の目盛りは `scale_x_date()` で決めます。`date_breaks` は目盛りの間隔、`date_labels` は目盛りの書き方です。`%Y` は4桁の年、`%m` は2桁の月を表します。

```r
ggplot(gdp_covid, aes(x = quarter, y = real_gdp)) +
  geom_line() +
  scale_x_date(date_breaks = "6 months", date_labels = "%Y-%m")
```

この図から次のことが読み取れます。実質GDPは2019年7–9月期の584.2兆円が山でした。10–12月期には消費税率の引上げ（8%→10%）で前期比−2.9%と落ちます。2020年4–6月期には、緊急事態宣言で外出や営業が止まり、569.2兆円から528.2兆円へ前期比−7.2%と急落しました。翌7–9月期は+5.0%と反発します。それでも、2019年7–9月期の山を初めて上回るのは2023年1–3月期です。

失業率も同じように描けます。

```r
lfs_covid <- filter(lfs, date >= ymd("2019-01-01"), date <= ymd("2022-12-31"))
ggplot(lfs_covid, aes(x = date, y = unemp_rate_sa)) +
  geom_line() +
  scale_x_date(date_breaks = "6 months", date_labels = "%Y-%m")
```

失業率（季節調整値）は2020年初めの2.4%から上がり、10月と12月に3.1%になりました。その後はゆっくり下がり、2022年7月に2.5%になります。2009年7月の5.5%と比べると、コロナ禍での上がり方は小さいものでした。GDPが大きく落ちても、企業が解雇でなく休業や労働時間の短縮で対応すれば、失業率はあまり上がりません。2つの指標を並べて見ると、こうした違いに気づけます。

## 卒論・実務での使いどころ

景気指標の推移を折れ線で描き、関心のある時期に絞って見る作業は、卒論で政策や景気の影響を論じる前にも、仕事で売上の落ち込みが景気によるものかを見分けるときにも使えます。
