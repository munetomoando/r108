## 問い

第56・57ステップのRCTでは、訓練に参加するかどうかを無作為に決めていました。しかし現実の訓練の多くは、参加するかどうかを本人が選びます。そのような**観察データ**で参加者と不参加者を比べると、どれだけ外れるのでしょうか。

データは、同じ訓練の**架空の観察データ** `obs`（4,000人）です。年収の式は `training_rct` と同じで、真の効果は +30万円/年です。参加者は1,102人（27.6%）で、前年収入が低い人ほど、また若い人ほど参加しやすいように作ってあります。

## 単純比較：負になる

```r
m_raw <- lm(earn_post ~ treat, data = obs)
coef(m_raw)[["treat"]]
```

treat の係数は約−65.4万円です。単純に比べると「訓練に参加した人のほうが年収が65万円低い」ことになり、真の効果（+30万円）とは符号まで逆です。

理由は第55ステップの選択バイアスです。参加者の前年収入の平均は約191万円、不参加者は約308万円です。もともと収入の低い人が参加しているので、訓練がなかったとしても、参加者の訓練後の年収は低かったはずです。単純比較はこの差まで訓練のせいにしてしまいます。DAG で書けば、前年収入は訓練参加と年収の両方に矢印を出す交絡因子です（第58ステップ）。

## 共変量で調整する

交絡因子を回帰に入れて統制します。

```r
m_ctrl <- lm(earn_post ~ treat + prior_earn + age + I(age^2) + educ_years + female,
             data = obs)
c(coef(m_raw)[["treat"]], coef(m_ctrl)[["treat"]])
```

調整後の treat の係数は約26.9万円（標準誤差 約2.3）です。真の30万円との差は約3万円で、標準誤差の1.4倍ほどです。標本から推定するときのばらつきで説明できる大きさです。

うまくいったのは、このデータでは参加を左右した変数（前年収入と年齢）がすべて観察でき、回帰に入れたからです。この条件を**条件付き独立**（観察できる変数をそろえれば、参加するかどうかは結果と無関係に決まっている）といいます。実際のデータでは、意欲や家庭の事情のような観察できない変数も参加を左右しているかもしれません。条件付き独立はデータからは確かめられない仮定です。調整した値を因果効果と読むときは、この仮定を必ず書き添えます。

## 共通サポート：比べる相手はいるか

調整にはもう1つ条件があります。参加者と似た不参加者が、データの中に実際にいることです。前年収入の分布を群別に描きます。

```r
ggplot(obs, aes(x = prior_earn, fill = factor(treat))) +
  geom_density(alpha = 0.5)
```

`geom_density()` は分布をなめらかな曲線（**密度曲線**）で描きます。曲線の下の面積が1になるように描くので、人数の違う2つの群でも形を比べられます。`alpha = 0.5` で塗りを半透明にすると、重なりが見えます。

参加者の前年収入は最も高い人でも495万円です。不参加者には495万円を超える人が296人いて、その人たちと似た参加者は1人もいません。2つの群の分布が重なっている範囲を**共通サポート**といいます。共通サポートの外の人どうしを比べようとすると、回帰はデータのないところを式の形（直線や2次式）で補って推定します。式の形が正しくなければ、推定は外れます。このデータでは、参加者の前年収入の範囲には不参加者もいるので、参加者についての比較はできます。

## 卒論・実務での使いどころ

観察データで効果を推定するときは、単純比較と調整後の推定を並べ、処置群と対照群の分布の図で共通サポートを示し、条件付き独立の仮定が成り立つ理由を本文で説明します。
