## 問い

第39ステップでは、大事な変数を入れ忘れると係数がずれること（欠落変数バイアス）を見ました。では、手に入る変数はとにかく全部入れればよいのでしょうか。答えは「いいえ」です。入れるべき変数と、入れてはいけない変数があります。それを見分ける道具が **DAG** です。

## DAG：因果関係を矢印で描く

**DAG**（有向非巡回グラフ、directed acyclic graph）は、変数を箱で、「影響を与える」という関係を矢印で描いた図です。矢印をたどって元の変数に戻ってくる輪は作りません（非巡回）。DAG はデータから自動で出てくるものではありません。経済理論や制度の知識をもとに、分析する人が自分の仮定として描きます。

処置 X（原因と考える変数）から結果 Y への効果を知りたいとき、第3の変数の置かれ方は主に3通りあります。

## 交絡因子：統制する

![交絡の DAG。能力から教育年数と賃金へ、教育年数から賃金へ矢印がある](images/058_confounder.svg)

能力 Z は教育年数 X と賃金 Y の両方に矢印を出しています。このような変数を**交絡因子**といいます。X と Y の間には、X → Y の直接の経路のほかに、X ← Z → Y という「裏口」の経路があります。Z を統制しないと、裏口を通った見かけの関係が X の係数に混ざります。これが第39ステップの欠落変数バイアスの正体です。

小課題 b で確かめます。

```r
set.seed(58)
conf <- tibble(z = rnorm(2000),
               d = if_else(z + rnorm(2000) > 0, 1, 0),
               y = 10 + 2 * d + 3 * z + rnorm(2000))
```

z が大きい人ほど処置を受けやすく（d = 1）、z そのものも y を高めます。d の真の効果は 2 です。z を入れない回帰では d の係数が約5.26と大きくずれ、z を入れると約2.03になります。

## 中間変数：統制しない

![中間変数の DAG。教育年数から正社員と賃金へ、正社員から賃金へ矢印がある](images/058_mediator.svg)

教育を受けると正社員になりやすく、正社員になると賃金が上がる、という経路です。正社員 M は X から Y へ向かう道の途中にある**中間変数**です。教育の効果全体を知りたいのに M を統制すると、「正社員になる」という道を通った効果を取り除いてしまい、効果を小さく見積もります。第57ステップで見た「処置の後に決まる変数を入れる誤り」は、このパターンです。

## 合流点：統制しない

![合流点の DAG。技能と人脈から採用へ矢印があり、技能と人脈の間に矢印はない](images/058_collider.svg)

技能 X と人脈 Y は互いに無関係でも、どちらも採用 C に影響するとします。矢印が2本流れ込む C を**合流点**（collider）といいます。合流点は統制しなければ何も起きません。ところが C を統制すると、無関係だった X と Y の間に関係が生まれます。採用された人だけを見ると、「技能が低いのに採用された人は人脈が強いはずだ」という形で、技能と人脈が負の相関をもつからです。このずれを**合流点バイアス**といいます。

小課題 c では、x と y が無関係なデータで確かめます。

```r
set.seed(58)
coll <- tibble(x = rnorm(2000), y = rnorm(2000), cc = x + y + rnorm(2000))
```

`lm(y ~ x)` の x の係数はほぼ0（約0.003）ですが、合流点 cc を入れた `lm(y ~ x + cc)` では約−0.49になります。真の効果は0なのに、統制したせいで「x が増えると y が減る」ように見えてしまいます。回帰に入れなくても、「採用された人だけ」「調査に回答した人だけ」のようにデータを合流点で絞り込むと、同じことが起きます。

## 統制すべき変数の選び方

1. 処置 X と結果 Y の両方に影響する変数（交絡因子）は統制する
2. 処置の後に決まる変数（中間変数や合流点）は統制しない

DAG に描かなかった交絡因子が本当はある場合、この手順でも偏りは残ります。観察できる変数を統制して因果効果を読めるのは、「統制した変数以外に交絡因子はない」という仮定が成り立つときだけです。次のステップから、この仮定の下で観察データを分析します。

## 卒論・実務での使いどころ

卒論で説明変数を選ぶときは、まず DAG を描き、各変数が交絡因子か中間変数か合流点かを本文で説明すると、変数選びの理由がはっきりします。
