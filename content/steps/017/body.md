## 問い

そらまめマーケットは、新しい県への出店を考えています。店を開くには、パート・アルバイトを数十人集めなければなりません。経営企画部のあなたは「候補の県では、仕事を探している人がどのくらいいるか」を調べるよう頼まれました。目安になるのが、県ごとの**完全失業率**です。

これまでのステップでは、役所が公表した Excel や CSV を読んできました。このステップでは、政府統計の総合窓口 **e-Stat** の **API** から、プログラムでデータを取る方法を学びます。

## API とは

API（Application Programming Interface）は、プログラムからデータを問い合わせるための窓口です。ブラウザで画面を開いて表を探す代わりに、決まった形の URL を送ると、データが文字の形で返ってきます。毎月・毎年更新される統計を何度も取り直すときや、何十もの表をまとめて取るときに便利です。

e-Stat API に送る URL は、次の部分からできています。

| 部分 | 例 | 意味 |
| --- | --- | --- |
| 機能 | `json/getStatsData` | 統計データを JSON という形式で返す |
| `appId` | `YOUR_APP_ID` | 利用者ごとのアプリケーションID |
| `statsDataId` | `0000010206` | 統計表ID（どの表か） |
| `cdCat01` | `%23F01301` | 分類事項のコード（表の中のどの項目か） |
| `cdTime` | `2020100000` | 時間のコード（どの年か） |

`%23` は記号 `#` を URL の中で表す書き方です。

このステップの応答 `estat_sample.json` は、総務省統計局「社会・人口統計体系 都道府県データ」の「F 労働」の表（統計表ID 0000010206）から、完全失業率の総数・男・女を、2010・2015・2020年の3時点、全国と47都道府県について取り出したものです。応答をそのまま保存し、アプリケーションIDだけを `YOUR_APP_ID` に置き換えてあります。

## JSON を読む

API の応答は **JSON** という形式の文字です。`{ }` の中に「名前: 値」の組を並べ、その値の中にまた `{ }` を入れていく、入れ子の形をしています。`jsonlite` パッケージの `fromJSON()` で読むと、入れ子のリストになります。

```r
res <- fromJSON("data/estat_sample.json")
names(res$GET_STATS_DATA)
names(res$GET_STATS_DATA$STATISTICAL_DATA)
```

`$` を順につないで、外側から内側へたどっていきます。応答の主な中身は次のとおりです。

- `RESULT` … 問い合わせが成功したか（`STATUS` が 0 なら成功）
- `STATISTICAL_DATA$TABLE_INF` … 表の名前や更新日
- `STATISTICAL_DATA$CLASS_INF` … コード表（コードと名前の対応）
- `STATISTICAL_DATA$DATA_INF$VALUE` … 値の表

## 値の表を取り出す

```r
values <- res$GET_STATS_DATA$STATISTICAL_DATA$DATA_INF$VALUE
glimpse(values)
```

列の名前が `@cat01` や `$` になっています。`@` や `$` で始まる名前は、そのままでは R のコードに書けません。バッククォート（`` ` ``、キーボードの Shift + @）で囲んで `` `@area` `` のように書きます。`select()` の中で `新しい名前 = 古い名前` と書くと、列を選びながら名前を変えられます。

また、値の列 `$` は `<chr>`（文字）です。JSON では値が文字として届くからです。`as.numeric()` で数値に直してから計算します。

## コード表で名前に置き換える

値の表の地域は "13000" のようなコードです。応答の `CLASS_INF$CLASS_OBJ` には、コードと名前の対応表（コード表）が入っています。

```r
classes <- res$GET_STATS_DATA$STATISTICAL_DATA$CLASS_INF$CLASS_OBJ
classes[, c("@id", "@name")]
classes$CLASS[[3]]
```

`classes` は4行の表で、`CLASS` の列に、それぞれのコード表が1つずつ入っています。`[[3]]` は「3番目の中身を取り出す」という書き方です。3番目が地域（area）なので、`classes$CLASS[[3]]` が地域コードと地域名の表です。これを `left_join()` で結合すれば、コードが名前に置き換わります（第14ステップ）。

時間のコード "2020100000" は先頭の4文字が年です。`str_sub(文字, 始め, 終わり)` で文字の一部を取り出せます。

```r
str_sub("2020100000", 1, 4)
as.integer(str_sub("2020100000", 1, 4))
```

## 結果を保存する

整えた表は `write_csv(表, ファイル名)` で CSV に書き出せます。一度 API から取ってファイルに保存しておけば、次からは `read_csv()` で読むだけで済み、同じデータで分析をやり直せます。

## 失業率を読むときの注意

2020年の完全失業率（総数）は、全国で 3.8% です。高い県は沖縄県 5.5%、青森県・福岡県 4.6%、低い県は島根県 2.7%、福井県 2.9%、三重県 3.1% でした。2010年には全国で 6.4% あり、沖縄県は 11.0% でした。

この表の完全失業率は、**国勢調査**の結果から計算した値です。ニュースでよく見る毎月の失業率は**労働力調査**の値で、2020年平均は 2.8% でした。2つは調べ方と時期が違うため、値も違います。国勢調査は5年に1度ですが、全員を調べるので県ごとの値を比べやすい、という長所があります。どの調査の値かを、出所として必ず書き添えましょう。

失業率が高い県では仕事を探している人が多く、求人に応募が集まりやすいと考えられます。ただし、失業率は「仕事を探しているのに就けていない人」の割合です。働いていない人には、仕事を探していない人もいるので、人の集めやすさを考えるときは、第13ステップの就業率もあわせて見るとよいでしょう。

## 付録：自分の R で API を呼ぶ

このアプリの中からは e-Stat API に問い合わせできないので、ここでは保存した応答を使いました。自分のパソコンの R（RStudio など）では、次の手順で実際に API を呼べます。

1. e-Stat の API のページ（https://www.e-stat.go.jp/api/）で利用者登録をし、アプリケーションIDを取得する
2. `usethis::edit_r_environ()` などで `.Renviron` というファイルを開き、`ESTAT_APP_ID=取得したID` と1行書いて保存し、R を再起動する
3. 次のコードを実行する

```r
library(jsonlite)
url <- paste0(
  "https://api.e-stat.go.jp/rest/3.0/app/json/getStatsData",
  "?appId=", Sys.getenv("ESTAT_APP_ID"),
  "&statsDataId=0000010206",
  "&cdCat01=%23F01301",
  "&cdTime=2020100000"
)
res <- fromJSON(url)
res$GET_STATS_DATA$RESULT$STATUS   # 0 なら成功
```

アプリケーションIDは、パスワードと同じように扱います。コードに直接書き込んだり、レポートやインターネットに載せたりせず、`.Renviron` に書いて `Sys.getenv()` で読み出しましょう。統計表IDは、e-Stat のサイトで表を開き、「API」のボタンから確かめられます。

## 卒論・実務での使いどころ

API で取るコードを一度書いておけば、新しい年の統計が公表されたときに、同じコードを実行し直すだけで表を更新できます。卒論でも実務でも、「どの表を、どの条件で取ったか」が URL とコードに残るので、あとから誰でも同じデータを取り直せます。
