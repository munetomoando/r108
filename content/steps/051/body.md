## 問い

卒論の原稿をワープロで書き、R で作った図表を貼り付けていると、データを直すたびに図表を作り直して貼り替えることになります。Quarto を使うと、文章とコードと図表を1つのファイルに書き、ボタン1つで Word の論文に仕上げられます。このステップでは、都道府県の最低賃金と平均時給のデータ（`pref_panel`）で、短い論文の形を作ります。

## Quarto の文書の作り

Quarto（クオート）は、`.qmd` という拡張子のファイルを Word・PDF・HTML に変換する道具です。最近の RStudio と Positron には最初から入っています。`.qmd` ファイルは3つの部分からできています。

- **YAML ヘッダ**：先頭の `---` と `---` の間。題名・著者・出力形式などの設定
- **本文**：Markdown で書く文章。`## はじめに` のように、行の先頭の `#` が見出しになります
- **コードチャンク**：```` ```{r} ```` と ```` ``` ```` で囲んだ R のコード。結果（図や表）が文書に入ります

## 雛形を Word に出力する

1. ステップ50で作ったプロジェクト `r108` を開きます（RStudio は「File」→「Open Project...」）。
2. このアプリから [pref_panel.csv](data/pref_panel.csv) をダウンロードし、`data` フォルダに移します。
3. 雛形 [paper.qmd](local/paper.qmd) をダウンロードし、プロジェクトのフォルダ（`r108.Rproj` と同じ場所）に移して開きます。
4. RStudio はエディタの上の「Render」ボタンを押します。Positron はエディタ右上の「Preview」ボタンを押します。
5. 少し待つと、同じフォルダに `paper.docx` ができます。
   - Windows：エクスプローラーでプロジェクトのフォルダを開き、`paper.docx` をダブルクリックすると Word で開きます。
   - macOS：Finder でプロジェクトのフォルダを開き、`paper.docx` をダブルクリックします（Word が入っていなければ Pages で開きます）。

雛形の YAML ヘッダは次のとおりです。

```yaml
title: "最低賃金と平均時給の関係"
author: "氏名"
date: today
lang: ja
format:
  docx: default
knitr:
  opts_chunk:
    dev: ragg_png
execute:
  echo: false
```

`lang: ja` にすると、キャプションの番号が「図 1」「表 1」になります。`dev: ragg_png` は図の日本語が文字化けしないようにする設定です。`echo: false` は、論文にコードを載せず、結果だけを出す設定です。`format:` を `pdf` にすれば PDF も作れますが、TinyTeX という別のソフトが要るので、この教材では Word を使います。

## 図にラベルとキャプションを付ける

雛形の図のチャンクは、先頭に `#|` で始まる行（チャンクオプション）を書いています。

```r
#| label: fig-scatter
#| fig-cap: "最低賃金と平均時給（2024年6月、47都道府県）"
ggplot(pref24, aes(x = min_wage, y = avg_wage)) +
  geom_point() +
  labs(x = "最低賃金（円/時）", y = "平均時給（円/時）")
```

`label` は図の名前で、**図なら `fig-`、表なら `tbl-` で始めます**。こう書くと、Quarto が図表に通し番号を付け、`fig-cap`（表は `tbl-cap`）の文がキャプションになります。2024年の散布図では、最低賃金の高い県ほど平均時給も高く、相関係数は約0.92です。

## 表と見出しを加える

雛形の最後にあるコメント `<!-- ... -->` の下に、次を加えます。

````markdown
## 結果

```{r}
#| label: tbl-year
#| tbl-cap: "年ごとの平均（47都道府県の単純平均）"
pref |>
  group_by(year) |>
  summarise(最低賃金 = mean(min_wage), 平均時給 = mean(avg_wage),
            カイツ指標 = mean(kaitz)) |>
  knitr::kable(digits = c(0, 0, 0, 3))
```

## おわりに

（分かったことを2〜3文で書きます）
````

`knitr::kable()` は、データフレームを文書の表に変える関数です。`digits` で列ごとの小数の桁数を決めます。もう一度 Render すると、7年分の表が「表 1」として入ります。最低賃金の平均は2019年の815円から2025年の998円に上がり、カイツ指標（最低賃金÷平均時給）も0.478から0.529に上がっています。最後に「はじめに」の問いと著者名を自分の言葉に書き換えます。

確認スクリプトは、見出しが4つ以上あるか、`fig-` と `tbl-` のラベルとキャプションがあるかを調べ、実際に Word へ出力して図と表が入っているかを確かめます。チャンクの中の `#` で始まるコメントは見出しに数えません。

## 卒論・実務での使いどころ

卒論は最初から `.qmd` で書き、データや分析を直したら Render し直すだけで、本文の図表と番号がすべて最新の結果にそろうようにしておきます。
