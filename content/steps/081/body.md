## 問い

第9部の総合演習で、第III段階の関門です。あなたは経済の見通しをまとめる担当者として、「1年後の完全失業率はどの範囲にあると予測できるか」に答えます。第73〜80ステップで学んだ、時系列の扱い・モデルの推定・テスト期間での評価・予測区間を、ひとそろい使います。失業率の見通しは、企業にとっては採用のしやすさや人件費、消費の強さを見込む材料になります。

## データ

`lfs` は、総務省統計局「労働力調査」の長期時系列（表1-a-1、2026年8月分公表時点で取得）の2000年1月から2026年8月までの320か月です。予測には完全失業率の**季節調整値** `unemp_rate_sa` を使います。季節の上下を取り除いた系列なので、季節をモデルに入れずに済みます。季節調整値は毎年1月分の公表時に過去にさかのぼって改定されるので、結論には「2026年8月分公表時点のデータによる」と書き添えます。

## 進め方

| 小課題 | 何をするか | 使うもの |
| --- | --- | --- |
| a | 訓練期間とテスト期間に分け、2つのモデルを推定する | `filter()`、`ts()`、`arima()`、`AIC()` |
| b | テスト期間の24か月を予測し、ナイーブ予測と比べる | `predict()`、RMSE、MAE |
| c | 全期間で推定し直し、12か月先を予測区間つきで図にする | `predict()` の `se`、`geom_ribbon()` |
| d | 結論3行と注意点を書く | a〜c の結果 |

## 期間の分け方

**テスト期間は直近の24か月**（2024年9月〜2026年8月）とし、**訓練期間**は2000年1月〜2024年8月の296か月とします。モデルは訓練期間だけで推定し、テスト期間の値は「まだ知らない未来」として予測の答え合わせにだけ使います（第78ステップ）。12か月ではなく24か月にするのは、12か月だと偶然よく当たる・外れる月の影響が大きいからです。

b では、訓練期間の終わり（2024年8月）から24か月先までを**一度に**予測します。毎月の実績を見て1か月ずつ予測し直すのではありません。c で知りたいのも「今から1年先まで」なので、評価もそれに近い形にそろえます。

## 2020年をどう扱うか

訓練期間には2020年のコロナ禍の時期も含めます。理由は2つあります。

- `ts()` と `arima()` は、月が切れ目なく並んでいることを前提にします。途中の月を抜くと、1つ前の行が1か月前でなくなります
- ショックは将来も起こりえます。ショックの時期を含めて推定すると、そうした動きも予測区間の幅に反映されます

ただし、2020年の失業率の上がり方は、2009年のリーマン・ショックの後より小さいものでした（第20ステップ）。訓練期間の始まりを遅らせる（例えば2010年から）と結果がどう変わるかを、時間があれば確かめてみましょう。どちらを選んでも、急なショックそのものは過去のデータから予測できないこと（第80ステップ）は変わりません。

## 2つのモデルとナイーブ予測

- **AR(1)**（`order = c(1, 0, 0)`）… 水準のままの自己回帰です。予測は、遠い先ほど訓練期間全体の平均に近づきます（**平均への回帰**）
- **ARIMA(1,1,0)**（`order = c(1, 1, 0)`）… 前月差（階差）に AR(1) を当てはめます。水準が平均に戻る力を仮定しません
- **ナイーブ予測** … 「この先もずっと最後の月の値のまま」と予測します。モデルが本当に役立つかを見るための比べる相手です

AIC は訓練期間への当てはまりの良さ、RMSE と MAE はテスト期間での予測の当たり具合を測ります。両者が同じ順位になるとは限りません。また、AR(1) と ARIMA(1,1,0) は階差の回数 d が違うので、AIC は同じデータへの当てはまりを比べたものにはなりません。AIC の差は目安にとどめ、テスト期間の当たり具合で確かめます（第77ステップ）。RMSE は大きな外れを重く見るので、2つの指標で順位が違うこともあります。また、公表値は0.1ポイント単位に丸めてあるので、0.05ポイントに満たない誤差の差は、丸めの範囲とほとんど区別できません。数字の大小だけでなく、その差が実際にどれくらいの大きさかも考えましょう。

## 予測区間

`predict()` は予測値 `pred` と標準誤差 `se` を返します。95%予測区間は、予測値 ∓ 1.96 × 標準誤差です（第77ステップ）。先の月ほど不確かさが積み重なり、区間は広がります。図では実績と予測値を線で、予測区間を帯で描きます。

```r
ggplot() +
  geom_line(data = recent, aes(x = date, y = unemp_rate_sa)) +
  geom_ribbon(data = fc, aes(x = date, ymin = lower, ymax = upper), alpha = 0.3) +
  geom_line(data = fc, aes(x = date, y = pred), linetype = "dashed")
```

## 合格の基準

次の2つを満たせば、第III段階の関門を通過です。

1. a〜c の判定にすべて通る
2. d の結論3行に、テスト期間の RMSE・MAE の数字とナイーブ予測との比較、2027年8月の予測値と95%予測区間を書き、注意点に「予測が外れうる理由」と「予測が当たっても因果関係は分からないこと」を書く

最後の点は大切です。失業率がよく予測できても、それは過去の動きのくり返しを使っているだけで、何が失業率を動かしたか（例えば、ある政策が失業を減らしたか）は分かりません。因果効果を知るには、第7・8部の方法が必要です。

## 卒論・実務での使いどころ

卒論でも仕事でも、予測は「訓練期間で推定し、テスト期間でナイーブ予測と比べ、予測区間つきで示す」という型で報告すると、どこまで信頼できるかが読み手に伝わります。
