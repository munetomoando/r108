## 問い

2019年の暮れに、翌2020年の鉱工業生産を予測していたとします。実際には、新型コロナウイルス感染症の拡大で、生産は春に大きく落ち込みました。時系列モデルはこれを予測できたでしょうか。できなかったなら、それはなぜでしょうか。予測の**限界**を知ることも、予測を使う人の大切な仕事です。

## データ

`iip` は、経済産業省「鉱工業生産指数」（2020年基準、2026年10月24日に取得）の鉱工業総合で、季節調整済指数 `iip_sa` を使います。季節調整済指数は毎年の年間補正でさかのぼって改定されるので、取得した時点の値です。

この系列は2018年1月から始まります。2020年基準の指数は2018年1月より前にさかのぼって作られていないからです（2015年基準の古い系列はありますが、基準が違うのでつないでいません）。そのため「2019年まで」の訓練期間は**24か月しかありません**。AR(1) の係数 `ar1` は約0.70ですが、標準誤差が約0.16もあり、推定はかなり不確かです。この短さは、このステップの結果を読むときの限界として覚えておきます。

## 2019年までで推定し、2020年を予測する

```r
pre <- filter(iip, date < ymd("2020-01-01"))
m_pre <- arima(ts(pre$iip_sa, start = c(2018, 1), frequency = 12),
               order = c(1, 0, 0))
fc_raw <- predict(m_pre, n.ahead = 12)
```

AR(1) が推定した平均（`intercept`、約112.7）は、2018〜19年の高い水準を表しています。2019年10月に108前後へ下がった後だったので、AR(1) は2020年の値を、平均に戻るように109.6（1月）から112.7（12月）へ上がっていくと予測しました。

実際の値は、4月に95.2、5月に87.6まで下がりました。誤差（実際 − 予測）は5月に約−24.4で、2020年の RMSE は約14.0、MAE は約12.2です。ナイーブ予測（2019年12月の108.2を並べる）でも RMSE は約10.7でした。95%予測区間（予測値 ∓ 1.96 × `se`）の外に出た月は、1月を除く11か月にのぼります。b の棒グラフでは、1月から誤差がマイナスで、2月から約−5に広がり、5月を底にして、年末になっても約−9のまま戻りきらないことが分かります。

## 予測できなかった理由

AR モデルは「過去と同じ動き方がこれからも続く」と仮定して予測します。訓練期間の24か月に、感染症による生産の急減は一度もありませんでした。モデルの次数を増やしても、過去にない動きは予測できません。訓練期間をもっと長くとれたとしても、リーマン・ショック（2008〜09年）のような落ち込みが予測区間を広げるだけで、いつ起こるかは分かりません。

さらに、2021年以降の生産は一度も110を超えず、年平均は101〜105ほどでした。2018〜19年の約112〜115の水準には戻っていません。このように、ある時期を境に系列の水準や動き方が変わることを**構造変化**といいます。構造変化があると、変化の前のデータで推定したモデルは、変化の後も外れ続けます。

## ショック期のダミー

全期間で推定するときは、2020年4〜6月だけ1になる**ダミー変数**を入れて、ショックの影響を取り出せます。`arima()` では `xreg` に説明変数を渡します。

```r
m_d <- arima(y_all, order = c(1, 0, 0), xreg = iip_d$covid)
```

ダミーを入れると AIC は約492から約471に下がり、`covid` の係数は約−8.4でした。2020年4〜6月の生産は、ふだんの動きより約8.4ポイント低かったという意味です。ただし、ダミーは**起きた後に**入れるものです。将来を予測するときはダミーを0（ショックなし）とおくしかなく、次のショックの予測には使えません。どの月をショック期とするかも、データを見てから決めています。

なお、ダミーの係数は落ち込みの大きさを表すだけで、感染症のどの要因が生産を減らしたかという因果関係は分かりません。

## 卒論・実務での使いどころ

予測を報告するときは、訓練期間にどんなショックが含まれ、どんなショックが含まれていないかを書き、「急なショックや構造変化があれば予測は外れる」と限界を明記します。
