## 問い

第60ステップでは、参加者1人ごとに「似た不参加者」を1人選んで比べました。似た人を選ぶ代わりに、不参加者全員を使い、参加者に似ている人ほど大きな重みをつけて平均すると、何が分かるでしょうか。

## 傾向スコア：参加しやすさを1つの数にまとめる

使うのは、第59ステップからの職業訓練の観察データ `obs`（4,000人）です。教材用の合成データで、真の効果は全員+30万円/年と決めてあります。前年収入の低い人ほど訓練に参加しやすいので、単純に平均を比べると約−65万円になりました。

前年収入・年齢・教育年数・性別が同じ人の中で比べれば、選択の偏りは取り除けそうです。しかし4つの変数がすべて同じ人を探すのは大変です。そこで、これらの変数から計算した「訓練に参加する確率」を1つの数にまとめます。これを**傾向スコア**（propensity score）といいます。第48ステップのロジットで推定できます。

```r
ps_model <- glm(treat ~ prior_earn + age + educ_years + female,
                data = obs, family = binomial)
obs_ps <- obs |>
  mutate(ps = predict(ps_model, type = "response"))
```

傾向スコアの平均は、参加者で約0.409、不参加者で約0.225です。参加者は、もともと参加しやすい特徴を持った人に偏っています。

## ATT の重み：不参加者を参加者の姿に近づける

知りたいのは、実際に参加した人にとっての平均効果（ATT）です。参加者の年収はそのまま使います。比べる相手として、「参加者が参加しなかったら、年収はいくらだったか」を不参加者から作ります。

そのために、不参加者一人ひとりに $\dfrac{p}{1-p}$（$p$ は傾向スコア）の重みをつけます。参加者の重みは1です。傾向スコアが0.75の不参加者は重み3、0.1の人は重み約0.11です。「参加しやすいのにたまたま参加しなかった人」を多めに数え、参加しにくい人を少なめに数えるので、重みつきの不参加者は参加者に似た集団になります。これを**逆確率重み付け**（inverse probability weighting、IPW）といいます。

```r
obs_w <- obs_ps |>
  mutate(w = if_else(treat == 1, 1, ps / (1 - ps)))
obs_w |>
  group_by(treat) |>
  summarise(前年収入 = mean(prior_earn),
            前年収入_重みつき = weighted.mean(prior_earn, w))
```

`weighted.mean(x, w)` は重みつき平均 $\sum w_i x_i / \sum w_i$ を計算します。不参加者の前年収入の平均は、重みなしでは約308万円、重みつきでは約190万円で、参加者の約191万円とほぼそろいます。年齢も約41.1歳から約35.8歳になり、参加者の約35.7歳に近づきます。

## 加重平均の差で効果を推定する

```r
obs_w |>
  group_by(treat) |>
  summarise(年収 = weighted.mean(earn_post, w))
```

訓練後の年収の加重平均の差が、ATT の推定値です。実行して、単純比較の約−65万円と比べてみましょう。`lm(earn_post ~ treat, data = obs_w, weights = w)` の treat の係数も同じ値になります。

ただし、この推定が因果効果を表すには条件があります。1つ目は、参加するかどうかが、モデルに入れた観察できる変数だけで説明できること（条件付き独立）です。やる気のように観察できない違いで参加が決まっていれば、重みをつけても偏りは残ります。2つ目は、参加者に似た不参加者が実際にいること（共通サポート）です。

## ATE の重みとの違い

全員の平均効果（ATE）を推定するなら、重みは参加者が $1/p$、不参加者が $1/(1-p)$ です。このデータでこの重みを使うと、推定値は約11.4万円で、真の値から大きく外れます。前年収入が500万円を超える283人には参加者が1人もおらず、その人たちが参加した場合の年収はデータからは分からないからです。参加しにくい参加者には重み約51がつき、数人の年収で結果が揺れます。

このデータでは ATT の重みは最大でも約3.6です。何の平均効果を推定したいのかを先に決め、重みの大きさと共通サポートを必ず確かめましょう。

## 卒論・実務での使いどころ

卒論で政策や制度の利用者と非利用者を比べるときは、傾向スコアの分布と重みつきのバランス表を示してから、加重平均の差を報告します。
