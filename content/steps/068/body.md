## 問い

第64〜67ステップでは、真の効果が分かっている架空のパネルで差の差分析とイベントスタディを練習しました。今度は実際の政策に使います。米国カリフォルニア州は、臓器提供の登録の聞き方を変えました。この変更で、登録する人は増えたのでしょうか。

## データと政策

causaldata パッケージの `organ_donations` は、Kessler と Roth（2014）の研究のデータです。米国の27の州（ワシントンD.C.を含む）について、6つの四半期の臓器提供の登録率 `Rate` が入っています（27 × 6 = 162行）。`Rate` は割合で、0.27 は27%です。

カリフォルニア州は2011年第3四半期に、登録の質問を「登録するかどうかを必ずどちらか選んで答える」形（active choice）に変えました。ほかの26は、比較に使えるとして研究者が選んだ、変更のなかった州です。

時点を表す列は2つあります。`Quarter` は `"Q32011"` のような文字列、`Quarter_Num` は1〜6の整数です。パッケージの説明（`?organ_donations`）によると `Quarter_Num` の1は2010年第4四半期なので、2011年第3四半期は4です。`count(od, Quarter, Quarter_Num)` で対応を確かめておきましょう。したがって事後の期間は `Quarter_Num >= 4` の3四半期です。

## 差の差分析

第66ステップと同じく、処置の変数と事後の変数を作り、州と四半期の固定効果を入れて推定します。

```r
od_did <- od |>
  mutate(treated = as.numeric(State == "California"),
         post = as.numeric(Quarter_Num >= 4))
did_od <- feols(Rate ~ treated:post | State + Quarter_Num,
                data = od_did, cluster = ~State)
```

4つの平均で確かめると、カリフォルニア州は変更前の約0.271から変更後の約0.263に下がり、比較の州は約0.445から約0.459に上がりました。差の差は約 −0.022 です。回帰の係数も約 −0.0225（州でクラスタした標準誤差は約0.0061）で、登録率は約2.2ポイント下がったと推定されます。増えたのではありません。

## イベントスタディ

変更の四半期を0とする相対四半期 `rel_q = Quarter_Num - 4` を作り、第67ステップと同じく `i()` で推定します。基準は変更の直前の四半期（`ref = -1`）です。

```r
od_es <- od_did |>
  mutate(rel_q = Quarter_Num - 4)
es_od <- feols(Rate ~ i(rel_q, treated, ref = -1) | State + Quarter_Num,
               data = od_es, cluster = ~State)
```

変更後の3つの係数は約 −0.022、−0.020、−0.022 で、変更の四半期からすぐに下がり、その水準が続いています。変更前の2つは約 −0.003 と約 +0.006 です。後者は信頼区間が0をわずかに外れますが、変更後の低下よりずっと小さな動きです。ただし、変更前の期間は3四半期しかないので、事前トレンドの確認は合成データのときより弱い証拠にとどまります。

## 実データで注意すること

第1に、この推定は「変更がなければカリフォルニア州も比較の州と平行に動いた」という仮定に頼っています。カリフォルニア州の登録率はもともと比較の州よりかなり低く、水準の違いは州の固定効果で取り除けますが、動き方の違いは取り除けません。

第2に、処置を受けたのは1州だけです。クラスタ標準誤差は、処置を受けたクラスタがたくさんあることを前提にした方法なので、ここでは精度を正しく測れている保証がありません。p値は参考程度にとどめ、推定値の符号と大きさ、図の形を中心に読みます。

## 卒論・実務での使いどころ

自治体や企業の制度変更を卒論で分析するときは、差の差の推定値とイベントスタディの図を並べ、処置を受けた単位が少ないときは標準誤差の限界も書き添えます。
