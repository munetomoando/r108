## 問い

そらまめマーケットは、新しい県への出店とパートの時給を検討しています。最低賃金は県ごとに違い、時給の下限、つまり人件費の床を決めます。その地域差を、会議で一目で分かる日本地図にして示します。

## 使うデータ

- `mw` … 厚生労働省「地域別最低賃金改定状況」（2002〜2025年度）。地域別最低賃金は都道府県ごとに決める時給の下限で、使用者はこの額以上を払わなければなりません。毎年10月前後に改定され、年度（`fiscal_year`）で表します。2025年度は、発効日が県によって2025年10月〜2026年3月とばらつきます
- `tile` … 47都道府県を1県1マスで並べた位置表です。`row` は上から何行目、`col` は左から何列目かを表します。setup で、県名を短くした列 `short` を足してあります（`str_sub(pref, 1, -2)` で最後の1文字「県」「府」「都」を除き、北海道だけはそのままにしています）

## タイル地図を描く

本物の地図の形（境界線）を描くには専用のデータとパッケージが必要です。ここでは、どの県も同じ大きさの正方形にして並べる**タイル地図**を使います。面積の大きい北海道や岩手県が目立ちすぎず、47県を同じ重さで見比べられるのが利点です。

`geom_tile()` は、横軸と縦軸の位置にマスを描く層です。

```r
p <- ggplot(tile, aes(x = col, y = row)) +
  geom_tile(colour = "white") +
  geom_text(aes(label = short), size = 3, colour = "white") +
  scale_y_reverse() +
  coord_fixed()
p
```

`row` は上から数えた番号です。ところが ggplot の縦軸は、下ほど小さく上ほど大きい向きです。そのまま描くと北海道（1行目）が一番下に来てしまうので、`scale_y_reverse()` で縦軸を上下反転させます。`coord_fixed()` は縦と横の1目盛りの長さをそろえ、マスを正方形にします。`geom_tile(colour = "white")` はマスの枠線を白にして、県の境目を見やすくします。第24ステップの `geom_text()` で県名も載せられます。

## 最低賃金で塗る

色を付けるには、位置表に最低賃金を結合して、`fill`（塗り）に対応づけます。

```r
map25 <- left_join(tile, filter(mw, fiscal_year == 2025), by = "pref_code")
ggplot(map25, aes(x = col, y = row, fill = min_wage)) +
  geom_tile(colour = "white") +
  scale_fill_viridis_c() +
  scale_y_reverse() +
  coord_fixed()
```

`scale_fill_viridis_c()` は、連続した値を濃い紫→青緑→黄色の順に塗る色の物差しです（`_c` は continuous＝連続の意味）。明るさが値の順にそろって変わるので、色覚の多様性があっても、白黒で印刷しても大小が読めます。

2025年度の最高は東京都の1,226円、次いで神奈川県の1,225円です。最低は高知県・宮崎県・沖縄県の1,023円で、差は203円（約1.20倍）です。地図では、関東・東海・近畿の大都市圏が明るく、東北・四国・九州が暗く塗られます。47県の単純平均は約1,067円です（労働者数で重みを付けた全国加重平均1,121円とは別の値です）。

## 年度を並べて比べる

2005年度と2025年度を同じ色の物差しで塗ると、20年でどの県も394〜513円上がったため、2005年度はすべて暗く、2025年度はすべて明るくなります。地域差の「形」を比べたいときは、各年度の中で47県平均との差を計算して塗り、`facet_wrap()` で並べます。

```r
gap <- mw |>
  filter(fiscal_year == 2005 | fiscal_year == 2025) |>
  group_by(fiscal_year) |>
  mutate(gap = min_wage - mean(min_wage))
```

2005年度の最高（東京都714円）と最低（青森県・沖縄県など8県の608円）の差は106円でした。2005→2025年度の引上げ額は、神奈川県513円、東京都512円、大阪府469円が大きく、最も小さいのは岐阜県の394円です。差は額で見ると106円から203円に広がりました。一方、2025年度に47県平均を上回るのは15都道府県だけです。2005年度の26から減っており、少数の大都市圏が平均を引き上げる形がはっきりしてきました。色の物差しを年度ごとに作り直していることは、図の説明に必ず書き添えましょう。

## パートの時給を考えるときに

同じチェーンでも、東京都と沖縄県では時給の下限だけで200円ほど違います。1日8時間・月20日働くパート1人なら、月3万円以上の差です。出店先の人件費を見積もるときは、県ごとの最低賃金と、その差が年々どう動いてきたかを地図で確かめておくとよいでしょう。

## 卒論・実務での使いどころ

都道府県別の指標をタイル地図に塗る方法は、卒論で地域差を示す図にも、出店や人員配置を検討する社内資料にも、そのまま使えます。
