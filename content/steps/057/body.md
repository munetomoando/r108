## 問い

第56ステップでは、抽選で分けた RCT なら、平均の差 `lm(earn_post ~ treat)` だけで訓練の効果を推定できることを確かめました。推定値は約34.8万円、95%信頼区間は約19.0〜50.5万円と、かなり幅があります。共変量を回帰に加えると、何が変わるのでしょうか。また、どんな変数でも加えてよいのでしょうか。

## 共変量を加える

データは引き続き、架空の RCT のデータ `rct`（1,000人、真の効果は +30万円）です。訓練の前から決まっている共変量（前年収入・教育年数・年齢・性別）を加えて推定します。

```r
m_simple <- lm(earn_post ~ treat, data = rct)
m_cov <- lm(earn_post ~ treat + prior_earn + educ_years + age + female, data = rct)
c(coef(m_simple)[["treat"]], coef(m_cov)[["treat"]])
```

`treat` の係数は約34.8から約33.5に変わります。第39ステップの欠落変数バイアスでは、変数を加えると係数が大きく変わりました。RCT では、抽選のおかげで共変量が処置と（平均的には）無関係です。そのため、共変量を入れても入れなくても、係数は平均的には真の効果になります。今回の約1.3万円の違いは、第56ステップで見た年齢の約1歳の差のような、偶然の偏りを調整した分です。

## 標準誤差が小さくなる

共変量を入れる本当の利点は、**精度**が上がることです。第43ステップの `feols()` で、不均一分散に頑健な標準誤差を比べます。

```r
f_simple <- feols(earn_post ~ treat, data = rct, vcov = "hetero")
f_cov <- feols(earn_post ~ treat + prior_earn + educ_years + age + female,
               data = rct, vcov = "hetero")
c(se(f_simple)[["treat"]], se(f_cov)[["treat"]])
```

標準誤差は約8.03から約3.75へと、半分以下（約0.47倍）になります。95%信頼区間も約26.1〜40.8万円と、幅が約31万円から約15万円に狭まります。

なぜでしょうか。訓練後の年収は人によって大きくばらつきます。そのばらつきの大部分は、訓練とは関係なく前年収入の違いから来ています（前年収入と訓練後の年収の相関係数の2乗は約0.77）。前年収入を回帰に入れると、このばらつきが「説明済み」になり、残りの誤差が小さくなります。誤差が小さいほど、処置群と対照群の差を見分けやすくなるのです。同じ精度を共変量なしで得ようとすると、参加者を何倍も集める必要があります。

## 処置の後の変数を入れてはいけない

`rct` には setup で、訓練の**後**に決まる変数 `regular_post`（訓練後1年以内に正社員の仕事に就いたら1）を加えてあります。次の式で作りました。

$$\text{logit}(p) = -1 + 1.5 \times \text{treat} + 0.03 \times u$$

$p$ は正社員になる確率、$u$ は訓練後の年収の式の誤差で、意欲や能力のようにデータにない要因を表します。訓練を受けると正社員になりやすく（割合は対照群約0.33、処置群約0.53）、意欲の高い人ほど正社員になりやすいという設定です。なお、このデータでは正社員になったこと自体は年収を変えません。

これを説明変数に加えると、`treat` の係数は約33.5から約20.1に下がり、真の効果30万円から大きく外れます。

```r
feols(earn_post ~ treat + prior_earn + educ_years + age + female + regular_post,
      data = rct, vcov = "hetero")
```

`regular_post` をそろえることは、「正社員になった人どうし」「ならなかった人どうし」で比べることです。対照群で正社員になったのは、訓練なしでも就職できた意欲の高い人に偏ります。処置群の正社員には、訓練のおかげで就職できた人も含まれます。せっかく抽選でそろえた2つの群を、処置の後の変数で選び直したことになり、選択バイアスが入り込みます。`regular_post` の係数が約67と大きく出るのも、正社員の効果ではなく、意欲の違いを拾っているためです。

共変量として入れてよいのは、**処置の前に決まっていて、処置によって変わらない変数**だけです。どの共変量を入れるかは、結果を見る前に決めておきます。

## 卒論・実務での使いどころ

RCT や A/B テストの分析では、事前に決めた処置前の共変量を加えて標準誤差を小さくし、処置後に測った変数（購入後の満足度、訓練後の就職先など）は説明変数に入れないようにしましょう。
