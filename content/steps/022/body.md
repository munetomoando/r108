## 問い

そらまめマーケットの経営企画部で、店舗ごとの成績を役員会で報告することになりました。「どの店舗が、売場をうまく使って売っているか」を、一目で分かる図にして並べます。

## 棒グラフは2種類ある

ggplot2 には棒グラフを描く関数が2つあります。違いは「棒の高さをどこから取るか」です。

- `geom_col()` … 表にある値をそのまま棒の高さにします。縦軸 `y` を指定します
- `geom_bar()` … 表の**行の数を数えて**、その数を棒の高さにします。縦軸は指定しません

たとえば、立地（駅前・郊外・商業施設）ごとの店舗数を見たいなら、`stores` の行を数えればよいので `geom_bar()` を使います。

```r
ggplot(stores, aes(x = location)) +
  geom_bar()
```

一方、店舗ごとの売上のように、高さにしたい値が列としてすでにあるときは `geom_col()` です。`geom_bar()` に `y` を渡すと、数えるべきか値を使うべきか決められず「stat_count() must only have an x or y aesthetic.」というエラーになります。このエラーを見たら、`geom_col()` に直せばよいと覚えておきましょう。

## 名前の重なりは縦横を入れ替えて解く

50店舗の売上を `geom_col()` で描くと、横軸に50個の店舗名が並び、文字が重なって読めません。`coord_flip()` を足すと、縦軸と横軸が入れ替わり、店舗名が縦に並びます。項目が多い棒グラフは横向きにするのが定番です。

```r
ggplot(stores, aes(x = store_name, y = sales)) +
  geom_col() +
  coord_flip()
```

## 値の順に並べ替える

上の図では、店舗が名前の順に並んでいます。順位を伝えたいのに、これでは上位の店舗を目で探さなければなりません。

R では、図の中の項目の並び順は「因子（factor）」という型の「水準の順番」で決まります。因子とは、決まった種類の値（ここでは店舗名）に順番を付けて持つ型です。forcats パッケージの `fct_reorder(並べたい列, 基準の列)` は、基準の列の値が小さい順に水準を並べ替えます。`coord_flip()` と組み合わせると、下から小さい順に積み上がるので、最も大きい店舗が一番上に来ます。

```r
ggplot(stores, aes(x = fct_reorder(store_name, sales), y = sales)) +
  geom_col() +
  coord_flip()
```

実行して、どの店舗が上位に来るか確かめましょう。売上の上位には、金沢店や池袋店など郊外の大型店が並びます。

## 売上の大きさと売場効率は違う

売上が大きいのは、売場が広いからかもしれません。そこで、第5ステップで作った**売場効率**（売上 ÷ 売場面積。1m²あたりで何万円売っているか）で比べ直します。上位10店に絞り、立地で棒を塗り分けます。棒の中の色は `fill`、棒のふちの線の色は `colour` で指定します。

```r
eff_top10 <- stores |>
  mutate(sales_per_m2 = sales / floor_m2) |>
  slice_max(sales_per_m2, n = 10)
ggplot(eff_top10, aes(x = fct_reorder(store_name, sales_per_m2), y = sales_per_m2, fill = location)) +
  geom_col() +
  coord_flip()
```

この図では、上位10店がすべて駅前の店舗になり、1位は船橋店（約121万円/m²）です。売上の順位で上位だった郊外の大型店は、1m²あたりでは上位に入りません。色が1色しか出ないこと自体が「売場効率では駅前が強い」という発見になっています。

全店で確かめるなら、立地ごとに売場効率の平均を求めてみましょう。駅前（24店）は約96万円/m²、商業施設（9店）は約73万円/m²、郊外（17店）は約64万円/m²です。郊外店は売場が広い（面積の中央値は約2,170m²で、駅前の約830m²の2倍以上）ぶん、売上は大きくても1m²あたりでは薄くなります。

```r
stores |>
  mutate(sales_per_m2 = sales / floor_m2) |>
  group_by(location) |>
  summarise(n = n(), mean_eff = mean(sales_per_m2))
```

どの指標で並べるかで「良い店舗」は変わります。役員会では、何の順に並べた図なのかを必ず添えましょう。

## 卒論・実務での使いどころ

項目の多い比較は「値の順に並べ替えた横向きの棒グラフ」にすると、順位と差が一目で伝わり、店舗の報告にも都道府県の比較にもそのまま使えます。
