## 問い

賃金は働き始めてからしばらく伸び、やがて伸びが鈍っていきます。経験年数と時給の関係は直線ではなく、山なりの曲線に近いと考えられます。回帰に経験年数の2乗を加えて曲線を表し、時給は経験何年目でピークを迎えるかを求めます。

## 使うデータ

`wage` は教材用に乱数で作った**架空の**賃金調査（3,000人）です。経験年数 `exper` は「年齢 − 教育年数 − 6」で計算した潜在的な経験年数で、0〜46年の値をとります。

## 二次項を入れる：I(exper^2)

経験年数の1次の項に加えて2乗の項（**二次項**）を入れると、回帰で放物線を表せます。

$$\log(\text{時給}) = b_0 + \cdots + b_1\,\text{exper} + b_2\,\text{exper}^2$$

R の式の中では、`^` は「変数どうしの組み合わせ」という別の意味を持ちます。そのため `exper^2` とそのまま書くと、2乗の項は入らず `exper` だけのモデルになってしまいます。式の中で普通の計算をさせたいときは `I()` で囲みます。

```r
m_q <- lm(log_wage ~ educ_years + exper + I(exper^2) + female, data = wage)
coef(m_q)
```

`exper` の係数は約0.0415、`I(exper^2)` の係数は約 −0.00064 です。2乗の係数が負なので、曲線は上に凸の山なりになります。二次項を入れない回帰と比べると、決定係数 R² は約0.261から約0.319に上がります。

## ピークの年数を計算する

$b_1 x + b_2 x^2$ は、$b_2 < 0$ のとき $x = -b_1/(2b_2)$ で最大になります（二次関数の頂点）。

```r
b1 <- coef(m_q)[["exper"]]
b2 <- coef(m_q)[["I(exper^2)"]]
peak <- -b1 / (2 * b2)
peak
```

ピークは経験**約32.3年**です。大卒（教育年数16年）なら、22歳で働き始めて54歳ごろにあたります。このデータを作るときに決めた値（0.035と −0.0006）から計算した頂点は約29年でした。推定値はそれと近いものの、一致はしません。

## 予測曲線を描く

係数の表だけでは形をつかみにくいので、予測値を図にします。まず、予測したい人の条件を表にします。`seq(0, 45, by = 1)` は、0から45まで1刻みの数の並び（0, 1, 2, …, 45）を作る関数です。

```r
new <- tibble(exper = seq(0, 45, by = 1), educ_years = 16, female = 0)
new <- mutate(new, pred_wage = exp(predict(m_q, newdata = new)))
ggplot(new, aes(x = exper, y = pred_wage)) +
  geom_line()
```

大卒男性の予測時給は、経験0年で約1,395円、10年で約1,981円、20年で約2,475円、30年で約2,720円と伸び、45年では約2,463円に下がります。`exp()` で戻した値は、その条件の人の時給のおおよその目安です。

## 対数と二次項の解釈

二次項があると、経験年数1年の効果は一定ではありません。経験年数を1年増やしたときの対数時給の変化は、およそ $b_1 + 2b_2 \times \text{exper}$ です。

| 経験年数 | 1年あたりの時給の伸び |
| --- | --- |
| 0年 | 約4.2% |
| 10年 | 約2.9% |
| 20年 | 約1.6% |
| 30年 | 約0.3% |

`exper` の係数0.0415は「経験0年の時点の傾き」で、どの年数でも4.2%伸びるという意味ではありません。また、二次項の係数だけを取り出して%で読むこともできません。

読み方の注意が2つあります。第1に、これは同じ時点の若い人と年配の人の比較（横断面）で、1人の人の賃金が年とともにこう変わるとは限りません。第2に、ピーク後の下がり方は「放物線」という形を仮定した結果でもあります。データの少ない端の部分は、特に慎重に読みます。

## 卒論・実務での使いどころ

賃金と経験、売上と広告費のように「増えるほど効果が小さくなる」関係では、二次項を入れて頂点や各点の傾きを計算し、予測曲線の図で示すと、人事の賃金カーブの検討でも卒論でも伝わりやすくなります。
