## 問い

論文や報告書では、説明変数を少しずつ増やした複数の回帰を1つの表に並べて示します。係数が変数を加えるとどう動くかが一目で分かるからです。`summary()` の出力を3つ貼り付けるのではなく、R で1つの**回帰表**を作るにはどうすればよいでしょうか。

## 3つのモデルをリストにまとめる

使うのは架空の賃金調査 `wage`（3,000人、教材用に乱数で作ったデータ）です。第37〜42ステップで扱ったモデルを、説明変数を増やす順に3つ推定します。

```r
m1 <- lm(log_wage ~ educ_years, data = wage)
m2 <- lm(log_wage ~ educ_years + exper + I(exper^2) + tenure, data = wage)
m3 <- lm(log_wage ~ educ_years + exper + I(exper^2) + tenure + female + regular, data = wage)
models <- list("(1)" = m1, "(2)" = m2, "(3)" = m3)
```

`list()` は、種類の違うものをいくつでも1つにまとめる入れ物です。`"(1)" = m1` のように名前を付けておくと、その名前が表の列見出しになります。中身は `models[["(3)"]]` や `models[[3]]` で取り出せます。

## modelsummary で1つの表に

modelsummary パッケージの `modelsummary()` にリストを渡すと、モデルを横に並べた表ができます。

```r
modelsummary(models, vcov = "HC1", output = "markdown")
```

各行の上段が係数、括弧内が標準誤差です。`vcov = "HC1"` は、括弧内を不均一分散に頑健な標準誤差にする指定です。第43ステップの `feols(vcov = "hetero")` と同じ計算で、たとえば (2) の教育年数の標準誤差は約0.0032になります。`output = "markdown"` は、表を画面に文字で出す指定です。`output = "表.docx"` のようにファイル名を書くと Word の表として保存できます（第49ステップ）。

表を見ると、教育年数の係数は (1) の約0.049から、経験年数と勤続年数を加えた (2) で約0.063に上がります。(3) では約0.064でほとんど動きません。第39ステップで学んだ欠落変数バイアスの話を、表の1行で示せるのが回帰表の強みです。決定係数は (1) 約0.057、(2) 約0.299、(3) 約0.371と上がっていきます。

## 体裁を整える

そのままの表は、変数名が英語のままです。また `I(exper^2)` の係数は小さすぎて -0.001、標準誤差は (0.000) と表示されてしまいます。表の下の行（適合度の指標）も、AIC や BIC など初学者の読み手には不要なものが並びます。次の引数で整えます。

| 引数 | 働き |
| --- | --- |
| `fmt = 4` | 小数第4位まで表示する |
| `coef_rename = c(educ_years = "教育年数", …)` | 係数名を読み手の言葉に置き換える |
| `gof_map = c("nobs", "r.squared")` | 表の下の行を観測数と決定係数だけにする |
| `notes = "…"` | 表の下に注記を付ける |

```r
modelsummary(models, vcov = "HC1", output = "markdown", fmt = 4,
  coef_rename = c(educ_years = "教育年数", female = "女性"),
  gof_map = c("nobs", "r.squared"),
  notes = "括弧内は不均一分散に頑健な標準誤差（HC1）。")
```

`coef_rename` に書かなかった係数は元の名前のまま残ります。`(Intercept)` や `I(exper^2)` のように、かっこや記号を含む名前は引用符で囲みます。

注記には少なくとも「括弧内は何か（どの標準誤差か）」と「データの出所」を書きます。読み手が表だけを見ても、何を推定したのかが分かるようにするためです。(3) の女性の係数は約 −0.121 で、学歴・経験・勤続・雇用形態が同じなら、女性の時給は男性より約11%低い（$(e^{-0.121}-1)\times 100 \approx -11.4$）と読めます。ただし、ここに入れていない違い（職種など）も含んだ差で、そのまま差別の大きさとは言えません。

## 卒論・実務での使いどころ

卒論の結果の章では、主な推定を1つの回帰表にまとめ、注記に標準誤差の種類とデータの出所を書きます。そらまめマーケットの人事部が時給テーブルを見直す資料でも、同じ形の表で「どの条件をそろえると差がどう変わるか」を示せます。
