## 問い

大きな企業で働く人ほど、時給は高いのでしょうか。性別や企業規模のような「数ではない区分」を回帰分析に入れる方法を学び、学歴や経験をそろえたうえで、企業規模による時給の差を測ります。

## 使うデータ

`wage` は教材用に乱数で作った**架空の**賃金調査（3,000人）です。企業規模 `firm_size` は「〜29人」「30〜299人」「300〜999人」「1000人以上」の4区分で、人数はそれぞれ766人、1,039人、446人、749人です。

## ダミー変数：0と1で区分を表す

`female` は女性なら1、男性なら0をとる変数です。このように、ある区分に当てはまるかどうかを0と1で表した変数を**ダミー変数**といいます。ダミー変数は、ふつうの数値の変数と同じように式に入れられます。

```r
m_f <- lm(log_wage ~ female + educ_years + exper + tenure, data = wage)
coef(m_f)
```

`female` の係数は約 −0.157 です。教育年数・経験年数・勤続年数が同じなら、女性の対数時給は男性より約0.157低い、という意味です。被説明変数が対数なので、%に直すと (exp(−0.157) − 1) × 100 ≈ −14.5%、つまり**およそ15%低い**と読めます。係数 × 100 の「−15.7%」は近似です。

ダミー変数の係数は「0のグループ（基準）と1のグループの差」です。男性を基準にしているので、男性の係数は出てきません。

## 4つ以上の区分は factor で入れる

企業規模のように区分が4つあるときは、区分ごとにダミー変数を作ります。R では列を**因子**（factor）にして式に入れると、この作業を自動でしてくれます。因子の区分の並び順は `levels()` で確かめられます。

```r
wage <- mutate(wage, firm_size = factor(firm_size,
  levels = c("〜29人", "30〜299人", "300〜999人", "1000人以上")))
levels(wage$firm_size)
m_s <- lm(log_wage ~ firm_size + female + educ_years + exper + tenure, data = wage)
coef(m_s)
```

`levels` を指定しないと、区分は文字の順に並びます。その順は「1000人以上」が「30〜299人」より前に来るなど不自然なうえ、パソコンの設定によって変わることもあるので、意味のある順を自分で書くのが安全です。

結果には `firm_size30〜299人`、`firm_size300〜999人`、`firm_size1000人以上` の3つの係数が出ます。並び順の1番目の「〜29人」が**基準**で、それぞれの係数は「〜29人」との差です。

| 企業規模 | 係数 | %に直した差 |
| --- | --- | --- |
| 〜29人（基準） | 0 | 0 |
| 30〜299人 | 0.045 | 約4.6% |
| 300〜999人 | 0.066 | 約6.8% |
| 1000人以上 | 0.184 | 約20.2% |

性別・学歴・経験・勤続が同じなら、1000人以上の企業で働く人は29人以下の企業の人より、時給がおよそ2割高い傾向があります。このデータを作るときに決めた上乗せは0.05・0.10・0.18でした。推定値はこれと近いものの、乱数の影響で同じにはなりません。

4区分すべてのダミー変数を入れないのは、4つを足すと必ず1になり、定数項と区別できなくなるからです。1つを基準として外すことで、差が計算できます。

## 基準を変える：relevel

大企業と比べた差を知りたいときは、`relevel()` で基準を変えます。`ref` に基準にしたい区分を書きます。

```r
wage <- mutate(wage, firm_size = relevel(firm_size, ref = "1000人以上"))
m_r <- lm(log_wage ~ firm_size + female + educ_years + exper + tenure, data = wage)
coef(m_r)
```

「〜29人」の係数は約 −0.184、「30〜299人」は約 −0.139、「300〜999人」は約 −0.118 になります。基準を変えても、区分どうしの差（たとえば1000人以上と〜29人の差0.184）や、ほかの変数の係数は変わりません。変わるのは「何と比べた差として表に出すか」だけです。

## 係数は因果効果とは限らない

企業規模の係数は、他の条件を一定とした**平均的な差**です。「小さな企業の人が大企業に移れば時給が2割上がる」とまでは言えません。大企業に採用される人は、データにない能力や職種が違うかもしれないからです。

## 卒論・実務での使いどころ

人事部で時給テーブルを見直すときも卒論でも、雇用形態や地域などの区分を factor で回帰に入れ、比べたい区分を `relevel()` で基準にすると、表の係数をそのまま「〇〇との差」として説明できます。
