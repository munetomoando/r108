## 問い

ある自治体が、失業中の人や年収の低い人向けに職業訓練を行いました。翌年の年収を比べると、訓練を受けた人のほうが受けなかった人より低くなっていました。訓練には効果がなかった、むしろ逆効果だった、と結論してよいのでしょうか。

第7部では、この職業訓練を題材に「効果」をデータから測る方法を学びます。まずは、何を測りたいのかをはっきりさせます。

## 潜在的結果：もし受けていたら、もし受けていなかったら

ある人 $i$ の訓練の効果とは、「訓練を受けた場合の年収」と「受けなかった場合の年収」の差です。

- $Y_i(1)$ … 訓練を**受けた場合**の年収
- $Y_i(0)$ … 訓練を**受けなかった場合**の年収
- 個人の効果 $= Y_i(1) - Y_i(0)$

この2つを**潜在的結果**（potential outcomes）と呼びます。ところが現実には、1人の人が訓練を「受けた」と「受けなかった」を同時に経験することはできません。見えるのはどちらか一方だけです。これを因果推論の**根本問題**といいます。

このステップでは練習のために、両方の潜在的結果が分かる架空のデータ `pop`（1,000人、単位は万円）を setup で作ってあります。

```r
set.seed(55)
pop <- tibble(id = 1:1000,
              prior_earn = round(rnorm(1000, mean = 250, sd = 70), 1)) |>
  mutate(y0 = round(150 + 0.8 * prior_earn + rnorm(1000, mean = 0, sd = 40), 1),
         y1 = round(y0 + 30 + rnorm(1000, mean = 0, sd = 10), 1),
         treat = rbinom(1000, size = 1, prob = plogis(-1 - 0.02 * (prior_earn - 250))),
         earn_post = if_else(treat == 1, y1, y0))
```

`y0` は前年収入 `prior_earn` が高い人ほど高くなります。`y1` は `y0` に平均30万円を足したものです（効果は人によって少しずつ違います）。`treat` は訓練に参加したら1で、`rbinom()` と `plogis()` によって、前年収入の低い人ほど参加しやすくしてあります（第48ステップのロジットと同じ形です）。`earn_post` は実際に観察される年収で、参加した人は `y1`、しなかった人は `y0` です。

全員の個人の効果を平均したものを**平均処置効果**（ATE, average treatment effect）といいます。

```r
mean(pop$y1 - pop$y0)
```

## 観察できる差

現実のデータで計算できるのは、`earn_post` の群別の平均の差だけです。

```r
mean(pop$earn_post[pop$treat == 1]) - mean(pop$earn_post[pop$treat == 0])
```

`[pop$treat == 1]` は「参加した人の分だけ取り出す」という意味です。実行すると、平均処置効果は約30.4万円なのに、観察できる差は約 −30.4万円と、符号まで逆になります。

群ごとに平均を並べると、理由が見えてきます。

```r
pop |>
  group_by(treat) |>
  summarise(人数 = n(), 前年収入 = mean(prior_earn),
            y0 = mean(y0), y1 = mean(y1), 観察 = mean(earn_post))
```

参加者（335人）の前年収入の平均は約201万円、不参加者（665人）は約276万円です。参加者は、訓練を受けなくても年収が低めになるはずの人たちでした。`y0` の平均は参加者で約311万円、不参加者で約371万円です。

## 観察できる差 ＝ 効果 ＋ 選択バイアス

観察できる差は、次のように2つに分けられます。

$$\underbrace{E[Y(1)\mid D=1]-E[Y(0)\mid D=0]}_{\text{観察できる差}} = \underbrace{E[Y(1)-Y(0)\mid D=1]}_{\text{参加者の平均効果}} + \underbrace{E[Y(0)\mid D=1]-E[Y(0)\mid D=0]}_{\text{選択バイアス}}$$

$D$ は参加なら1の変数（`treat`）、$E[\cdot \mid D=1]$ は参加者の平均です。右辺の1つ目は参加者だけの平均効果で、**処置群の平均処置効果**（ATT）と呼びます。2つ目の**選択バイアス**は、「もし誰も訓練を受けなかったとしても、2つの群の間にあったはずの差」です。右辺の2つを足すと、真ん中の $E[Y(0)\mid D=1]$ が打ち消し合って左辺になります。

このデータでは ATT が約30.4万円、選択バイアスが約 −60.7万円で、足すと観察できる差の約 −30.4万円にぴったり一致します。小課題 c で確かめてください。

現実のデータでは $Y(0)$ が参加者について見えないので、選択バイアスを直接計算することはできません。第7部の残りでは、選択バイアスを0にする方法（無作為割当、第56ステップ）と、観察できる変数で選択バイアスを取り除こうとする方法（第59〜61ステップ）を学びます。後者は「参加するかどうかが、観察できる変数だけで説明できる」という仮定が成り立つときにだけ使えます。

## 卒論・実務での使いどころ

「〇〇を利用した人は成果が高い（低い）」というデータを見たら、まず「利用しなかったとしても、その人たちは成果が高かった（低かった）のではないか」と選択バイアスを疑う習慣をつけましょう。
