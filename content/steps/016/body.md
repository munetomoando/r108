## 問い

そらまめマーケットは、来年度のパート・アルバイトの時給を見直します。経営企画部のあなたは、その前に「各県の最低賃金は、その県の平均的な賃金の何割か」を調べるよう頼まれました。最低賃金の表と賃金の表という、別々に公表される2つの統計を県と年でつなげて答えます。

## 使う2つの統計

- `wage` … 厚生労働省「賃金構造基本統計調査」の都道府県別の値（2019〜2025年）。一般労働者（短時間労働者を除く）の所定内給与額 `scheduled_wage`（千円/月。残業代などを除いた毎月決まって払われる給与）と、所定内実労働時間数 `hours`（時間/月）です。どちらも**毎年6月分**の値で、男女計・男・女の3行があります。2019年は、2020年調査と同じ推計方法で厚生労働省が集計し直した参考系列の値です
- `mw_raw` … 厚生労働省「地域別最低賃金改定状況」による各県の最低賃金（円/時、2002〜2025年度）と発効日 `effective_date`

まず `glimpse()` で2つの表を見比べましょう。

```r
glimpse(wage)
glimpse(mw_raw)
```

## 県コードの型をそろえる

結合に使う県コード `pref_code` が、`wage` では `<dbl>`（数値の 1, 2, …）、`mw_raw` では `<chr>`（文字の "01", "02", …）になっています。役所や他の部署から届く表では、県コードが2桁の文字になっていることがよくあります。このステップでは setup でわざとこの形にしてあります。

キーの型が違うと、`left_join()` は「incompatible types」というエラーで止まります。数値の 1 と文字の "01" は、人には同じに見えても R には別のものだからです。片方の型をもう片方に合わせましょう。`as.integer()` は文字を整数に変えます。"01" は 1 になり、先頭の0は消えます。

```r
as.integer(c("01", "13", "47"))
mw <- mutate(mw_raw, pref_code = as.integer(pref_code))
```

逆に `wage` の側を `as.character()` で文字にすると、エラーは出ません。ところが北海道〜茨城（1〜9）では "1" と "01" が一致せず、9県分が結合されずに残ります。エラーが出ないことは正しさの証明にならない、という第8ステップの教訓を思い出してください。

## 時期をそろえて、2つのキーで結合する

最低賃金は毎年10月ごろに改定され、「年度」（`fiscal_year`）で表されます。一方、賃金は毎年6月分です。たとえば2025年6月の賃金と比べるべきなのは、2024年10月ごろから効いていた**2024年度**の最低賃金です。2025年度の額は、2025年6月にはまだ効いていません。つまり、Y年6月の賃金には `fiscal_year = Y − 1` の最低賃金を合わせます。

そこで、最低賃金の表に「その額が6月に効いている年」を表す列 `year = fiscal_year + 1` を作り、県コードと年の**2つのキー**で結合します。キーが複数あるときは、`by` に列名を並べます。

```r
mw_wage <- wage |>
  filter(sex == "男女計") |>
  left_join(mutate(mw, year = fiscal_year + 1), by = c("pref_code", "year"))
nrow(mw_wage)
```

`by = "pref_code"` だけで結合すると、1つの県の7年分の賃金それぞれに24年度分の最低賃金がすべて付き、行数が大きく増えてしまいます。結合したら、行数が47県×7年になっているかを必ず確かめましょう。

## カイツ指標を計算する

最低賃金がその地域の賃金に比べてどのくらいの高さかを表す指標を、**カイツ指標**（Kaitz index）と呼びます。ここでは「最低賃金 ÷ 平均時給」とします。月の給与を時給に直すには、千円を円にして（×1000）、月の労働時間で割ります。

```r
kaitz_tbl <- mw_wage |>
  mutate(avg_wage = scheduled_wage * 1000 / hours,
         kaitz = min_wage / avg_wage)
summary(kaitz_tbl$kaitz)
```

値が 0.5 なら、最低賃金が平均時給の5割という意味です。平均時給は短時間労働者を含まない一般労働者のものです。また、6月の労働時間は平日の日数で年ごとに少し上下するので、時給にも暦の影響がわずかに乗ります。実際に年ごと・県ごとの値を表示して、どの県が高いかを確かめてください。

## パートの時給を考えるときに

カイツ指標が高い県では、最低賃金がその県の賃金水準に比べて高い位置にあります。そうした県では、最低賃金ちょうどの時給で募集すると、周りの仕事と比べた魅力の差が小さくなりやすいと考えられます。時給を決めるときは、最低賃金の額だけでなく、その県の賃金水準との比も見ておくとよいでしょう。

## 卒論・実務での使いどころ

県と年の2つのキーで公的統計をつなぐ作業は、最低賃金の影響を調べる卒論でも、店舗のある県の人件費を比べる実務でも、分析の最初の一歩になります。
