## 問い

第73ステップでは、前の月と比べるときは季節調整値、前年同月と比べるときは原数値を使うと学びました。では、季節調整値は原数値からどうやって作るのでしょうか。完全失業率の原数値を、季節の動き・長い期間の動き・それ以外の3つに自分で分けて、統計局が公表している季節調整値と比べます。売上や来店客数にも季節の波があるので、この考え方は需要予測でもそのまま使えます。

## 使うデータ

`lfs` は、総務省統計局「労働力調査」の長期時系列（表1-a-1、2026年8月分公表時点で取得）の2000年1月から2026年8月までの月次の表です。`unemp_rate_nsa` が完全失業率の原数値、`unemp_rate_sa` が統計局の公表した季節調整値です。季節調整値は毎年1月分の公表時に過去にさかのぼって改定されるので、取得した時点の系列であることに注意します。

## 時系列オブジェクト：ts

R には、時系列を扱うための `ts` という形があります。`ts()` は数のベクトルに「いつ始まり、1年に何個の値があるか」を付けます。

```r
u_ts <- ts(lfs$unemp_rate_nsa, start = c(2000, 1), frequency = 12)
```

`start = c(2000, 1)` は「2000年の1か月目から」、`frequency = 12` は「1年に12個（月次）」という意味です。四半期なら `frequency = 4` です。季節の分解では、何個ごとに同じ季節が来るかを `frequency` から読み取ります。

## STL 分解：stl

`stl()` は、時系列を次の3つの**成分**の和に分けます（STL は Seasonal and Trend decomposition using Loess の略です）。

- **季節成分**（seasonal）… 毎年同じ時期にくり返す上下
- **トレンド成分**（trend）… 数年単位のゆっくりした動き。景気の山や谷はここに表れます
- **残差**（remainder）… 上の2つで説明できない、その月だけの動き

原数値 ＝ 季節成分 ＋ トレンド成分 ＋ 残差、です。

```r
fit <- stl(u_ts, s.window = 13)
head(fit$time.series, 12)
```

`fit$time.series` は3列の表で、`fit$time.series[, "seasonal"]` のように列名で取り出せます。b のように `tibble()` で日付と並べ、`pivot_longer()` で縦長にして `facet_wrap()` で段に分けると、4つの系列を上下に並べて見られます。

## s.window の選び方

`s.window` は、季節成分を推定するときに何年分の同じ月を使うかを決める数で、7以上の奇数を指定します。

- `s.window = "periodic"` … 季節成分を全期間で同じ形に固定します
- 数を指定する … その年数ほどの範囲で季節成分を少しずつ変えられます。小さいほど季節の形が変わりやすくなりますが、その年だけの偶然の動きまで季節成分に吸い込んでしまいます

このステップでは `s.window = 13` を使います。失業率の季節の形は、この26年で変わってきたからです。分解すると、12月の季節成分は2000年の約−0.37ポイントから2025年の約−0.21ポイントへ、3月は約+0.31から約+0.07へと小さくなりました。失業率の水準そのものが下がり、季節による上下の幅も縮んだと考えられます。`"periodic"` ではこの変化をとらえられません。13年は、変化を追いつつ偶然の動きを拾いすぎない中ほどの選択です。

成分の図を見ると、トレンド成分は2002年秋に約5.4%の山をつけ、2019年夏に約2.35%まで下がりました。残差が大きいのは2008年10月（約−0.40）や2009年7月（約+0.34）など、リーマン・ショック前後の急な動きの月です。

## 公表の季節調整値と比べる

季節調整値は「原数値 − 季節成分」です。c で、自分で作った値と公表値の差を測ります。

```r
cmp <- comp |>
  mutate(sa_stl = observed - seasonal,
         sa_pub = lfs$unemp_rate_sa,
         gap = sa_stl - sa_pub)
summarise(cmp, mae = mean(abs(gap)), max_gap = max(abs(gap)))
```

`s.window = 13` では、差の絶対値の平均が約0.04ポイント、最大でも約0.14ポイントでした。公表値は0.1ポイント単位に丸めてあるので、平均の差の多くは丸めの範囲に収まります。`s.window = "periodic"` に替えると、平均が約0.06ポイント、最大が約0.23ポイントに広がります。確かめてみましょう。

完全には一致しないのは、統計局が STL ではなく、米国センサス局が開発した別の季節調整の方法を使っているからです。論文や報告で季節調整値を使うときは、自分で作るより公表値を使い、出所と取得した時点を書くのが基本です。

## 卒論・実務での使いどころ

自社の月次売上のように公表の季節調整値がない系列は、`stl()` で季節成分を取り除いてから前月と比べると、季節の波に惑わされずに動きを読めます。
