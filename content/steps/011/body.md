## 問い

そらまめマーケットは、食品スーパーの新しい出店先を探しています。経営企画部のあなたは、上司から「生鮮食品（魚・肉・野菜・果物）にお金をよく使う都市はどこか、家計調査で調べてほしい」と頼まれました。このステップでは、役所の統計表をそのまま R に読み込むときにつまずきやすい、文字化けと見出しの直し方を学びます。

## 使うデータ：家計調査

データは、総務省統計局「家計調査」（2025年、二人以上の世帯）の第4-1表から、52都市の生鮮魚介・生鮮肉・生鮮野菜・生鮮果物の年間支出金額（1世帯当たり、円）を抜き出したものです。都道府県庁所在市と、いくつかの政令指定都市が入っています。値は元の表のままの、本物の公的統計です。

公的統計の CSV は、Excel で見やすいように作られています。このファイルも、65行のうち都市のデータは9〜60行目だけです。

- 1〜5行目：統計名・表番号・表題などの表の情報
- 6〜8行目：見出し（品目名・分類コード・単位）
- 9〜60行目：52都市のデータ（「01100 札幌市」のように地域コード付き）
- 61〜65行目：注記

## 文字化けを直す：locale

コンピュータは文字を数字の列として保存します。その対応表を**文字コード**と呼びます。今の主流は UTF-8 ですが、日本の役所や古い Excel の CSV には Shift-JIS（Windows 版は CP932）がよく使われます。`read_csv()` は何も指定しないと UTF-8 として読むので、Shift-JIS のファイルは文字化けします。このアプリでは、化けた列名を表示しようとして「invalid multibyte string」というエラーになります。

文字コードは、引数 `locale` に `locale(encoding = "CP932")` を渡して指定します。

```r
read_csv("data/kakei_raw_sjis.csv", skip = 5, n_max = 3,
         locale = locale(encoding = "CP932"))
```

`skip = 5` は先頭の5行を飛ばす指定、`n_max = 3` は3行だけ読む指定です。大きなファイルは、まずこのように数行だけ読んで中身を確かめると安全です。

## 見出し行を飛ばす：skip と n_max

上の結果では、6行目の品目名が列名になりました。ところが1行目に分類コード（1.2.1 など）、2行目に単位（円）が入るため、金額の列まで文字（`<chr>`）として読まれています。文字のままでは足し算ができません。

そこで、見出しの3行も含めて先頭の8行を飛ばし、都市の52行だけを読みます。`col_names = FALSE` は「1行目を列名に使わない」という指定で、列名は X1〜X5 になります。

```r
kakei_b <- read_csv("data/kakei_raw_sjis.csv",
                    locale = locale(encoding = "CP932"),
                    col_names = FALSE, skip = 8, n_max = 52)
kakei_b
```

`n_max` を付け忘れると、末尾の注記まで読み込まれます。読み込んだら、行数が元の表の都市数と合っているかを必ず確かめましょう。

## 列名を英字に：rename と clean_names

X1〜X5 では何の列か分かりません。`rename()` で名前を付け直します。書き方は `rename(新しい名前 = 古い名前)` です。

```r
kakei <- kakei_b |>
  rename(city = X1, fish = X2, meat = X3, vegetables = X4, fruits = X5)
```

列名を英字にしておくと、引用符なしで書けて打ち間違いも減ります。

列名に空白や記号が混じった表を受け取ることもあります。janitor パッケージの `clean_names()` は、そうした列名を小文字・数字・「_」だけの名前に一括で整えます。

```r
memo <- data.frame(check.names = FALSE,
                   "Store ID" = c("S01", "S02"),
                   "Sales 2025" = c(98000, 125000))
clean_names(memo)
```

列名は `store_id` と `sales_2025` になります。ただし、日本語の列名に使うと「生鮮魚介」が中国語の読み（ピンイン）の `sheng_xian_yu_jie` になってしまいます。日本語の見出しは、`rename()` で自分で名前を付ける方が分かりやすいでしょう。

## 生鮮食品への支出が多い都市

正しく読めたら、上司の問いに答えましょう。4品目を足して合計を作り、多い順に並べます。

```r
kakei |>
  mutate(total = fish + meat + vegetables + fruits) |>
  arrange(desc(total)) |>
  select(city, total)
```

どの都市が上位に並ぶか、実行して確かめてください。ただし、これは1世帯当たりの金額です。出店先を決めるには、世帯数や競合店の数もあわせて見る必要があります。

## 卒論・実務での使いどころ

e-Stat などからダウンロードした統計表は、読み込んだ直後に文字化け・見出し・行数の3点を確かめてから分析に進みましょう。
