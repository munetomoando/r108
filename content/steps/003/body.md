## 問い

あなたは、食品スーパーを50店舗運営する「そらまめマーケット」の経営企画部に配属されたばかりです（会社もデータも、この教材のための架空のものです）。初日、上司からこう頼まれました。「うちで今年いちばん売上が多かった店はどこか、店舗データから確かめておいて」。このステップでは、表の形のデータを R に読み込み、全体を眺め、売上が最も多い店舗を自分で探します。

## データフレームとは

第2ステップでは、値を一列に並べたベクトルを学びました。実際の仕事で受け取るデータは、Excel のような表の形をしています。R では、この表を**データフレーム**と呼びます。データフレームは、同じ長さのベクトル（列）を横に並べたものです。1行が1つの観測（ここでは1つの店舗）、1列が1つの変数（売上や客数など）に当たります。

## CSV ファイルを読み込む

**CSV ファイル**は、値をカンマで区切って並べた、表のデータを保存する一般的な形式です。社内のシステムから書き出したデータも、多くは CSV で渡されます。CSV を読み込むには、readr パッケージの `read_csv()` を使います。**パッケージ**とは、R に機能を追加する拡張セットのことで、`library()` で呼び出します。このステップでは、最初から呼び出してあります。

```r
library(readr)
stores <- read_csv("data/sora_stores.csv", show_col_types = FALSE)
```

`"data/sora_stores.csv"` はファイルの場所です。`show_col_types = FALSE` は、読み込み時の細かい説明を表示しないための指定で、省略しても構いません。読み込んだ表は、`stores` という名前で保存しました。このデータには、店舗ごとの地域、立地（駅前・郊外・商業施設）、売場面積、従業員数、客数、今年と前年の売上高（万円）などが入っています。

## 全体を眺める

データを受け取ったら、計算を始める前にまず中身を眺めます。そのための関数がいくつかあります。

```r
head(stores)       # 最初の6行を表示
nrow(stores)       # 行数
glimpse(stores)    # 列ごとの型と最初の値
```

`head()` は表の先頭だけを見せます。全体を表示すると長くなりすぎるときに便利です。`nrow()` は行数を返します。`glimpse()` は dplyr パッケージの関数で、列の名前・型・最初のいくつかの値を横向きに一覧にします。`<chr>` は文字、`<dbl>` は数値を表します。列が多い表でも、どんな変数があるかを一目でつかめます。

次に、`summary()` で列ごとの要約を見てみましょう。

```r
summary(stores)
```

数値の列については、最小値（Min.）、平均（Mean）、最大値（Max.）などが表示されます。桁を一つ間違えたような極端な値や、マイナスの客数のようなありえない値がないかを確かめるのに役立ちます。

## 1つの列を取り出す

データフレームから1つの列を取り出すには、`$` を使って `データフレーム$列名` と書きます。取り出した列はベクトルなので、第2ステップの `sum()` や `mean()` がそのまま使えます。

```r
stores$sales
mean(stores$staff)
```

## いちばん大きい値を探す

売上が最大の店舗を探すには、`which.max()` が便利です。この関数は、ベクトルの中で最大の値が「何番目」にあるかを返します。ベクトルの後ろに `[ ]` を付けて番号を入れると、その位置の要素を取り出せます。

```r
which.max(stores$sales)
stores$store_name[which.max(stores$sales)]
```

2行目では、「売上が最大になる位置」を使って、同じ位置にある店舗名を取り出しています。売上の列と店舗名の列は、同じ行どうしで対応しているので、このような取り出し方ができます。実行して、どの店舗が出てくるか確かめましょう。都心の駅前店でしょうか、それとも郊外の大型店でしょうか。

## 卒論・実務での使いどころ

社内のデータでも卒論の調査データでも、受け取ったら `glimpse()` と `summary()` で列の型と値の範囲を確かめてから分析を始めると、読み込みの失敗や入力ミスに早く気づけます。
