## 問い

第7部では、一人ひとりを1回だけ観察したデータで比べました。同じ県を毎年くり返し観察すると、何ができるようになるのでしょうか。

## パネルデータとは

第8部で使うのは `mw`（minwage_panel）です。47都道府県を2012〜2024年の13年間、毎年観察した**架空のパネルデータ**です。同じ対象（ここでは県）を複数の時点で観察したデータを**パネルデータ**といいます。

設定は次のとおりです。12県で2019年から「最低賃金の特別引上げ」（架空の政策）が行われました。`treated` は対象県なら1、`post` は2019年以降なら1です。`youth_emp_rate` は若年（15〜24歳）、`adult_emp_rate` は成人（25〜64歳）の就業率（%）です。教材用の合成データなので、若年就業率への真の効果は決めてあります（経過0年 −0.5、1年 −0.8、2年以降 −1.0ポイント）。成人就業率への効果はありません。また2020年には、全県で一律に若年就業率が下がるように作ってあります。

パネルデータを扱う前に、まず「県×年で1行」になっているかを確かめます。同じ県・同じ年の行が2つあると、平均や回帰の結果がずれます。

```r
mw |>
  count(pref_code, year) |>
  filter(n > 1)
mw |>
  summarise(県の数 = n_distinct(pref_code), 年の数 = n_distinct(year), 行数 = n())
```

`n_distinct()` は、列に何種類の値があるかを数える関数です。47県 × 13年 = 611行で、重複がなければ1つ目の結果は0行になります。全県が全年そろっているパネルを**バランスパネル**といいます。

## 県内平均を引く

県によって若年就業率の水準はかなり違います。産業の構成や進学率など、県ごとにほぼ変わらない事情があるからです。そこで、各県の値から「その県の13年間の平均」を引いてみます。

```r
mw_dm <- mw |>
  group_by(pref_code) |>
  mutate(youth_mean = mean(youth_emp_rate),
         youth_dm = youth_emp_rate - youth_mean) |>
  ungroup()
mw_dm |>
  summarise(sd_raw = sd(youth_emp_rate), sd_dm = sd(youth_dm))
```

`group_by()` のあとの `mutate()` では、`mean()` はグループ（県）ごとに計算されます。`ungroup()` はグループを外す関数です。外し忘れると、後の集計が県ごとに行われてしまいます。

標準偏差は、元の値で約2.84、県内平均を引いた後で約1.09です。若年就業率のばらつきの多くは「県による水準の違い」でした。県内平均を引くと、その違いが消え、「同じ県の中で、いつもより高い年・低い年」だけが残ります。この変換を **within 変換**（群内変換）といいます。第65ステップの固定効果モデルは、この考え方で県の違いを取り除きます。

## 処置群と対照群の推移を描く

引上げの対象県（**処置群**）と対象外の県（**対照群**）の平均を、年ごとに描きます。

```r
trend <- mw |>
  group_by(treated, year) |>
  summarise(youth = mean(youth_emp_rate), .groups = "drop")
ggplot(trend, aes(x = year, y = youth, colour = factor(treated))) +
  geom_line() +
  geom_vline(xintercept = 2018.5, linetype = "dashed")
```

`.groups = "drop"` は、集計した後にグループを外す指定です。

図から3つのことが読み取れます。1つ目に、処置群は最初から水準が高く、2012年に約42.8%（対照群は約41.3%）、2018年に約44.1%（約42.7%）です。差は約1.4〜1.5ポイントです。2つ目に、2018年までの2本の線はほぼ平行に上がっています。3つ目に、2020年には両方の群で前年より下がります（対照群は約1.6ポイント、処置群は約2.3ポイント）。2019年以降、2本の差は縮み、2024年には約0.27ポイントになりました。

ここで「2019年以降の処置群と対照群の差」だけを見ると、処置群の方が高いので「引上げは就業を増やした」と誤って読みそうです。もともとの水準の違いと、全国共通の動きを分けて考える必要があります。これが第65・66ステップの固定効果と差の差分析の出発点です。

## 卒論・実務での使いどころ

卒論で都道府県や企業のパネルデータを使うときは、最初に「単位×時点で1行か」を確かめ、処置群と対照群の推移の図を示してから推定に進みます。
