## 問い

5つの都市でワンルームの家賃を調べました。その平均はいくらでしょうか。また、家賃が8万円を超える都市はいくつあるでしょうか。このステップでは、複数の値をまとめて扱う「ベクトル」を学びます。

## ベクトルを作る

第1ステップでは、1つの変数に1つの数を入れました。データ分析では、たくさんの値をまとめて扱います。R では、値を一列に並べたものを**ベクトル**と呼び、`c()` で作ります。c は combine（結合する）の頭文字です。

```r
rent <- c(7.2, 6.5, 8.8, 5.9, 9.4)
rent
length(rent)
```

`length()` は、ベクトルに入っている値（**要素**）の個数を返します。

ベクトルの便利な点は、計算がまとめてできることです。たとえば `rent * 10000` と書くと、5つの家賃がすべて円に換算されます。1つずつ計算する必要はありません。

## 合計と平均

ベクトルの合計は `sum()`、平均は `mean()` で求めます。

```r
sum(rent)
mean(rent)
sum(rent) / length(rent)
```

3行目は、平均の定義（合計 ÷ 個数）どおりに計算したものです。`mean()` と同じ結果になることを確かめてみましょう。

## データの型

ベクトルに入る値には、いくつかの**型**（種類）があります。よく使うのは次の3つです。

- 数値（numeric）：`7.2` や `100` など、計算できる数
- 文字（character）：`"東京"` のように `"` で囲んだ文字列
- 論理値（logical）：`TRUE`（真）と `FALSE`（偽）の2つだけ

型は `class()` で調べられます。

```r
class(rent)
city <- c("東京", "大阪", "名古屋", "福岡", "札幌")
class(city)
class(TRUE)
```

1つのベクトルには、1つの型しか入りません。数値と文字を混ぜると、R は全部を文字に変えてしまいます。数値に見えても文字になっていると、平均などの計算ができません。データを読み込んだら、まず型を確かめる習慣をつけましょう。

## 比較と論理値

`>` や `<` で比べると、結果は論理値になります。ベクトルに対して比べると、要素ごとに TRUE か FALSE が返ります。

```r
rent > 8
sum(rent > 8)
```

`sum()` は TRUE を1、FALSE を0として足し算します。そのため `sum(rent > 8)` で「8万円を超える都市の数」が数えられます。「等しい」は `==` と、イコールを2つ重ねて書く点に注意しましょう。

## 欠損値 NA

実際のデータには、調べられなかった値が含まれることがあります。R ではこれを **NA**（Not Available、欠損値）で表します。NA を含むベクトルの平均を求めると、結果も NA になります。分からない値が1つでもあれば、平均も分からないと考えるからです。

```r
rent_na <- c(7.2, 6.5, NA, 5.9, 9.4)
mean(rent_na)
mean(rent_na, na.rm = TRUE)
```

`na.rm = TRUE` は「NA を取り除いて（remove）計算する」という指定です。このように、関数には `名前 = 値` の形で細かい指定を渡せます。ただし NA を除いた平均は、残りの4都市だけの平均です。なぜ値が欠けたのかを考えずに除くと、結果がゆがむこともあります。

## 卒論・実務での使いどころ

アンケートや統計データには必ずと言ってよいほど欠損値があるため、型と NA を確かめてから `mean()` や `sum()` で集計するのが、卒論でも実務でも基本の手順になります。
