## 問い

時系列のデータを2つ並べて回帰すると、まったく関係のない系列どうしでも、強い相関と小さな p 値が出ることがあります。なぜでしょうか。このステップでは、鉱工業生産指数を使って**階差**と**自己相関**を学び、乱数の実験で「見せかけの回帰」を自分で起こしてみます。第76〜80ステップの予測モデルを使う前に、時系列ならではの落とし穴を知っておきます。

## 使うデータ

`iip` は、経済産業省「鉱工業生産・出荷・在庫指数」（2020年基準）の鉱工業総合の月次の値です。2026年10月24日に同省のサイトから取得した時点の系列で、2018年1月から2026年8月までの104か月あります。2020年の平均を100とする指数で、工場や鉱山の生産量の動きを表します。

- `iip_sa` … 季節調整済指数。季節による上下を取り除いた値です
- `iip_nsa` … 原指数。調べたままの値です

2020年基準の系列は2018年1月から始まるので、それより前の月はありません。季節調整済指数は毎年の年間補正で過去にさかのぼって改定されるため、当時の発表と違う月があります。

季節調整済指数の年平均は、2018年が約114.6、2020年が約99.7、2024年が約100.8でした。2018年からの数年で、水準がはっきり下がっています。

## 階差：diff

`diff()` は、隣どうしの差「今月 − 前月」をとります。これを**階差**（1階の階差）といいます。第73ステップの `iip_sa - lag(iip_sa)` と同じ値ですが、`diff()` は最初の月（前の月がない月）を落とすので、104か月から103個の前月差ができます。

```r
y <- ts(iip$iip_sa, start = c(2018, 1), frequency = 12)
dy <- diff(y)
```

水準 `y` は数年かけて上下しますが、前月差 `dy` は0のまわりを上下します。前月差の標準偏差は約2.6ポイントです。最も大きく下がったのは2020年4月（−10.6ポイント）で、2020年7月には+5.9ポイント戻しています。コロナ禍の落ち込みと回復です。

平均や散らばりが時期によって変わらない系列を**定常**な系列といいます。水準 `y` のように、ゆっくりした動き（**トレンド**）で平均が変わっていく系列は**非定常**です。経済の多くの系列は水準では非定常で、階差をとると定常に近づきます。

## 自己相関：acf

`acf()` は**自己相関**、つまり「今月の値と k か月前の値の相関」を k = 0, 1, 2, … について求め、棒の図にします。

```r
acf_y <- acf(y, lag.max = 12)
acf_dy <- acf(dy, lag.max = 12)
```

図の横軸は ts の年単位で、1.0 が12か月です。青い点線は、本当は相関がないときに棒がおおむね収まる範囲（約±0.19）です。

- 水準 `y` … 1か月前との相関が約0.89、12か月前とでも約0.16です。先月が高ければ今月も高い、という関係が長く続きます
- 前月差 `dy` … 1か月前との相関は約−0.01で、ほとんどの棒が点線の内側です。12か月目だけ約−0.24と少しはみ出しますが、12本の棒のうち1本ほどは偶然はみ出してもおかしくありません

水準の自己相関がゆっくりとしか減らないことは、非定常な系列の目印です。

## 見せかけの回帰

**ランダムウォーク**は、「先月の値 ＋ 今月の偶然の動き」をくり返した系列です。`cumsum(rnorm(100))` で、偶然の動きを100か月分積み上げて作れます。偶然の積み重ねなので、たまたま何年も上がり続けたり、下がり続けたりします。

```r
set.seed(75)
p_rw <- replicate(500, {
  x <- cumsum(rnorm(100))
  z <- cumsum(rnorm(100))
  summary(lm(z ~ x))$coefficients[2, 4]
})
mean(p_rw < 0.05)
```

`x` と `z` は別々の乱数から作ったので、本当の関係はありません。それでも c の実験では、500回のうち約8割で x の係数が5%水準で有意になります。同じ実験を、積み上げない `rnorm(100)` どうしで行うと約5%です。関係のない非定常な系列どうしの回帰で、有意な結果が出てしまうことを**見せかけの回帰**といいます。

原因は、2本とも一方向にさまようことにあります。同じ期間に両方が下がれば、関係がなくても水準どうしは強く相関します。鉱工業生産のように2018年から下がってきた系列を、同じ時期に下がり続けた別の系列と並べれば、それだけで高い相関が出ます。通常の p 値は、観測が互いに独立に近いことを前提にしているので、この状況では当てになりません。

対策の基本は、**階差をとってから**関係を調べることです。`lm(diff(z) ~ diff(x))` に替えると、有意になる割合は約6%に下がります。水準どうしの強い相関を見たら、「両方にトレンドがあるだけではないか」とまず疑います。

## 卒論・実務での使いどころ

「売上と広告費の推移がよく似ている」のような時系列どうしの比較では、水準ではなく前月差や前年同月比で相関を確かめると、見せかけの関係にだまされにくくなります。
