## 問い

上司から「クーポンで2割引きにすると、どれだけ多く売れるのか。それで利益は増えているのか」と聞かれました。そらまめマーケット（架空の会社）のネット通販では、クーポンを注文ごとに無作為に配っています。この「無作為」を手がかりに、**価格弾力性**を推定し、値引きが利益に与える影響を計算します。

## クーポンの有無で数量を比べる

**価格弾力性**は、価格が1%上がったときに数量が何%変わるかを表す数です。値引きで数量が増えるなら、弾力性は負になります。−1 より小さい（絶対値が1より大きい）とき、需要は価格に「敏感」だといいます。

まず、クーポンあり（`coupon = 1`）となしで1明細あたりの平均数量を比べます。1つの注文に複数の明細があるので、明細の数 `n()` と注文の件数 `n_distinct(order_id)` は分けて数えます。

```r
orders |>
  group_by(coupon) |>
  summarise(lines = n(), n_orders = n_distinct(order_id), qty = mean(qty))
```

クーポンなしの平均数量は約1.60個、ありは約2.26個で、約1.41倍です。価格は0.8倍なので、弾力性は大まかに $\log(2.26/1.60) / \log(0.8) \approx -1.53$ と計算できます。2割の値引きで、数量が4割ほど増えるということです。

## 対数-対数の回帰で推定する

数量と価格の両方を対数にした回帰 $\log(\text{数量}) = a + e \log(\text{価格})$ の係数 $e$ は、そのまま弾力性になります（**対数-対数回帰**）。商品とクーポンの有無ごとに平均数量と平均価格を求め、400行の表 `pq` にして回帰します。

```r
m_pool <- lm(log(qty) ~ log(price), data = pq)
m_fe <- feols(log(qty) ~ log(price) | product_id, data = pq, cluster = ~product_id)
```

2つの係数は大きく違います。`m_pool` は約 −0.18、`m_fe` は約 −1.53（商品でクラスタした標準誤差は約0.03）です。

`m_pool` は、家電のような高い商品と食品のような安い商品を比べています。高い商品はもともと1個ずつ買われることが多いので、この比較には「値引きの効果」ではなく「商品の違い」が混ざります。商品の固定効果を入れた `m_fe` は、**同じ商品の**クーポンあり・なしを比べます。クーポンは注文ごとに無作為なので、同じ商品の中では、クーポンの有無以外に違いはありません。だから `m_fe` の係数を値引きの因果効果と読めます。第56ステップの無作為化実験と同じ考え方です。

## 値引きで利益は増えるか

数量が増えても、利益が増えるとは限りません。1明細あたりの粗利を（販売単価 − 仕入原価）× 数量 で計算し、クーポンの有無で比べます。仕入原価 `unit_cost` は商品マスタ `products` にあります。

| | 平均売上 | 平均粗利 |
| --- | --- | --- |
| クーポンなし | 約2,474円 | 約1,058円 |
| クーポンあり | 約2,777円 | 約789円 |

売上は約12%増えますが、粗利は約25%減ります。仕入原価は定価の6割近くあるので、2割引くと1個あたりのもうけが大きく削られ、数量が4割増えても取り戻せません。

ほかの値引き率ではどうでしょうか。値引き率を $d$ とすると、価格は $(1-d)$ 倍、数量は $(1-d)^e$ 倍になります。仕入額は数量に比例し、値引きしても単価は変わりません。

$$\text{粗利}(d) = (1-d)^e \times \{(1-d) \times \text{売上}_0 - \text{仕入額}_0\}$$

ここで $\text{売上}_0$・$\text{仕入額}_0$ はクーポンなしの1明細あたりの平均です。`tibble(discount = seq(0, 0.3, by = 0.05))` に、この式で粗利の見込みを付けます。粗利は値引きしないとき（$d = 0$）が最も大きく、値引き率を上げるほど減っていきます。$d = 0.2$ の見込みは約793円で、実際のクーポンありの約789円とほぼ一致します。

ただし、この計算には限界があります。観察したのは0%と20%の2つの価格だけで、ほかの値引き率では「弾力性がどの価格でも同じ」という仮定を置いた見込みです。また、クーポンが新しい客を呼ぶ、次の注文につながる、といった効果はこの計算に入っていません。上司には「この注文の中だけで見れば、2割引きは数量を約1.4倍にするが、1明細あたりの粗利を約25%減らす」と、範囲を区切って報告します。

## 卒論・実務での使いどころ

値引きや価格改定の効果を測るときは、価格が無作為に（または外から）変わった部分だけを使い、商品の固定効果で商品の違いを取り除いてから、売上ではなく利益で評価します。
