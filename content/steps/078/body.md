## 問い

第76・77ステップでは、AR モデルや ARIMA モデルで鉱工業生産指数を予測しました。でも、その予測はどれくらい当たるのでしょうか。「この先も今と同じ値」という、何も考えない**素朴な予測**より本当に良いのでしょうか。モデルを使う前に、この問いに答えておく必要があります。

## データ

`iip` は、経済産業省「鉱工業生産指数」（2020年基準、2026年10月24日に取得）の鉱工業総合です。2018年1月から2026年8月までの104か月分で、季節調整済指数 `iip_sa` を使います。季節調整済指数は毎年の年間補正で過去にさかのぼって改定されるので、取得した時点の値であることに注意します。

## 訓練期間とテスト期間

モデルを推定したデータで当てはまりを測ると、実力より良く見えます。そこで、データの終わりの24か月（2024年9月〜2026年8月）を**テスト期間**として取っておき、それより前の80か月を**訓練期間**とします。モデルは訓練期間だけで推定し、テスト期間の値は「まだ知らない未来」として答え合わせにだけ使います。

```r
train <- filter(iip, date < ymd("2024-09-01"))
test <- filter(iip, date >= ymd("2024-09-01"))
y_train <- ts(train$iip_sa, start = c(2018, 1), frequency = 12)
m_ar <- arima(y_train, order = c(1, 0, 0))
pred_ar <- as.numeric(predict(m_ar, n.ahead = 24)$pred)
```

ここでは、訓練期間の終わり（2024年8月）から24か月先までを**一度に**予測します。

## RMSE と MAE

予測の誤差 $e_t$ ＝ 実際の値 − 予測値 を、2つの指標にまとめます。

- **RMSE**（平均二乗誤差の平方根）$\sqrt{\frac{1}{h}\sum e_t^2}$ … 誤差を2乗するので、大きな外れを重く数えます
- **MAE**（平均絶対誤差）$\frac{1}{h}\sum |e_t|$ … 外れの大きさをそのまま平均します

どちらも元の値と同じ単位（ここでは指数のポイント）で、小さいほど良い予測です。R では `sqrt(mean((test$iip_sa - pred_ar)^2))` と `mean(abs(test$iip_sa - pred_ar))` です。

## 2つの素朴な予測

素朴な予測（ナイーブ予測）には、よく使う形が2つあります。どちらも推定はいりません。

- **ナイーブ予測（最後の値）** … 訓練期間の最後の月の値を h か月並べます。`rep(tail(train$iip_sa, 1), 24)` です。`tail(x, 1)`（第76ステップ）で最後の1個を取り出し、`rep(値, 24)` で同じ値を24個並べます。**h か月先の予測**で、第81ステップの総合演習でもこの形を使います
- **前月値予測** … 毎月、「今月は先月の実績と同じ」と予測し直します。`lag(iip_sa)` で作れます。毎月の最新の実績を使う、**1か月先の予測のくり返し**です

## 結果を読む

AR(1) の RMSE は約3.16、ナイーブ予測（最後の値＝100.5）は約1.87で、**AR(1) は素朴な予測に負けました**。AR(1) の予測は、遠い先ほど訓練期間の平均（約106.2）に戻ります。ところが訓練期間には、110を超える月が21か月ある2018〜19年が入っていて、平均を押し上げていました。実際の値は99〜105の横ばいだったので、上がり続ける予測が外れたのです。

前月値予測の RMSE は約1.51で、さらに小さく見えます。ただし、これは毎月の実績を見て予測し直しているので、24か月先を一度に予測した2つとは条件が違います。公平に比べるには、AR(1) も1か月ずつ予測し直します。AR(1) の1か月先の予測は「平均 ＋ ar1 ×（先月の値 − 平均）」です。

```r
mu <- coef(m_ar)[["intercept"]]
phi <- coef(m_ar)[["ar1"]]
test_prev <- iip |>
  mutate(pred_prev = lag(iip_sa)) |>
  filter(date >= ymd("2024-09-01")) |>
  mutate(pred_ar1 = mu + phi * (pred_prev - mu))
summarise(test_prev, rmse = sqrt(mean((iip_sa - pred_ar1)^2)))
```

結果は約1.50で、前月値予測とほとんど同じです。このデータでは、AR(1) は素朴な予測にはっきり勝てませんでした。なお、予測がよく当たっても、何が生産を動かしたかという因果関係は分かりません。

## 卒論・実務での使いどころ

予測モデルを報告するときは、テスト期間の RMSE・MAE を、同じ条件（同じ何か月先か）のナイーブ予測と並べて示すと、モデルを使う意味があるかが一目で伝わります。
