## 問い

本体価格1,980円の商品は、消費税10%を加えるといくらになるでしょうか。また、100万円を年2%で10年間預けると、いくらに増えるでしょうか。このステップでは、R を電卓として使ってこの2つを計算します。

## R に計算をさせる

R（アール）は、データの分析によく使われるプログラミング言語です。プログラミング言語とは、コンピュータに仕事を頼むための決まった書き方のことです。いちばん簡単な使い方は、電卓としての使い方です。下の枠に式を書いて実行すると、すぐに答えが表示されます。

```r
1980 * 1.1    # 掛け算
263 - 248     # 引き算
15 / 248      # 割り算
2^10          # べき乗（2の10乗）
```

足し算は `+`、引き算は `-`、掛け算は `*`、割り算は `/`、べき乗は `^` で書きます。数学と同じく、掛け算・割り算は足し算・引き算より先に計算されます。先に計算させたい部分は `( )` で囲みます。

`#` から行の終わりまでは**コメント**です。コメントは R に無視されるので、人間向けのメモとして自由に書けます。後で読み返したときに、何をしたかったかが分かるように書いておきましょう。

割り算には、ほかに2つの書き方があります。`%/%` は割り算の商（整数の部分）を、`%%` は余りを返します。

## 結果に名前を付けて保存する

計算結果は、名前を付けて保存できます。これを**代入**といい、`<-` という記号を使います。保存した入れ物を**変数**（オブジェクト）と呼びます。

```r
price <- 1980
price_tax <- price * 1.1
price_tax
```

1行目で、`price` という名前に1980を入れています。2行目では、その `price` を使って税込価格を計算し、`price_tax` に入れています。代入しただけでは何も表示されません。3行目のように名前だけを書いて実行すると、中身が表示されます。

変数を使うと、価格が変わったときに1行目を書き換えるだけで済みます。数字を何度も書き写す必要がなく、写し間違いも防げます。名前には英字・数字・`_` を使い、中身が分かる名前を付けましょう。大文字と小文字は区別されます。

## 関数を使う

R には、よく使う計算があらかじめ**関数**として用意されています。関数は `関数名(入力)` の形で使います。かっこの中に渡す値を**引数**（ひきすう）と呼びます。

```r
sqrt(2)               # 平方根（ルート）
round(3.14159, 2)     # 小数第2位に丸める
```

`round()` は四捨五入に近い丸めを行う関数で、2つ目の引数で残す桁数を指定します。成長率のように桁の多い数を報告するときに便利です。

```r
growth <- (263 - 248) / 248 * 100
round(growth, 1)
```

この例では、売上が248から263に増えたときの成長率を%で求め、小数第1位に丸めています。引き算をかっこで囲まないと、割り算が先に計算されて別の答えになるので注意しましょう。

## 複利の計算

年利2%の複利とは、毎年「前の年の残高 × 1.02」になることです。1年後は元本の1.02倍、2年後はさらにその1.02倍になります。10年後は1.02を10回掛けることになるので、べき乗を使って次のように書けます。

```r
1000000 * (1 + 0.02)^10
```

単利（毎年、元本の2%だけ増える）と比べると、どれだけ違うでしょうか。`1000000 * (1 + 0.02 * 10)` も実行して比べてみましょう。

## 卒論・実務での使いどころ

物価上昇率や成長率をその場で計算し、変数に保存して後の分析で使い回すことは、卒論でも実務でもあらゆる分析の出発点になります。
