## 問い

そらまめマーケットの経営企画部で、来週の会議資料の点検を任されました。先輩が作った図を見ると、どれも「言いたいこと」がはっきり伝わります。ただ、伝わりすぎてはいないでしょうか。図のどこが「ずるい」のかを見抜き、誤解のない図に直します。

## 縦軸を切ると、差が大きく見える

setup では、`stores` を地域ごとに集計し、今年（`sales`）と前年（`sales_last`）の売上（万円）を縦長にした `region_long` を用意しています。先輩の図 `p_cut` は次のコードで作ったものです。小課題 c や d のエディタに `p_cut` とだけ書いて「試しに実行」すると、図が出ます。

```r
ggplot(region_long, aes(x = region, y = sales, fill = period)) +
  geom_col(position = "dodge") +
  coord_cartesian(ylim = c(480000, 1450000), expand = FALSE)
```

`geom_col(position = "dodge")` は、今年と前年の棒を横に並べる指定です。`coord_cartesian(ylim = ...)` は、図の表示する範囲だけを決める関数で、カメラを寄せるように一部を拡大します。ここでは縦軸を480,000万円から始めているので、北海道・東北の今年の棒は前年の何倍にも見えます。

数字で確かめましょう。

```r
region_sales
```

北海道・東北の前年比は4.3%増、中国・四国は1.5%減です。棒グラフは「棒の長さ＝量」として読まれるので、縦軸は0から始めるのが原則です。

縦軸の範囲は `scale_y_continuous(limits = c(下限, 上限))` でも決められます。`NA` は「データに合わせて自動で決める」という意味です。`limits = c(0, NA)` なら「0から、上はデータに合わせて」になります。

```r
ggplot(region_long, aes(x = region, y = sales, fill = period)) +
  geom_col(position = "dodge") +
  scale_y_continuous(limits = c(0, NA))
```

2つの関数には違いがあります。`coord_cartesian()` は表示を拡大するだけで、データは残します。`scale_y_continuous(limits = ...)` は、範囲の外のデータを捨ててから描きます。下限を480,000にすると、0から伸びる棒は範囲の外に出るので、すべて消えて警告が出ます。

なお、折れ線グラフでは縦軸を0から始めなくてもかまいません。線は「長さ」ではなく「変化の形」を見せるものだからです。

## 二軸グラフは、作り手が「相関」を作れる

もう1つの資料には、総務省統計局「労働力調査」の完全失業率（失業者が働く意思と能力のある人に占める割合、季節調整値）と、同「消費者物価指数」（2025年基準）の総合指数を、左右2本の縦軸で1枚に描いた図がありました。期間は2013年1月〜2019年12月です。

```r
ggplot(both, aes(x = date)) +
  geom_line(aes(y = unemp_rate_sa)) +
  geom_line(aes(y = (cpi_all - 84) / 3 + 2.2), colour = "red") +
  scale_y_continuous(sec.axis = sec_axis(~ (. - 2.2) * 3 + 84))
```

右の縦軸（`sec_axis()`）は、物価指数を左の目盛りに換算して描いた線に、逆の換算をした目盛りを付けているだけです。`84` や `3` は作り手が自由に選べます。setup の `p_dual1` と `p_dual2` は、この数字だけを変えた2枚です。片方では2本の線が大きく交差して強い関係があるように見え、もう片方では物価がほとんど動かないように見えます。

2つの指標の関係を見せたいなら、散布図と相関係数（第24ステップ）を使います。それぞれの推移を見せたいなら、図を上下に2枚並べます。

## 面積の誇張

「売上を円の大きさで表す」図にも注意が必要です。関東の売上は北海道・東北の約2.8倍です。円の直径を2.8倍にすると、面積は2.8の2乗で約8倍になります。見る人は面積で量を感じるので、差が8倍に見えてしまいます。絵や円で量を表すときは、直径でなく面積を量に比例させます。迷ったら棒グラフにしましょう。

## 卒論・実務での使いどころ

図を作ったら「縦軸は0からか」「二軸で関係を演出していないか」「面積で誇張していないか」の3点を確かめる習慣が、会議資料にも卒論の図にも信頼を与えます。
