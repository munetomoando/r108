## 問い

第97ステップの決定木は読みやすい一方で、データが少し変わるだけで形が大きく変わる、不安定なモデルでした。上司から「木をたくさん作って多数決にする**ランダムフォレスト**という方法があるらしい。それで解約の予測はどこまで当たるようになるのか」と聞かれています。

## 木をたくさん作って平均する

**ランダムフォレスト**は、決定木を何百本も作り、その予測を平均する方法です。1本1本の木は次の2つの工夫で、わざと少しずつ違うものにします。

1. 訓練データから、重複を許して同じ人数を無作為に選び直したデータで木を作る（**ブートストラップ**）
2. 枝を分けるたびに、説明変数のうち一部（ここでは6つのうち2つ）だけを無作為に選び、その中から分け方を探す

1本の木は外れやすくても、違う間違え方をする木を平均すると、外れ方が打ち消し合って予測が安定します。くじ引きを2重に使うので、結果は乱数で変わります。必ず `set.seed()` で乱数を固定してから当てはめます。

tidymodels では、モデルを `rand_forest()` に替えるだけで、ワークフローの残りは第93〜97ステップと同じです。レシピ `churn_rec`（6つの説明変数）は、第95ステップと同じものを setup で作ってあります。

```r
set.seed(108)
rf_fit <- workflow() |>
  add_recipe(churn_rec) |>
  add_model(rand_forest(trees = 200) |>
              set_engine("randomForest", importance = TRUE) |>
              set_mode("classification")) |>
  fit(data = churn_train)
```

`trees = 200` は木の本数です。エンジン（実際に計算するパッケージ）には randomForest を使います。よく使われる ranger は、このアプリ（ブラウザの中の R）では動かないためです。`importance = TRUE` は、後で変数の重要度を計算するための指定です。ブラウザでは当てはめに数秒かかります。

`rf_fit` を表示すると、**OOB 誤り率**が出ます。各木は、ブートストラップで選ばれなかった約3分の1の客を使っていません。その客で測った誤り率で、テストデータを使わずに当たり具合の目安が分かります。ここでは約22.9%です。

## ロジスティック回帰と比べる

b では、テストデータ1,251人で AUC（第96ステップ）を比べます。結果は、ロジスティック回帰が約0.743、ランダムフォレストが約0.685でした。**ランダムフォレストの方が当たりません。**

理由の一つは、木を最後まで伸ばしていることです。`rand_forest()` の既定では、葉に客が1人になるまで枝を分けます。解約には偶然の要素が大きいので、木が訓練データの偶然まで覚えてしまいます（第92ステップの過学習）。1つの葉に最低50人を残す `min_n = 50` を指定すると、AUC は約0.711まで上がります。それでもロジスティック回帰には届きません。

もう一つの理由は、このデータの関係が単純なことです。解約のしやすさは、主に recency（最後の注文からの日数）が長いほど滑らかに高まります。こうした関係はロジスティック回帰が得意とする形です。ランダムフォレストが強いのは、変数どうしの複雑な組み合わせが効く場合です。**複雑なモデルほど当たるとは限りません。** 候補を同じテストデータ（や交差検証）で比べて選びます。

## 変数の重要度は因果ではない

ランダムフォレストは中身が数百本の木なので、式で読めません。代わりに、どの変数に頼って予測しているかを**変数の重要度**で見ます。

```r
imp <- randomForest::importance(extract_fit_engine(rf_fit))
```

`extract_fit_engine()` は、ワークフローの中から randomForest の結果そのものを取り出します。`randomForest::importance()` は「randomForest パッケージの importance()」という意味の書き方です。重要度には2種類あります。

- **並べ替えによる重要度**（MeanDecreaseAccuracy）：その変数の値を客の間でばらばらに並べ替えたとき、予測がどれだけ外れるようになるか
- **ジニ係数の減少**（MeanDecreaseGini）：木の分割でその変数がどれだけ使われ、葉をどれだけ解約・継続にそろえたか

c の図では、どちらでも recency が1位です。ただしジニ係数の減少では age が3位なのに、並べ替えによる重要度では age はほぼ0です。ジニ係数の減少は、値の種類が多い連続の変数を過大に評価しやすいからです。

そして、重要度は「予測にどれだけ役立つか」であって、「施策で動かすと解約がどれだけ減るか」ではありません（第91ステップ）。最後の注文から日がたっているのは、すでに離れかけていることの表れかもしれません。施策の効果は A/B テスト（第86〜88ステップ）で確かめます。

## 卒論・実務での使いどころ

新しい手法を使うときは、ロジスティック回帰のような単純なモデルと同じテストデータで比べ、重要度は「予測の手がかり」として報告し、原因とは書きません。
