## 問い

第59ステップでは、回帰に共変量を入れて調整しました。回帰は、年収と共変量の関係を直線などの式で表して差を取り除きます。そこで、式の形を決めずに、参加者1人ひとりに「前年収入や年齢が似た不参加者」を見つけて比べる方法を考えます。これが**マッチング**です。

データは引き続き、職業訓練の**架空の観察データ** `obs`（4,000人、参加者1,102人）です。真の効果は +30万円/年です。

## matchit()：似た人を組み合わせる

マッチングには MatchIt パッケージの `matchit()` を使います。初めて使うときは、パッケージの読み込みに少し時間がかかります。

```r
m_match <- matchit(treat ~ prior_earn + age + educ_years + female,
                   data = obs, method = "nearest")
m_match
```

`~` の左に処置、右にそろえたい変数を並べます。`method = "nearest"` は**最近傍マッチング**で、参加者1人ごとに、いちばん似た不参加者を1人選びます。一度選んだ不参加者は、ほかの参加者には使いません。

「似ている」かどうかは、4つの変数から計算した**傾向スコア**（その人が参加する確率の予測値。第61ステップで自分で作ります）の近さで決めています。表示の `distance: Propensity score` はそのことを指します。結果は「4000 (original), 2204 (matched)」で、参加者1,102人と、選ばれた不参加者1,102人が残りました。

## バランス表：似てきたかを確かめる

マッチングがうまくいったかは、組み合わせた後の参加者と不参加者で、共変量の平均が近くなったかで確かめます。これを**バランス**の確認といいます。

```r
bal <- summary(m_match)
bal
```

`summary()` の表示は長いので、次の2つの表を見ます。

- `Summary of Balance for All Data`（`bal$sum.all`）… マッチング前
- `Summary of Balance for Matched Data`（`bal$sum.matched`）… マッチング後

列の `Means Treated` と `Means Control` は参加者と不参加者の平均、`Std. Mean Diff.` は**標準化平均差**です。平均の差を参加者の標準偏差で割った値で、単位の違う変数どうしでも比べられます。絶対値が0.1未満なら、よくそろっているとみなすのが目安です。

| 変数 | マッチング前 | マッチング後 |
| --- | --- | --- |
| 前年収入 prior_earn | −1.52 | −0.09 |
| 年齢 age | −0.48 | −0.07 |
| 教育年数 educ_years | −0.22 | −0.01 |
| 女性 female | 0.16 | 0.03 |

前年収入の平均は、マッチング前は参加者 約191万円・不参加者 約308万円でしたが、後は約191万円・約199万円になりました。

## ATT を推定する

```r
md <- match.data(m_match)
m_att <- lm(earn_post ~ treat, data = md, weights = weights)
```

`match.data()` は、組み合わせに選ばれた2,204人だけの表を返します。`weights` の列は各人の重みです。いまの1対1のマッチングでは全員1ですが、1人の不参加者を何度も使う方法などでは1以外になります。どの方法でも正しく推定できるよう、`weights = weights` を付ける習慣にします。

参加者全員に相手を見つけたので、推定しているのは**参加者についての平均処置効果**（**ATT**, average treatment effect on the treated）です。「訓練に参加した人たちにとって、参加したことで年収がいくら変わったか」を表します。

treat の係数は約22.7万円です。前年収入などの差が少し残っているため、真の30万円より低めです。共変量を加えた回帰では約28.3万円になります。マッチングで大きな差を取り除き、残った小さな差を回帰で調整する組み合わせは、実務でもよく使われます。

ただし、マッチングがそろえるのは、式に入れた**観察できる**変数だけです。推定値を因果効果と読めるのは、第59ステップと同じく、観察できる変数で参加が説明できる（条件付き独立）ときに限られます。

## 卒論・実務での使いどころ

マッチングを使うときは、マッチング前後のバランス表を必ず示し、推定しているのが参加者についての効果（ATT）であることを明記します。
