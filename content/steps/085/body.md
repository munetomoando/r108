## 問い

第84ステップで顧客を分けた後、上司から次の宿題が出ました。「新しく来たお客さんは、初めて買ってから何か月くらいで離れていくのか。来た経路で違うのか」。初めて買った月が同じ顧客をひとまとめにし、その後の月ごとに何割が買い続けているかを追う**コホート分析**で答えます。

## コホートを作る

**コホート**は、同じ時期に同じ出来事を経験した人の集まりです。ここでは「初めて注文した月」が同じ顧客を1つのコホートにします。

```r
first_buy <- orders_m |>
  group_by(customer_id) |>
  summarise(cohort = min(ym)) |>
  inner_join(select(customers, customer_id, signup_date, channel), by = "customer_id") |>
  filter(signup_date >= ymd("2024-01-01"))
```

ここで大事なのが最後の `filter()` です。注文データは2024年1月から始まるので、2023年以前から買っていた既存顧客（約3割）も、データ上は2024年1月が「初回」に見えてしまいます。データの始まりより前の様子が見えないこの問題を、**左側の打ち切り**と呼びます。2024年以降に登録した新規顧客3,461人に絞ると、2024年1月から2025年6月までの18コホート（1コホート約190人）ができます。

## 継続率の表

次に、各注文が初回購入から何か月後か（経過月）を計算します。2024年11月に初めて買った人が2025年2月に買えば、(2025 − 2024) × 12 + 2 − 11 = 3 か月後です。

```r
ret <- orders_m |>
  inner_join(first_buy, by = "customer_id") |>
  mutate(month_n = (year(ym) - year(cohort)) * 12 + month(ym) - month(cohort)) |>
  group_by(cohort, month_n) |>
  summarise(active = n_distinct(customer_id), .groups = "drop") |>
  left_join(count(first_buy, cohort, name = "size"), by = "cohort") |>
  mutate(rate = active / size)
```

`count(first_buy, cohort, name = "size")` で各コホートの人数を数え、継続率 = その月に注文した人数 ÷ コホートの人数 とします。0か月目は全員が買っているので100%です。2025年6月のコホートは12月まで6か月分しかないので、表は右下が欠けた三角形になります。

## ヒートマップで見る

コホート × 経過月の表は、色の濃さで値を表す**ヒートマップ**にすると全体の形がつかめます。第25ステップのタイル地図と同じ `geom_tile()` を使います。

```r
ggplot(filter(ret, month_n >= 1), aes(x = month_n, y = cohort, fill = rate)) +
  geom_tile() +
  scale_fill_viridis_c()
```

0か月目（100%）を含めると色の幅がそこで使われてしまうので、1か月目以降で描きます。縦に見ればコホートの違い、横に見れば時間の経過、右下がりの斜めの線は同じ暦の月（例えば12月）の影響です。

全コホートをまとめるには、`ret |> group_by(month_n) |> summarise(rate = sum(active) / sum(size))` とします。1か月後が約43%、6か月後も約43%、12か月後が約40%でした。初回の翌月には約6割が注文しませんが、その後はほとんど下がりません。この継続率は「その月に注文したか」で数えているので、毎月は買わないが買い続ける顧客は、月によって数えられたり外れたりします。「1か月で6割が離れた」と読むのは誤りで、本当に離れた（解約した）かどうかは、例えば「3か月続けて注文がない」のような定義を別に決めて調べます（第95ステップ）。

## 流入経路で比べる

`first_buy` の channel ごとに同じ計算をすると、1か月後の継続率は紹介経由が約55%、検索が約45%、SNS が約39%、広告が約38%で、12か月後も紹介が約48%、広告が約38%と差が続きました。紹介で来た顧客は長く買い続け、広告で来た顧客は離れやすいようです。ただし、流入経路は顧客が自分で選んだもので、無作為に割り当てたものではありません。「広告をやめて紹介を増やせば継続率が上がる」と言うには、因果推論の方法（第7・8部）や実験が必要です。

## 卒論・実務での使いどころ

コホート分析は、同じ年に入社した人の離職率、同じ年に卒業した人の就職後の賃金など、「同じ時期に始めた集団をその後どこまで追えるか」を見る卒論の分析にもそのまま使えます。
