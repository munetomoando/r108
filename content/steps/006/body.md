## 問い

そらまめマーケット（架空の会社です）の経営企画部で、上司から「地域によって客単価はどれくらい違うのか」と聞かれました。50店舗を6つの地域（北海道・東北、関東、中部、近畿、中国・四国、九州・沖縄）に分け、地域ごとに客単価を集計します。このステップの stores には、第5ステップで作った客単価の列 spend（円）がはじめから加えてあります。

## グループに分ける：group_by()

第2ステップでは `mean()` でベクトル全体の平均を求めました。しかし、知りたいのは「地域ごと」の平均です。地域の数だけ `filter()` と `mean()` を繰り返すのは手間がかかります。

そこで dplyr では、まず `group_by()` で行をグループに分けます。

```r
stores_grouped <- group_by(stores, region)
stores_grouped
```

表示を見ると、先頭に `Groups: region [6]` という行が加わります。これは「region の値で6つのグループに分けた」という目印です。中身の値は何も変わっていません。グループ分けの情報が付いただけです。

## グループごとに集計する：summarise()

グループ分けした表を `summarise()` に渡すと、グループごとに集計した結果が1行ずつ返ってきます。summarise は「要約する」という意味です。

```r
region_spend <- summarise(stores_grouped, mean_spend = mean(spend))
region_spend
```

`summarise(データ, 新しい列名 = 集計の式)` の形です。6つの地域それぞれで `mean(spend)` が計算され、6行の表になります。グループ分けしていない `stores` を渡すと、全社で1行だけの結果になります。違いを実際に確かめてみましょう。

カンマで区切れば、複数の集計を一度に書けます。グループの行数は `n()` で数えます。`n()` はかっこの中に何も入れずに使う特別な関数です。

```r
summarise(stores_grouped,
          n_store = n(),
          mean_spend = mean(spend),
          max_spend = max(spend))
```

店舗数を一緒に出しておくと、平均がいくつの店舗から計算されたのかがわかります。店舗の少ない地域の平均は、1店舗の値に大きく左右されます。報告の表には店舗数を添えるのが親切です。

## 店舗の平均と、地域全体の客単価

ここまでの平均は、どの店舗も同じ重みで扱う単純平均（1店1票）です。しかし、客数の多い大型店と、客数の少ない小型店を同じ重みで扱ってよいでしょうか。

「その地域で、お客さん1人あたりいくら買ってもらえたか」を知りたいなら、地域の売上の合計を客数の合計で割ります。これは、各店舗の客単価を客数で重みづけた平均（加重平均）と同じ値になります。加重平均とは、各値に重みを掛けて合計し、重みの合計で割った平均です。

```r
summarise(stores_grouped,
          mean_spend = mean(spend),
          total_spend = sum(sales) * 10000 / sum(customers))
```

`summarise()` の中の `sum()` も、グループごとに計算されます。グループ分けしていない `stores` に同じ式を使えば、全社の客単価が求まります。経営会議の資料に載るのは、ふつうこちらの全社の客単価です。

単純平均と全体の客単価の差が大きい地域では、客数の多い店舗と少ない店舗で客単価が違っています。どちらが正しいということではなく、「店舗という単位の平均」を知りたいのか「お客さん1人あたり」を知りたいのかで使い分けます。

## 卒論・実務での使いどころ

地域別・立地別・商品別の集計はあらゆる分析の出発点であり、その際に単純平均と重みづけた平均のどちらが問いに合うかを意識することが、卒論でも経営の数字を読むときでも大切です。
