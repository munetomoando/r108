## 問い

そらまめマーケットでは、来年度のパートの時給と人件費の予算づくりが始まりました。あなたは経営会議で「最低賃金はこの20年でどう動き、地域による差はどう変わったか」を1枚の図で示し、来年度への含意を述べるよう頼まれました。第3部の総合演習で、第I段階（ステップ1〜27）の関門です。

## データと「平均」の定義

使うのは、第16ステップと同じ厚生労働省「地域別最低賃金改定状況」（2002〜2025年度）の `mw` です。地域別最低賃金は、都道府県ごとに決まる時給の下限で、毎年度10月前後に改定されます。1行は「県×年度」で、`min_wage` の単位は円/時です。

全国の動きを1本の線で表すとき、「平均」の定義に注意が必要です。厚生労働省が毎年公表する「全国加重平均額」は、県ごとの最低賃金を、その県で働く人の数で重み付けした平均です（2025年度は1121円）。この表には働く人の数がないので、ここでは47都道府県の**単純平均**を使います。2025年度の単純平均は約1067円で、公表値より50円ほど低くなります。東京・神奈川・大阪など、最低賃金が高く働く人も多い県の重みが小さくなるからです。図にも本文にも「単純平均」と明記しましょう。

## 1枚に「推移」と「地域差」を入れる

小課題 a では、年度ごとに47都道府県の最高・平均・最低を集計し、`pivot_longer()`（第13ステップ）で縦長にしてから、3本の折れ線を色分けして描きます。平均の線で全国の推移が、最高と最低の線の間の幅で地域差が、1枚で読めます。

```r
mw |>
  group_by(fiscal_year) |>
  summarise(最高 = max(min_wage), 最低 = min(min_wage)) |>
  mutate(差 = 最高 - 最低, 比 = 最高 / 最低)
```

上のコードを実行して、地域差の数字を確かめてみましょう。最高と最低の差は、2002年度の104円から広がり続け、2018年度に224円で最大になりました。その後は地方の県の引上げ幅が大きく、2025年度は203円です。最高÷最低の比で見ると、1.17倍（2002年度）から1.31倍（2014年度）まで広がり、2025年度は1.20倍まで縮んでいます。差（円）と比（倍）では、縮み始めた時期も程度も違います。どちらで語るかを決めて、図に書き添えます。

## 見出し・注記・出典で「伝わる図」にする

小課題 b では、第23ステップで学んだ `labs()`・`annotate()`・`theme_minimal()` で図を仕上げます。会議の図では、次の3つを守りましょう。

- 見出し（title）には、図から言えることを1文で書く。「最低賃金の推移」より「最低賃金は23年で約1.7倍に」の方が伝わります
- 補足（subtitle）に、何を・いつからいつまで描いたか（単純平均であること）を書く
- 出典（caption）に、統計の作成者と資料名を書く

数字で確かめておくと、単純平均は2002年度の約639円から2025年度の約1067円へ、約428円（約1.67倍）上がりました。2020年度はコロナ禍でほとんど据え置かれ（単純平均で約1.5円増）、その後は引上げが加速しています。2025年度の単純平均の引上げ額は約69円で、23年間で最大です。

## 図を画像で保存する（ggsave）

資料に貼るには、図を画像ファイルに保存します。`ggsave()` は、保存先のファイル名、図（`plot =`）、大きさ（`width`・`height`、単位はインチ）、解像度（`dpi`）を受け取ります。形式は拡張子で決まり、`.png` なら PNG 画像、`.pdf` なら PDF になります。

```r
ggsave(out_png, plot = p2, width = 8, height = 5, dpi = 150)
file.exists(out_png)
```

`file.exists()` は、そのファイルがあれば `TRUE` を返します。保存したら必ず確かめる習慣は、第18ステップで CSV を読み直したのと同じ考え方です。このアプリでは作業用フォルダ（`out_png`）に保存しますが、自分のPCの R なら `ggsave("output/min_wage.png", ...)` のように、プロジェクトのフォルダに保存しましょう。

## 結論を3行で書く

最後に、図の下に添える結論を3行で書きます。1行目は全国の動き、2行目は地域差、3行目は会社への含意です。たとえば、最低賃金の低い県ほど近年の引上げ率が高い（最低の額は2024年度の951円から2025年度の1023円へ約7.6%上昇）ことは、地方の店舗の人件費の伸びが大きくなりやすいことを意味します。ただし、来年度の引上げ額は図からは分かりません。「近年の傾向が続くとすれば」と前提を書き添えましょう。

## 卒論・実務での使いどころ

「定義を明記した図＋言いたいことを書いた見出し＋出典＋結論3行」を画像で保存する形は、経営会議の資料にも、卒論の図表にもそのまま使えます。
