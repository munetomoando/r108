## 問い

100人を調べて平均時給を求めても、第31ステップで見たとおり、その値は選んだ人によって揺れます。では、100人の調査の結果から「母集団の平均時給はこのあたりだ」と幅をもって言うには、どうすればよいのでしょうか。その幅である**信頼区間**を作り、「95%」の意味を確かめます。

## 使うデータと「母集団」

このステップでも、`wage` の3,000人（教材用に乱数で作った**架空のデータ**）を母集団とみなします。母集団の全員が手元にあるので、母平均 `mean(wage$hourly_wage)`（約2,077円）を計算できます。現実の調査では母平均は分かりません。分からないから信頼区間で推し量るのです。この教材では、作った区間が当たっているかを答え合わせできるように、あえて母平均の分かる母集団を使います。

## 信頼区間を手で計算する

95%信頼区間は、次の式で作ります。

$$\bar{x} \pm t_{0.975} \times \frac{s}{\sqrt{n}}$$

言葉でいえば「標本平均 ± t分布の値 × 標準誤差」です。$\bar{x}$ は標本平均、$s$ は標本の標準偏差、$n$ は人数で、$s/\sqrt{n}$ が第31ステップの標準誤差（σ/√n の σ を標本の $s$ で置き換えたもの）です。

```r
set.seed(108)
x <- sample(wage$hourly_wage, 100)
xbar <- mean(x)
se <- sd(x) / sqrt(100)
q <- qt(0.975, df = 99)
c(xbar - q * se, xbar + q * se)
```

`qt()` は **t分布**の値を返す関数です。σ が分からず標本の $s$ で代用すると、そのぶん不確かさが増えます。t分布は、その分を正規分布より少し裾を広げて考慮した分布です。`qt(0.975, df = 99)` は、両側に2.5%ずつを残す点で、約1.984です。`df`（自由度）は人数 − 1 です。人数が多くなると、正規分布の値1.96に近づきます。

この標本では、標本平均が約2,179円、標準誤差が約101円で、区間は約1,979円〜約2,379円になります。

## t.test() で確かめる

`t.test()` は平均についての検定（第33ステップ）を行う関数ですが、信頼区間も同時に計算します。結果の `$conf.int` で区間を取り出せます。

```r
tt <- t.test(x)
tt$conf.int
```

手で計算した区間と同じ値になります。実務では `t.test()` を使えば十分ですが、中身が「標本平均 ± 約2 × 標準誤差」だと知っておくと、結果の表を読むときに役立ちます。

## 「95%」とは何が95%なのか

母平均は1つの決まった値です。揺れるのは、標本から作る区間のほうです。そこで、100人を選んで区間を作る調査を100回くり返し、区間が母平均を含んだ回数を数えます。`between(値, 下限, 上限)` は、値が下限以上・上限以下なら `TRUE` を返す関数です。

```r
mu <- mean(wage$hourly_wage)
set.seed(108)
cover <- replicate(100, {
  s <- sample(wage$hourly_wage, 100)
  ci <- t.test(s)$conf.int
  between(mu, ci[1], ci[2])
})
sum(cover)
```

`replicate()` の `{ }` の中には複数の行を書けます。最後の行の値が、その回の結果になります。今回は100回中93回、区間が母平均を含みました。同じことを1000回くり返すと952回で、約95%になります。

つまり「95%」は、**この作り方で区間を作れば、くり返したときに約95%が母平均を含む**という、作り方の確かさです。手元の1つの区間は、母平均を含むか含まないかのどちらかに決まっています。「母平均がこの区間に入る確率が95%」という言い方は誤りです。また、信頼区間は「3,000人の95%の時給が入る範囲」でもありません。個人の時給は1,000円未満から8,000円台まで散らばっており、区間よりずっと広い範囲にあります。

## 卒論・実務での使いどころ

社内アンケートの平均満足度でも、卒論の平均賃金でも、平均値だけでなく95%信頼区間を添えて報告すると、その数字がどれくらい確かなのかを読み手に伝えられます。
