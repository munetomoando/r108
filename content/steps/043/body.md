## 問い

回帰の結果には、係数と並んで**標準誤差**（係数の推定値がどれくらい揺れうるかの目安）が表示されます。t値・p値・信頼区間はすべてこの標準誤差から計算されます。ところが、ふつうの `lm()` の標準誤差は、ある前提が成り立つときにしか正しくありません。その前提はこのデータで成り立っているのでしょうか。

## 残差のばらつきを図で見る

使うのは架空の賃金調査 `wage`（3,000人）です。教材用に乱数で作ったデータで、作るときに誤差の標準偏差を学歴とともに大きくしてあります（12年で0.25、18年で0.37）。学歴の高い人ほど、同じ条件でも時給の個人差が大きいという設定です。

```r
m <- lm(log_wage ~ educ_years + exper + tenure, data = wage)
wage_r <- mutate(wage, resid = residuals(m))
ggplot(wage_r, aes(x = factor(educ_years), y = resid)) +
  geom_boxplot()
```

箱は学歴が高いほど縦に長くなります。学歴ごとに残差の標準偏差を計算すると、12年で約0.29、14年で約0.33、16年で約0.37、18年で約0.42です。

```r
wage_r |>
  group_by(educ_years) |>
  summarise(sd_resid = sd(resid), n = n())
```

誤差のばらつきが人によって違うことを**不均一分散**といいます。反対に、どの人でも同じであることを均一分散といいます。通常の標準誤差は均一分散を前提に計算しているので、不均一分散のもとでは正しい大きさを示す保証がありません。

## 頑健な標準誤差

不均一分散があっても使える標準誤差を、**不均一分散に頑健な標準誤差**（robust standard error）と呼びます。ここでは fixest パッケージの `feols()` を使います。式と `data` の書き方は `lm()` と同じで、`vcov = "hetero"` を付けると頑健な標準誤差になります（Stata の `, robust` と同じ HC1 という計算方法です）。

```r
f_iid <- feols(log_wage ~ educ_years + exper + tenure, data = wage)
f_het <- feols(log_wage ~ educ_years + exper + tenure, data = wage, vcov = "hetero")
se(f_iid)
se(f_het)
```

`se()` は標準誤差だけを取り出す関数です。係数の値は2つのモデルでまったく同じです。変わるのは標準誤差だけです。

`educ_years` の標準誤差は、通常が約0.00331、頑健が約0.00332で、比は約1.004倍です。t値も約19.2から約19.1に変わるだけです。`exper` では約1.016倍でした。

## なぜほとんど変わらないのか

傾きの標準誤差では、説明変数の値が平均から遠い人の残差ほど重く数えられます。このデータでは教育年数の平均は約14.4年です。ばらつきの小さい12年の人と、ばらつきの大きい18年の人が、どちらも平均から離れています。そのため2つの影響が打ち消し合い、結果として通常の標準誤差とほぼ同じになりました。

これはこのデータでの結果です。ばらつきの大きい人が説明変数の端に偏っているデータでは、頑健な標準誤差が通常よりかなり大きくなることもあります。第45ステップで使う米国の賃金データでは、勤続年数の標準誤差が約0.0031から約0.0038へと2割ほど大きくなります。

## どちらを報告するか

頑健な標準誤差は、均一分散のときにも不均一分散のときにも使えます。そこで今の実証研究では、特別な理由がなければ頑健な標準誤差を報告し、表の注記に「括弧内は不均一分散に頑健な標準誤差」と書くのが標準です。結果を見てから都合のよい方を選んではいけません。使う方法は推定の前に決めておきます。

## 卒論・実務での使いどころ

卒論の回帰表では頑健な標準誤差を使って注記に明記し、社内の賃金分析で「学歴による時給の差は統計的に意味があるか」を示すときも、同じように頑健な標準誤差で判断します。
