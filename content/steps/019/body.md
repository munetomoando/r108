## 問い

1人当たりの所得が高い国ほど、人々は長生きでしょうか。世界の国々のデータを散布図に描いて確かめます。第3部「データを見せる」の最初のステップとして、R で図を作る ggplot2 パッケージの考え方を学びます。

## 使うデータ

`gapminder` パッケージの `gapminder` は、スウェーデンの財団 Gapminder が集めた世界142か国のデータを、1952年から2007年まで5年おきにまとめた表です（Based on free material from [GAPMINDER.ORG](https://www.gapminder.org/), CC-BY LICENSE）。このステップで使う列は次の4つです。

- `country`（国名）、`continent`（大陸）
- `lifeExp` … 出生時の平均寿命（年）
- `gdpPercap` … 1人当たりGDP（物価の動きを調整した米ドル）

まず2007年の行だけを取り出します。第4ステップの `filter()` です。

```r
gap07 <- filter(gapminder, year == 2007)
glimpse(gap07)
```

## ggplot の文法：データ・対応づけ・層

ggplot2 では、図を次の3つの部品の組み合わせとして書きます。

1. **データ** … どの表を描くか。`ggplot()` の1つ目の引数に渡します
2. **対応づけ（aes）** … 表のどの列を、図のどの見た目（横軸・縦軸・色など）に当てるか。`aes()` の中に `x = 列名` のように書きます。aes は aesthetics（見た目）の略です
3. **層（geom）** … 点・線・棒など、何で描くか。`geom_point()` は点の層です

部品は `+` でつなぎます。`ggplot()` だけを実行すると、軸だけの白紙の図が出ます。そこに `+ geom_point()` で点の層を重ねると、散布図になります。

```r
ggplot(gap07, aes(x = gdpPercap, y = lifeExp))
ggplot(gap07, aes(x = gdpPercap, y = lifeExp)) + geom_point()
```

散布図では、表の1行が1つの点になります。2007年の表は142行なので、点は142個です。

`+` は行の終わりに置けば、次の行に続けて書けます。部品が増えてきたら、1行に1つずつ書くと読みやすくなります。行の先頭に `+` を置くと、その前の行で式が終わってしまうので注意しましょう。

## 対数目盛りで見る

最初の散布図では、多くの国が左端に固まり、右側はまばらです。2007年の1人当たりGDPは、最も低い国で約278ドル、最も高いノルウェーで約4万9,000ドルと、170倍以上の開きがあるからです。

こうした値は**対数目盛り**で見ると読みやすくなります。対数目盛りでは、1,000→10,000 と 10,000→100,000 が同じ長さになります。つまり、差ではなく「何倍か」が同じ間隔で並びます。`scale_x_log10()` を足すと、横軸が10を底とする対数目盛りになります。

```r
ggplot(gap07, aes(x = gdpPercap, y = lifeExp)) +
  geom_point() +
  scale_x_log10()
```

`scale_` で始まる関数は、データの値を軸の目盛りにどう写すかを決める部品です。データそのものは変えていないので、目盛りの数字は元のドルのままです。

## 色で3つ目の変数を見せる

色も、横軸・縦軸と同じく「列と見た目の対応づけ」です。そのため `aes()` の中に `colour = continent` と書きます。凡例（色と大陸の対応表）は自動で付きます。

```r
ggplot(gap07, aes(x = gdpPercap, y = lifeExp, colour = continent)) +
  geom_point() +
  scale_x_log10()
```

一方、`geom_point(colour = "blue")` のように aes の外に書くと、列とは関係なく全部の点が青になります。「列の値で変わるものは aes の中、全部に同じものは aes の外」と覚えましょう。

図を見ると、1人当たりGDPが高い国ほど平均寿命が長いという右上がりの関係が見えます。大陸で色分けすると、アフリカの国々が左下に多いことも分かります。2007年に平均寿命が最も長いのは日本（82.6年）です。ただし、これは所得が寿命を延ばすという因果関係の証明ではありません。医療や教育など、所得と一緒に動く要因があるからです。

## 卒論・実務での使いどころ

2つの量の関係をまず散布図で見る習慣は、卒論で回帰分析をする前にも、仕事で「市場の大きさ（人口）と購買力（所得）の関係から出店先の候補を絞る」ときにも役立ちます。
