## 問い

教育年数が1年長いと時給が何%高いかは、第37ステップで調べました。では、その「学歴の効果」は男性と女性で同じでしょうか。2つの変数の積である**交差項**を使って、傾きが男女で違うかを確かめます。

## 使うデータ

`wage` は教材用に乱数で作った**架空の**賃金調査（3,000人）です。図で使うため、setup で性別のラベル `sex`（「女性」「男性」）の列を足してあります。

## 交差項：傾きがグループで違うことを許す

これまでの式 `log_wage ~ female + educ_years` では、男女の直線は**平行**です。`female` の係数は2本の直線の上下のずれを表し、傾き（教育年数の係数）は男女で共通でした。

傾きも男女で違ってよいことにするには、`female` と `educ_years` の積を説明変数に加えます。これが交差項です。

$$\log(\text{時給}) = b_0 + b_1\,\text{female} + b_2\,\text{educ} + b_3\,(\text{female} \times \text{educ})$$

R の式では、2つの変数を `*` でつなぐと、それぞれの変数と交差項 `female:educ_years` がまとめて入ります。

```r
m_i <- lm(log_wage ~ female * educ_years, data = wage)
coef(m_i)
```

係数は、定数項が約6.923、`female` が約 −0.144、`educ_years` が約0.0499、`female:educ_years` が約 −0.001 です。

## 男女別の傾きを計算する

式に female = 0 を入れると交差項が消え、男性の傾きは $b_2$ だけになります。female = 1 を入れると、女性の傾きは $b_2 + b_3$ です。

```r
slope_m <- coef(m_i)[["educ_years"]]
slope_f <- coef(m_i)[["educ_years"]] + coef(m_i)[["female:educ_years"]]
c(slope_m, slope_f)
```

男性は約0.0499、女性は約0.0489です。つまり**交差項の係数 $b_3$ は「女性の傾き − 男性の傾き」**です。実は、男女でデータを分けて別々に単回帰しても、同じ傾きになります。

```r
coef(lm(log_wage ~ educ_years, data = filter(wage, female == 1)))
```

交差項つきの回帰は、2つの回帰を1つの式にまとめたものだと考えられます。1つにまとめると、傾きの差 $b_3$ の標準誤差や信頼区間も一度に求められます。

ここでの教育の係数（約0.05）は、第39ステップの重回帰の値より小さくなっています。経験年数などを式に入れていないためです（同じ年齢なら学歴の長い人ほど経験年数が短い）。

## 図で確かめる

`aes()` の `colour` に `sex` を対応づけて `geom_smooth(method = "lm")` を足すと、男女別に回帰直線が引かれます。

```r
ggplot(wage, aes(x = educ_years, y = log_wage, colour = sex)) +
  geom_point(alpha = 0.1) +
  geom_smooth(method = "lm")
```

2本の直線はほぼ平行で、女性の直線が全体に下にずれています。傾きの差（交差項）は小さく、水準の差は大きい、ということが一目で分かります。

## 交差項の読み方の注意

交差項の95%信頼区間（`confint(m_i)`）は約 −0.015〜0.013 で0を含みます。このデータでは、学歴の効果が男女で違うとは言えません。

もう1つの注意は、交差項を入れると `female` の係数の意味が変わることです。−0.144 は「教育年数が0年のときの男女差」で、そのような人はデータにいません。実際の男女差は教育年数ごとに $b_1 + b_3 \times \text{educ}$ で計算し、12年なら約 −0.156、16年なら約 −0.160 です。

## 卒論・実務での使いどころ

「この施策の効果は若手とベテランで違うか」「最低賃金の影響は地方で大きいか」のように、効果がグループで異なるかを問うときは、交差項を入れてその係数と信頼区間を報告します。
